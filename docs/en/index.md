# Build with agents without losing the engineering

A task starts with intent. In Kavor, you keep the agents, context, and evidence around it that you need to reach a
deliverable you can review. The Canvas makes that work visible; Connections let your CodingAgents work with reachable
resources and participants.

![Specifications, CodingAgents, Files, Sticky Notes, and Terminals arranged in a real Kavor Workspace](https://media.agentkavor.com/demos/canvas-overview/workspace.8f917eaa5261.jpg)

[See this Workspace in action →](https://agentkavor.com/en/videos/overview)

## Start with a small deliverable

If this is your first Canvas, choose a change you know how to verify: fix validation, add a test, or implement a small
feature. The tutorial sets up a Specification, an Implementer, a Reviewer, and a Sticky Note to keep intent,
implementation, review, and decision in the same loop.

**[Build your first loop →](./first-loop.md)**

The structure grows as the task requires. You can start with a few Nodes and add a Terminal for checks, a File as a
reference, or a WebBrowser to test the application. If you prefer to understand the model first, read
[What is Kavor?](./what-is-kavor.md).

## What do you want to do?

| Your task | Where to go |
| --- | --- |
| Turn an idea into an implementable contract | [Specification](./specification.md): questions, scope, criteria, and evidence. |
| Split implementation and review between agents | [CodingAgents and roles](./agents-and-roles.md): responsibilities, context, and handoffs. |
| Keep open decisions and progress in view | [Sticky Note](./sticky-note.md): shared working memory. |
| Work from code, a PDF, an image, or another file | [File](./file.md): canonical source, reference, and execution input. |
| Run checks or investigate a process | [Terminal](./terminal.md): commands, logs, and collaboration in the same shell. |
| Reproduce and fix a web application problem | [WebBrowser](./web-browser.md): live page, console, network, and visual evidence. |
| Start a routine at a defined time | [Schedule](./schedule.md): prompts or commands, recurrence, and results. |
