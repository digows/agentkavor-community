# Build with agents without losing the engineering

Kavor is the local-first system around coding agents. Use one visual Workspace to connect the questions, context,
Specifications, files, CodingAgents, Terminals, WebBrowsers, evidence, and decisions that make software work durable.

## Your first loop in five minutes

1. Download and open Kavor, then choose the directory that will be the root of your Workspace.
2. Add one Specification, one CodingAgent, and one Terminal to the Canvas.
3. Connect the Specification, Terminal, and CodingAgent in one component so context and capabilities are reachable.
4. Ask the CodingAgent to implement the Specification, inspect its evidence, and decide what you accept.

Start with this small closed loop. Add reviewers, Files, Sticky Notes, and WebBrowsers only when the work benefits
from them.

## Work across multiple Workspaces

Each Kavor window can keep a different Workspace open. This lets you distribute projects across windows and monitors
without mixing Canvases, sessions, or context. Kavor keeps one shared runtime while each window preserves the work
you placed in it.
