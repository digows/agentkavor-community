# Kavor 2.3.0

## Highlights

- **Diagrams on the Canvas:** files from 13 format families, including Mermaid, PlantUML with C4, Graphviz, D2,
  Excalidraw and draw.io. Switch between Diagram, Source and Split, inspect rendering errors, and export SVG or PNG.
  Excalidraw supports visual editing; draw.io is view-only in Kavor.
- **Documentation organized on disk:** Specifications and Diagrams share Documentation roots. Set a Diagrams folder
  relative to the first root, browse the real folder tree, and create through the toolbar or inline form. The default
  remains `docs/diagrams/`; changing the destination does not move existing files.
- **More ways to add context:** drag files from your operating system onto the Canvas, or paste files, image data,
  a URL or text. Files stay at their sources; pasted images are saved as PNGs in the Workspace. External sources
  follow changes on disk, and files without a rich preview show a card with details and actions.

## Fixes

- Auto respects accounts excluded from participation in the Workspace and preserves Manual choices. When
  participating alternatives are unusable, existing sessions are preserved and reconsidered when an eligible account
  recovers, without turning an exclusion into permission for a new execution.
- Codex usage consultations no longer retry automatically after definitive credential revocation; explicit recovery
  remains available through human-initiated Refresh.
- Corrected Terminal and CodingAgent dimension handling when presenting prestarted sessions and changing zoom,
  preserving the native session rather than recreating it to adjust its presentation.

## Installation

Update through Kavor or use the [downloads page](https://agentkavor.com/downloads). If the updater is unavailable,
packages remain accessible at [download.agentkavor.com](https://download.agentkavor.com).

## Known limitations

- Diagram engines and resources are obtained on demand. First use may require internet access; the cache can reuse
  previously downloaded resources, but content referencing external URLs may still need a network connection.
- draw.io has no editor in Kavor, and D2 does not offer TALA. Model availability, usage readings and session resumption
  still depend on the capabilities and authentication of the selected harness.
