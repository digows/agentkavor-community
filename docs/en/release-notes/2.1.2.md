# Kavor 2.1.2

## Highlights

- Hotfixes for CodingAgent accounts, Channel attachments and Browser use.

## Fixes

- Avoids forced OAuth token renewal during ordinary Codex account reads and duplicate queries within the same
  selection decision. Preserves Automatic account selection and Auto Rotate behavior.
- New managed accounts for Codex, Claude Code and Grok no longer clone personal setup. Each account keeps isolated
  authentication; native history stays in the provider's canonical location and Kavor's integration is prepared
  separately.
- Fixes Channel attachment preparation and cleanup: preserves source files and attachments already claimed by a
  message when preparation fails, removes temporary staging files and retries expired-copy cleanup after transient
  failures.
- In the Browser, anonymous new-page openings, such as `target="_blank"` links, now use tabs in the same Node.
  Explicit popups, named targets and POST submissions remain native windows.
- Fixes control operations on background pages, interaction-geometry tracking and listener cleanup. Removes
  permanent geometry polling and bounds the network-response previews retained by the Browser.

## Installation

Download Kavor from <https://download.agentkavor.com> or check for updates in Software Update settings.

- **Windows x64:** Microsoft Store or the user-assisted NSIS installer. Microsoft signs and updates Store
  installations. The direct installer remains unsigned and may show a SmartScreen warning.
- **macOS 13+:** separate, signed and notarized DMGs for Apple Silicon and Intel. Automatic updates use the ZIP for
  the matching architecture; the DMG remains available for manual installation.
- **Linux x64:** AppImage and DEB. AppImage supports Kavor-managed updates with an explicit coordinated restart;
  DEB updates are installed manually.

## Known limitations

- Usage reporting and authentication recovery remain provider-dependent. Account-usage refresh intervals, account
  eligibility, rotation thresholds and provider limits are unchanged.
- Existing managed profiles are not automatically migrated or cleaned; previously copied setup is preserved.
- New tabs created for anonymous openings do not preserve native communication through `WindowProxy` and
  `window.opener`. Sites relying on it, including some sign-in or payment flows, may not complete that flow on
  this path.
- Windows ARM64 and Linux ARM64 packages are not included. Microsoft Store availability may follow direct
  publication because of Microsoft's independent certification.
