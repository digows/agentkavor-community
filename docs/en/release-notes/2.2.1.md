# Kavor 2.2.1

## Highlights

- Effective **Manual** mode, set on the CodingAgent or inherited from the Workspace, does not query capacity for
  rotation when a turn completes. Visible usage readings and **Refresh** remain available.
- **Automatic** reuses recent readings for the same account across Workspaces within the original 30-second
  window, without delaying reevaluation after expiry, usage-window renewal, or a confirmed authentication or quota failure.

Rotation remains preventive, with a default threshold of **95% usage**. Participation, model, and spending-permission
rules remain unchanged; account switching still respects the safe boundary between turns and session continuity.

## Fixes

- Displaying account names and resolving names or known identities in Agent Kavor commands no longer cause
  unnecessary usage queries. Unknown identities may still require a query.
- Fixes manual refresh for an account without an in-memory reading so it does not duplicate the initial query.

See [CodingAgent Accounts](../coding-agent-accounts.md) for Manual, Automatic, and reading timestamps.

## Installation

Download Kavor at <https://download.agentkavor.com> or check for updates in Software Update settings.

## Known limitations

Provider limits, authentication, and service availability remain under the providers' control.
