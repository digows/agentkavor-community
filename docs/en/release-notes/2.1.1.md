# Kavor 2.1.1

## Highlights

- Reduces redundant account observations while preserving Automatic account selection and Auto Rotate behavior.

## Fixes

- Stops ordinary Codex account reads from forcing OAuth token renewal. Native authentication recovery remains
  controlled by Codex.
- Shares pending observations for the same account and reuses the current account observation within one selection
  decision, without reusing execution data from an earlier decision.

## Installation

Download Kavor from <https://download.agentkavor.com> or check for updates in Software Update settings.

- **Windows x64:** Microsoft Store or the user-assisted NSIS installer. Microsoft signs and updates Store
  installations. The direct installer remains unsigned and may show a SmartScreen warning.
- **macOS 13+:** separate, signed and notarized DMGs for Apple Silicon and Intel. Automatic updates use the ZIP for
  the matching architecture; the DMG remains available for manual installation.
- **Linux x64:** AppImage and DEB. AppImage supports Kavor-managed updates with an explicit coordinated restart;
  DEB updates are installed manually.

## Known limitations

- Provider-reported usage and authentication recovery remain provider-dependent. This hotfix does not change
  refresh intervals, account eligibility, rotation thresholds or provider limits.
- Windows ARM64 and Linux ARM64 packages are not included. Microsoft Store availability may follow direct
  publication because of Microsoft's independent certification.
