# Kavor 2.2.0

## Highlights

- CodingAgents can start, restart, shut down and fork reachable sessions when **Allow workspace editing** and the authorized request permit it. Fork support depends on the provider and available native history.
- Atomic Canvas editing includes removing reachable Nodes, with execution teardown and reconciliation of Connections and pending messages, without deleting canonical sources or Git worktrees.

## Fixes

- Validates an association with a prepared worktree before starting the CodingAgent and keeps the Workspace root, the agent's active directory and each checkout's Git state separate.
- Fixes running-session transitions when creating, selecting or leaving a worktree. Resumption uses the existing native identity where supported; deliberately stopped sessions stay stopped.
- Protects Git associations against concurrent operations and prevents removal or finishing of worktrees referenced by other CodingAgents. Failures do not remove user-prepared worktrees as though they were attempt-owned temporary resources.
- Preserves startup failure stages and diagnostics, including an early provider exit or a viewport that stays blank. A repaired attempt can start again in the same Node.
- Preserves the pending first message across failed startup and retry, avoiding repetition of an already consumed delivery.
- Improves Claude Code input-readiness detection without confusing visual suggestions with text entered by the user. Human drafts, questions and approvals remain protected.

## Installation

Download Kavor from <https://download.agentkavor.com> or check for updates in Software Update settings.

- **Windows x64:** Microsoft Store or the user-assisted NSIS installer. Microsoft signs and updates Store installations. The direct installer remains unsigned and may show a SmartScreen warning.
- **macOS 13+:** separate, signed and notarized DMGs for Apple Silicon and Intel. Automatic updates use the ZIP for the matching architecture; the DMG remains available for manual installation.
- **Linux x64:** AppImage and DEB. AppImage supports Kavor-managed updates with an explicit coordinated restart; DEB updates are installed manually.

## Known limitations

- Fork depends on the provider's capabilities and installed version. The Antigravity integration does not offer Fork; creating another session without history is not an equivalent substitute.
- A Git worktree does not install dependencies or automatically copy local configuration or credentials. Environment preparation remains project-specific.
- Provider readiness and message delivery do not prove task completion. Limits, authentication and service availability remain under provider control.
- Windows ARM64 and Linux ARM64 packages are not included. Microsoft Store availability may follow direct publication because of Microsoft's independent certification.
