# Kavor 1.2.0

## Destaques

- Adiciona previews ricos em File Nodes para imagens e PDFs. PDFs grandes renderizam apenas as páginas visíveis,
  enquanto limites controlados de imagem, Canvas e arquivo protegem o Workspace contra uso ilimitado de memória.
- Completa os fluxos do ciclo de vida de Files e Specifications: crie uma Specification pelo menu do Canvas, renomeie
  ou exclua fontes pelas superfícies do Workspace, organize pastas e mantenha Nodes existentes sincronizados com
  alterações no sistema de arquivos.
- Permite soltar caminhos do painel Files diretamente em sessões de Terminal e CodingAgent, com escape adequado ao
  shell ativo.
- Expande propostas atômicas do Canvas com criação de Specifications, progresso persistido da aplicação e recuperação
  de efeitos colaterais reversíveis em Files e Specifications.
- Faz cada Kavor Skill disponível informar a chamada exata `kavor.skill.get("<name>")` usada por um CodingAgent para
  carregá-la.

## Correções

- Preserva campos personalizados, comentários e ordem do frontmatter YAML, além de nomes de arquivo e caminhos
  relativos ao Workspace, ao editar Specifications.
- Estabiliza a hidratação de Terminals e CodingAgents para que estados atrasados de PTY não percam conteúdo restaurado
  nem dupliquem ownership durante mudanças de Workspace.
- Mantém appends de Sticky Notes como blocos Markdown distintos, evita criar uma revisão para append vazio e aplica
  limites de texto por code point Unicode.
- Reforça mutações de Files e Specifications com alterações serializadas no Workspace, contenção de caminhos,
  invalidação de fontes e tratamento explícito de falhas.
- Resolve os alertas de segurança presentes no grafo de dependências de produção anterior.

## Instalação

Baixe o Kavor em <https://download.agentkavor.com>. A página detecta a plataforma atual e também mostra todos os
pacotes disponíveis.

- Windows x64 usa o instalador NSIS assistido por usuário. O instalador ainda não é assinado, então o Microsoft
  SmartScreen pode exigir confirmação explícita.
- macOS 13+ oferece DMGs separados para arm64 e x64. Os builds têm assinatura ad-hoc, mas não são notarizados; siga as
  instruções de Gatekeeper na página de download. As atualizações gerenciadas pelo Kavor usam o ZIP correspondente à
  arquitetura e oferecem reinício coordenado após revalidar o artefato em cache. O download manual permanece sempre
  disponível.
- Linux x64 oferece pacotes AppImage e DEB. AppImage aceita atualizações gerenciadas pelo Kavor com reinício
  coordenado explícito; atualizações DEB são instaladas manualmente pela página de download.

## Limitações conhecidas

- Pacotes Windows ARM64 e Linux ARM64 não estão incluídos até que seus gates nativos de PTY, SQLite, contenção de
  processos e runtime empacotado possam rodar em ambientes de CI correspondentes.
- Downloads diretos para Windows ainda não têm certificado de publisher Authenticode.
- Pacotes macOS ainda não têm assinatura Developer ID nem notarização. O Gatekeeper pode exigir confirmação manual,
  e substituir um build ad-hoc pode fazer o macOS solicitar novamente acesso ao `Kavor Safe Storage` no Keychain.
- A distribuição pela Microsoft Store não faz parte desta release.
