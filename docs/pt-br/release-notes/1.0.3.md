# Kavor 1.0.3

## Destaques

- Restaura Terminals e CodingAgents no pacote macOS iniciando a bridge de contexto com o runtime Electron Helper
  dedicado e carregando suporte a Windows Job Object apenas no Windows.
- Torna a apresentação de Terminals e CodingAgents resiliente a pan, zoom, remount e startup de Workspace. Output
  hidratado aparece somente depois do checkpoint autoritativo ser pintado, sem perder a sessão ao mudar sua apresentação.
- Adiciona canais explícitos stable e prerelease. Stable continua padrão; prerelease exige opt-in persistido fora dos
  dados do Workspace.
- Inclui identidade de build verificável nos pacotes e reforça a validação nativa antes de uma release chegar a stable.

## Correções

- Impede que o Process Host empacotado falhe antes do handshake no macOS e Linux quando o módulo Job Object exclusivo
  do Windows e sua dependência nativa `koffi` não estão nesses pacotes.
- Corrige o runtime da bridge de CodingAgent no macOS empacotado, evitando que Authentication, Terminal e CodingAgent
  falhem porque o executável principal rejeita o entry point Node em background.
- Adiciona gate de startup empacotado que aguarda o handshake do Process Host e verifica o runtime da bridge específica
  da plataforma, sem esconder crash precoce como timeout genérico.
- Refaz hidratação PTY e ownership de apresentação para manter output, readiness, acknowledgements, foco e controles
  consistentes quando Nodes transitam entre Canvas e camadas em screen space.
- Remove status persistido de apresentação da configuração da sessão Terminal e migra bancos existentes para derivar
  disponibilidade de recursos vivos, evitando estado antigo após restart ou recovery.
- Melhora startup, restart, worktree e controles de disponibilidade do CodingAgent, com recuperação mais clara quando
  o provider ou seu Terminal não inicia.
- Limita a extração de respostas do Antigravity à requisição concluída e aceita variantes suportadas de transcript e
  término sem vazar resposta antiga de outra execução.
- Impede checks antigos de update de substituir estado novo, preserva detalhes de update/build após reload do renderer
  e adiciona o ícone Kavor às notificações de update do sistema.
- Melhora posicionamento no Canvas, orientação de Connections, transições de painel, startup do Workspace, Settings,
  controles Git, Specifications e consistência de apresentação dos Nodes.
- Faz o canary de telemetry empacotado tolerar writes transitórios do perfil Chromium no cleanup após entrega bem-
  sucedida, evitando falha da release apenas por `ENOTEMPTY` temporário.
- Simplifica CI nativa: diagnósticos manuais constroem uma plataforma; uma tag de versão continua acionando toda a
  matriz. Updates stable chegam a 100% das instalações elegíveis por padrão, com pausa emergencial reversível.

## Instalação

Baixe o Kavor em <https://download.agentkavor.com>. A página detecta a plataforma e mostra todos os pacotes.

- Windows x64 usa instalador NSIS por usuário, ainda sem assinatura; o SmartScreen pode exigir confirmação.
- macOS 13+ oferece DMGs arm64 e x64. Os builds têm assinatura ad-hoc, sem notarização; siga o Gatekeeper, instale
  updates manualmente e saiba que a troca pode pedir novamente acesso ao `Kavor Safe Storage` no Keychain.
- Linux x64 oferece AppImage e DEB. AppImage aceita updates gerenciados; DEB é atualizado manualmente.

## Limitações conhecidas

- Windows ARM64 e Linux ARM64 aguardam gates nativos de PTY, SQLite, contenção de processos e runtime em CI compatível.
- Downloads Windows ainda não têm certificado Authenticode.
- Instalação automática no macOS permanece desabilitada até Developer ID e notarização.
- A Microsoft Store não faz parte desta release.
