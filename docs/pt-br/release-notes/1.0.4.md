# Kavor 1.0.4

## Destaques

- Adiciona updates gerenciados pelo Kavor ao macOS arm64 e x64 usando ZIPs específicos por arquitetura, blockmaps
  diferenciais e um único canal estável consolidado.
- Mantém o DMG específico de arquitetura como download humano, enquanto o updater escolhe o ZIP correto, baixa em
  background e instala pelo fluxo coordenado de encerramento normal do Kavor.
- Preserva <https://download.agentkavor.com> como fallback permanente em toda plataforma e para toda falha do updater.

## Correções

- Corrige o contrato de release do macOS que havia habilitado o updater automático nos pacotes sem publicar os ZIPs e
  arquivos `latest-mac.yml` exigidos pelo Electron Updater.
- Impede que o job de uma arquitetura macOS substitua os metadados da outra, validando cada ZIP nativo e consolidando
  ambas as entradas na publicação.
- Adiciona cobertura SHA-256 imutável para os dois ZIPs e blockmaps do updater macOS, verificação exata de assets antes
  da promoção e gates de pacote nativo para o metadata gerado.
- Renomeia a configuração obsoleta do pacote inicial para o contrato de distribuição direta das releases atuais.

## Instalação

Baixe o Kavor em <https://download.agentkavor.com>. A página detecta a plataforma atual e mostra todos os pacotes.

- Windows x64 usa o instalador NSIS assistido por usuário. Ele ainda não é assinado, e o Microsoft SmartScreen pode
  exigir confirmação explícita.
- macOS 13+ oferece DMGs separados para arm64 e x64. Os builds têm assinatura ad-hoc, mas não são notarizados; siga as
  instruções do Gatekeeper. Depois desta versão, releases posteriores aceitas podem baixar e instalar automaticamente
  quando o Kavor encerrar normalmente. O download manual permanece sempre disponível.
- Linux x64 oferece AppImage e DEB. AppImage aceita updates gerenciados; updates DEB são instalados manualmente.

## Limitações conhecidas

- Pacotes Windows ARM64 e Linux ARM64 não estão incluídos até que gates nativos de PTY, SQLite, contenção de processos
  e runtime empacotado possam rodar em CI correspondente.
- Downloads diretos para Windows ainda não têm certificado Authenticode.
- Pacotes macOS ainda não têm Developer ID nem notarização. O Gatekeeper pode exigir confirmação manual e substituir
  um build ad-hoc pode pedir novamente acesso ao `Kavor Safe Storage` no Keychain.
- A Microsoft Store não faz parte desta release.
