# Kavor 1.1.0

## Destaques

- Substitui, nos novos pacotes, o login por protocolo privado do sistema operacional por um callback de curta duração
  em `127.0.0.1`, vinculado à tentativa. Authentications por Google, GitHub e link de e-mail sem senha agora retornam
  diretamente ao Kavor pelo navegador do sistema, com PKCE nos fluxos de providers e fallback explícito pela área de
  transferência.
- Adiciona consentimento legal no primeiro uso à Authentication e mantém a sincronização do ciclo de vida da conta
  atrás da API pública e versionada do Kavor.
- Permite que CodingAgents proponham File e Specification Nodes pelo mesmo catálogo de propostas atômicas do Canvas
  usado pelas demais alterações revisadas. Connection Skills agora começam com regras aplicáveis e contexto Git-aware.
- Melhora a apresentação, troca de Workspace, inicialização e recuperação de sessões de Terminal e CodingAgent sob
  atividade concorrente de PTY.
- Simplifica navegação e ações de Specifications, mantendo acesso direto ao trabalho baseado em Files pelo Workspace.

## Correções

- Corrige a troca do authorization code do Google Desktop e a troca confidencial server-side do GitHub, para que
  ambos concluam Authentication direta por loopback sem distribuir credenciais do GitHub na aplicação.
- Remove o registro de protocolo privado dos novos pacotes desktop, evitando falhas de desktop handler no Linux e
  preservando rotas hospedadas de compatibilidade para versões antigas ainda suportadas.
- Reforça callbacks de loopback contra tentativas antigas, repetidas, malformadas ou incompatíveis e mantém
  credenciais de providers e respostas de callback fora do armazenamento persistente e dos logs.
- Corrige hidratação de PTY e ownership de apresentação durante mudanças de Workspace, incluindo recuperação de
  handshakes atrasados ou interrompidos sem inventar encerramentos de processo.
- Reduz trabalho desnecessário de Canvas e painéis ao redor de Terminal, CodingAgent, File e Specification Nodes e
  deixa mais claras as ações do painel de Specification.
- Direciona a descoberta de releases pela API estável de download do Kavor, removendo o acoplamento direto do cliente
  desktop com o host das releases.

## Instalação

Baixe o Kavor em <https://download.agentkavor.com>. A página detecta a plataforma atual e também mostra todos os
pacotes disponíveis.

- Windows x64 usa o instalador NSIS assistido por usuário. O instalador ainda não é assinado, então o Microsoft
  SmartScreen pode exigir confirmação explícita.
- macOS 13+ oferece DMGs separados para arm64 e x64. Os builds têm assinatura ad-hoc, mas não são notarizados; siga as
  instruções de Gatekeeper na página de download. As atualizações gerenciadas pelo Kavor usam o ZIP correspondente à
  arquitetura e oferecem reinício coordenado após revalidar o artefato em cache. O download manual permanece sempre
  disponível.
- Linux x64 oferece pacotes AppImage e DEB. AppImage aceita atualizações gerenciadas pelo Kavor com reinício
  coordenado explícito; atualizações DEB são instaladas manualmente pela página de download.

## Limitações conhecidas

- Versões lançadas até a 1.0.6 não conseguem mais iniciar um novo login pelo GitHub porque o OAuth App legado foi
  desativado após a migração para autenticação direta com o provider. Sessões já autenticadas continuam válidas;
  instale o Kavor 1.1.0 para entrar com GitHub novamente.
- Pacotes Windows ARM64 e Linux ARM64 não estão incluídos até que seus gates nativos de PTY, SQLite, contenção de
  processos e runtime empacotado possam rodar em ambientes de CI correspondentes.
- Downloads diretos para Windows ainda não têm certificado de publisher Authenticode.
- Pacotes macOS ainda não têm assinatura Developer ID nem notarização. O Gatekeeper pode exigir confirmação manual,
  e substituir um build ad-hoc pode fazer o macOS solicitar novamente acesso ao `Kavor Safe Storage` no Keychain.
- A distribuição pela Microsoft Store não faz parte desta release.
