# Kavor 1.5.0

## Destaques

- Publica o Kavor na Microsoft Store para Windows, além do download direto do NSIS. A Microsoft assina e distribui
  o pacote da Store e gerencia as atualizações das instalações feitas por esse canal.
- Assina as duas arquiteturas do macOS com Apple Developer ID e as notariza pela Apple. O Gatekeeper agora pode
  verificar o publisher do Kavor e o ticket de notarização, sem o fluxo inicial de desenvolvedor não identificado.
- Adiciona um seletor de diretório de trabalho a cada CodingAgent. Uma sessão pode iniciar em qualquer diretório
  existente escolhido pelo usuário, inclusive fora do Workspace, preservando sua associação independente de Git e
  worktree.
- Permite que CodingAgents conectados leiam passivamente turnos concluídos da sessão atual de provider de um peer
  alcançável. O histórico usa paginação por cursor e a leitura não envia entrada ao provider, não ativa o peer nem
  cria uma mensagem do Kavor.
- Melhora a entrega de contexto das Kavor Skills: as orientações para criar Specifications ficam disponíveis antes
  de uma Specification ser conectada, e Triggers recebem diretamente o contexto operacional relevante.

## Correções

- Preserva mensagens longas completas de sessões de CodingAgent em páginas de histórico limitadas, sem truncar o
  texto restante.
- Detecta mudanças de sessão do provider durante a leitura passiva de um peer e rejeita a continuação obsoleta, em
  vez de combinar fragmentos de sessões diferentes.
- Valida sessões do Codex antes de retomá-las e substitui uma sessão atual arquivada externamente sem perder seu
  histórico de provider restaurável.
- Lê o histórico concluído do Antigravity entre páginas do provider e normaliza o suporte a histórico passivo em
  Claude Code, Codex, Antigravity, OpenCode e Grok.
- Mantém argumentos longos de inicialização e caminhos de diretório selecionados contidos no painel de configurações
  do CodingAgent.

## Instalação

Baixe o Kavor em <https://download.agentkavor.com>. A página detecta a plataforma atual e também exibe todos os
pacotes disponíveis. Instalações diretas existentes podem procurar esta versão nas configurações de Software Update
do Kavor. Nenhuma migração manual dos dados do Workspace é necessária; o Kavor cria backup dos bancos locais
suportados antes de aplicar atualizações de schema.

- Windows x64 está disponível na Microsoft Store ou no instalador NSIS assistido por usuário. A Microsoft assina e
  atualiza as instalações da Store. O instalador direto continua sem assinatura, então o Microsoft SmartScreen pode
  exigir confirmação explícita.
- macOS 13+ oferece DMGs separados para Apple Silicon e Intel, assinados com o Apple Developer ID do Kavor e
  notarizados pela Apple. Esta versão migra a identidade ad-hoc anterior para a identidade estável de Developer ID.
  Se o macOS recusar a transição automática de um build antigo, instale manualmente o DMG correspondente pela página
  permanente de downloads; os dados existentes do Kavor são preservados.
- Linux x64 oferece pacotes AppImage e DEB. AppImage aceita atualizações gerenciadas pelo Kavor com reinício
  coordenado explícito; atualizações DEB são instaladas manualmente pela página de download.

## Limitações conhecidas

- Triggers de Schedule exigem que o runtime do Kavor esteja em execução, a máquina esteja acordada, o usuário esteja
  autenticado e a sessão de destino esteja ativa. Uma ocorrência perdida enquanto o Kavor não estava em execução é
  registrada e oferecida como execução manual explícita; ela nunca roda automaticamente na próxima abertura.
- Pacotes Windows ARM64 e Linux ARM64 não estão incluídos até que seus gates nativos de PTY, SQLite, contenção de
  processos e runtime empacotado possam rodar em ambientes de CI correspondentes.
- Downloads diretos para Windows ainda não têm certificado de publisher Authenticode; os pacotes da Microsoft Store
  são assinados pela Microsoft.
- A primeira migração de um build macOS ad-hoc para o build assinado com Developer ID pode exigir instalação manual
  do DMG ou uma autorização do Keychain para `Kavor Safe Storage`. As versões assinadas seguintes mantêm a mesma
  identidade Apple Team.
- A Microsoft Store pode disponibilizar esta versão exata apenas depois de concluir sua certificação independente;
  os pacotes diretos stable ficam disponíveis imediatamente na página de download do Kavor.
