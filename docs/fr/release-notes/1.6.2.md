# Kavor 1.6.2

## Nouveautés

- Étend les contrôles humains du Node WebBrowser avec un bouton DevTools explicite, l'ouverture de la page HTTP ou
  HTTPS active dans le navigateur système et les actions natives couper, copier, coller et tout sélectionner dans
  le champ d'adresse.
- Gère les défis d'authentification HTTP et proxy dans le Node WebBrowser et affiche, pour chaque page, le nombre
  d'erreurs de console et de règles réseau de CodingAgents, avec des actions directes pour inspecter les erreurs ou
  effacer les règles actives.
- Ouvre les serveurs de développement local utilisant des certificats autosignés, expirés ou émis par une autorité
  privée dans le Browser Profile dédié de Kavor, sans affaiblir la validation des certificats de la session de
  l'application Kavor.

## Corrections

- Fait occuper tout le viewport à la présentation du nouvel onglet WebBrowser et maintient la progression du
  chargement sur le bord de la barre d'état sans déplacer le contenu de la page.
- Affine le menu de création du Canvas afin que les providers de CodingAgent et les types de Node bénéficient d'un
  regroupement cohérent et de couleurs d'icône distinctives.
- Fait valider les identifiants protégés et l'accès à Partner Center avant que la publication Microsoft Store ne
  consomme des minutes de build natif, tout en sérialisant les soumissions sans annuler une opération Store active.

## Installation

Téléchargez Kavor depuis <https://download.agentkavor.com>. La page détecte la plateforme actuelle et affiche aussi
tous les paquets disponibles. Les installations directes existantes peuvent rechercher cette version dans les
paramètres Software Update de Kavor. Aucune migration manuelle des données du Workspace n'est requise.

- Windows x64 est disponible dans le Microsoft Store ou via l'installateur NSIS assisté par utilisateur. Microsoft
  signe et met à jour les installations Store. L'installateur direct reste non signé, Microsoft SmartScreen peut donc
  demander une confirmation explicite.
- macOS 13+ propose des DMG distincts pour Apple Silicon et Intel, signés avec l'Apple Developer ID de Kavor et
  notariés par Apple. Les mises à jour automatiques utilisent le ZIP correspondant à l'architecture et conservent le
  DMG comme solution manuelle.
- Linux x64 propose des paquets AppImage et DEB. AppImage prend en charge les mises à jour gérées par Kavor avec un
  redémarrage coordonné explicite ; les mises à jour DEB sont installées manuellement depuis la page de téléchargement.

## Limitations connues

- Le Browser Profile dédié et partagé de Kavor accepte tout certificat de serveur afin de faciliter le développement
  local. Un réseau hostile peut donc usurper les sites ouverts dans ce profil, y compris ceux auxquels l'utilisateur
  se connecte. La session de l'application Kavor conserve la validation normale des certificats de Chromium.
- Les Nodes WebBrowser ne réutilisent pas le profil, les extensions, l'historique ni les cookies du Chrome externe de
  l'utilisateur. Supprimer un Node n'efface pas les données de site partagées ; les paramètres globaux de Kavor
  permettent d'effacer explicitement cache, cookies et données de site.
- Le contrôle par CodingAgent exige que le Node WebBrowser soit actif sur le Canvas. Les frames intersites isolées
  dans un autre processus Chromium sont signalées comme omises et ne peuvent pas être contrôlées à travers la
  frontière de sécurité du guest.
- Les paquets Windows ARM64 et Linux ARM64 ne sont pas inclus tant que leurs gates natifs PTY, SQLite, de confinement
  des processus et de runtime empaqueté ne peuvent pas s'exécuter dans des environnements CI correspondants.
- Les téléchargements Windows directs ne disposent pas encore d'un certificat de publisher Authenticode ; les
  paquets Microsoft Store sont signés par Microsoft. Leur disponibilité dans le Store peut suivre la release stable
  directe après la certification indépendante de Microsoft.
