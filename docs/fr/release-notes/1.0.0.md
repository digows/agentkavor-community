# Kavor 1.0.0

## Points forts

- Coordonne CodingAgents, Terminals, Specifications, Files et Sticky Notes sur un Canvas persistant local-first.
- Relie les Nodes pour accorder des capacités explicites tout en gardant Guardrails et revue humaine.
- Laisse les CodingAgents proposer des changements atomiques, puis les localiser, réviser, appliquer ou refuser dans le Header.
- Échange des messages durables entre CodingAgents et expose le catalogue révisé via la bridge MCP locale.
- Conserve Workspace, Canvas, Terminal et sessions provider entre redémarrages, avec les données sur la machine.
- Signale les updates avec repli manuel permanent sur <https://download.agentkavor.com>.

## Correctifs

- Améliore pan/zoom en adaptant le rendu riche à l'échelle de la viewport.
- Conserve état et compteurs Terminal indépendamment des optimisations de visibilité.
- Renforce démarrage PTY, confinement, nettoyage et runtime empaqueté sur les plateformes prises en charge.
- Rend les propositions Node/Connection atomiques avec une décision humaine et rollback commun.
- Ajoute Analytics anonyme borné et Performance optionnelle sans contenu, chemins, prompts, commandes, output ni identité.

## Installation

Téléchargez Kavor sur <https://download.agentkavor.com>. Windows x64 : NSIS initial non signé. macOS 13+ : DMG
arm64/x64 ad-hoc non notariés, update manuel. Linux x64 : AppImage avec update et DEB manuel.

## Limites connues

- Windows ARM64/Linux ARM64 attendent leurs gates natifs ; Windows Authenticode ; macOS Developer ID/notarisation.
- Microsoft Store ne fait pas partie de cette version.
