# Kavor 1.0.1

## Points forts

- Récupère les outils natifs sans quitter le Workspace : guide l'installation de Git/providers, affiche progression
  et erreurs exploitables, puis rafraîchit la détection sans redémarrage.
- Propose `Auto`, `Full` et `Reduced` ; `Auto` préserve le feedback et réduit les effets lorsque l'OS le demande ou que
  Chromium rend par logiciel.
- Gère les updates dans Settings avec un état unique, check explicite et repli manuel ; les badges restent visibles
  pendant le téléchargement et jusqu'à l'installation.
- Affiche en option dans les notifications un aperçu texte borné de la dernière réponse si le provider le fournit ;
  un réglage de confidentialité peut le masquer sur l'écran verrouillé.
- Démarre, arrête, redémarre et configure un CodingAgent depuis son Node ; le renommage synchronise la session native.
- Allège fortement les paquets en retirant locales, artefacts, source maps, tests et binaires inutiles sans retirer le runtime.

## Correctifs

- Revoit la livraison d'output avec backpressure borné, batches ordonnés, acknowledgements par attachment et checkpoints finaux.
- Améliore la présentation pendant pan, zoom, remount et startup ; les PTY restent hors du compositeur zoomé et attendent le checkpoint.
- Empêche décorations transparentes et Locate d'occulter les portals Terminal/CodingAgent.
- Corrige placement et drag à tout zoom, même si la viewport change sous un pointeur immobile.
- Écarte les résultats Git périmés, limite les contrôles aux dépôts valides et partage discovery/scans concurrents.
- Rend atomique le refresh d'outils entre Electron main et Process Host avec un nouveau `PATH`.
- Renforce Windows pour hooks PowerShell, environnement, Git utilisateur, `winget` et Job Objects concurrents.
- Améliore la récupération CodingAgent : installer, retry, installation manuelle, nouvelle détection et erreurs explicites.
- Isole et borne l'activité asynchrone par session ; Antigravity rejette les previews anciens ou sans rapport.
- Garde le Terminal Node si le teardown échoue et ferme le processus avant le Node en cas de succès.
- Sépare les révisions Sticky Note des mouvements et resize concurrents.
- Empêche checks concurrents et état initial ancien de remplacer disponibilité, téléchargement ou erreur récents.
- Fluidifie Authentication, onboarding, activation et startup, sans flash ni scène vide.
- Isole complètement les profils développement et production : SQLite, secrets, fenêtre, cookies, cache et storage.
- Ferme les connexions Codex app-server oisives après la dernière session.
- Rend Analytics anonyme de startup résilient aux reloads et pannes réseau, en laissant Analytics détaillé/Performance
  au choix de l'utilisateur et en excluant contenu, prompts, commandes, chemins, output et identité.

## Installation

Téléchargez Kavor sur <https://download.agentkavor.com>. Windows x64 : NSIS non signé. macOS 13+ : DMG arm64/x64
ad-hoc non notariés, update manuel. Linux x64 : AppImage avec update et DEB manuel.

## Limites connues

- Windows ARM64/Linux ARM64 attendent leurs gates natifs ; Windows Authenticode ; macOS Developer ID/notarisation.
- Microsoft Store ne fait pas partie de cette version.
