# Kavor 1.5.0

## Nouveautés

- Publie Kavor dans le Microsoft Store pour Windows en complément du téléchargement NSIS direct. Microsoft signe et
  distribue le package Store et gère les mises à jour des installations issues de ce canal.
- Signe les deux architectures macOS avec Apple Developer ID et les fait notarier par Apple. Gatekeeper peut
  désormais vérifier l'éditeur Kavor et le ticket de notarisation sans afficher le parcours initial de développeur
  non identifié.
- Ajoute un sélecteur de répertoire de travail à chaque CodingAgent. Une session peut démarrer dans tout répertoire
  existant choisi par l'utilisateur, y compris hors du Workspace, tout en conservant son association Git et worktree
  indépendante.
- Permet aux CodingAgents connectés de lire passivement les tours terminés de la session provider courante d'un peer
  accessible. L'historique est paginé par curseur et sa lecture n'envoie aucune entrée au provider, n'active pas le
  peer et ne crée pas de message Kavor.
- Améliore la transmission du contexte des Kavor Skills : les instructions de création d'une Specification sont
  disponibles avant sa connexion, et les Triggers reçoivent directement leur contexte opérationnel pertinent.

## Corrections

- Préserve les longs messages complets des sessions CodingAgent entre les pages d'historique limitées au lieu de
  tronquer le texte restant.
- Détecte les changements de session provider pendant une lecture passive et rejette la continuation obsolète au
  lieu de combiner des fragments de sessions différentes.
- Valide les sessions Codex avant leur reprise et remplace une session courante archivée à l'extérieur sans perdre
  son historique provider restaurable.
- Lit l'historique Antigravity terminé sur plusieurs pages provider et harmonise l'historique passif pour Claude
  Code, Codex, Antigravity, OpenCode et Grok.
- Maintient les longs arguments de démarrage et les chemins de répertoire sélectionnés dans les limites du panneau
  de paramètres du CodingAgent.

## Installation

Téléchargez Kavor depuis <https://download.agentkavor.com>. La page détecte la plateforme actuelle et présente aussi
tous les packages disponibles. Les installations directes existantes peuvent rechercher cette version dans les
paramètres Software Update. Aucune migration manuelle des données du Workspace n'est requise ; Kavor sauvegarde les
bases locales prises en charge avant les mises à jour de schéma.

- Windows x64 est disponible dans le Microsoft Store ou via l'installateur NSIS assisté par utilisateur. Microsoft
  signe et met à jour les installations Store. L'installateur direct reste non signé ; Microsoft SmartScreen peut
  donc demander une confirmation explicite.
- macOS 13+ fournit des DMG distincts pour Apple Silicon et Intel, signés avec l'Apple Developer ID de Kavor et
  notariés par Apple. Cette version remplace l'ancienne identité ad-hoc par l'identité Developer ID stable. Si macOS
  refuse la transition automatique depuis une ancienne version, installez manuellement le DMG correspondant depuis
  la page de téléchargement permanente ; les données Kavor existantes sont conservées.
- Linux x64 fournit des packages AppImage et DEB. AppImage prend en charge les mises à jour gérées par Kavor avec un
  redémarrage coordonné explicite ; les mises à jour DEB s'installent manuellement depuis la page de téléchargement.

## Limitations connues

- Les Triggers Schedule exigent que le runtime Kavor fonctionne, que la machine soit éveillée, que l'utilisateur soit
  connecté et que la session cible soit active. Une occurrence manquée est enregistrée et proposée comme exécution
  manuelle explicite ; elle ne s'exécute jamais automatiquement au prochain démarrage.
- Les packages Windows ARM64 et Linux ARM64 ne sont pas inclus tant que leurs validations natives PTY, SQLite,
  confinement des processus et runtime packagé ne peuvent pas s'exécuter sur des environnements CI correspondants.
- Les téléchargements Windows directs n'ont pas encore de certificat éditeur Authenticode ; Microsoft signe les
  packages du Microsoft Store.
- La première migration d'un build macOS ad-hoc vers le build signé Developer ID peut nécessiter une installation
  manuelle du DMG ou une autorisation Keychain pour `Kavor Safe Storage`. Les versions signées suivantes conservent la
  même identité Apple Team.
- Le Microsoft Store peut rendre cette version exacte disponible après sa certification indépendante ; les packages
  directs stable restent immédiatement disponibles sur la page de téléchargement de Kavor.
