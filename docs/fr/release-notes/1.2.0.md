# Kavor 1.2.0

## Points forts

- Ajoute aux File Nodes des aperçus riches pour les images et PDF. Les PDF volumineux ne rendent que les pages
  visibles ; des limites d'image, de Canvas et de fichier protègent le Workspace d'une mémoire non bornée.
- Achève le cycle de vie des Files et Specifications : création depuis le menu Canvas, renommage, suppression,
  organisation en dossiers et synchronisation des Nodes avec le système de fichiers.
- Permet de déposer les chemins du panneau Files dans un Terminal ou CodingAgent avec un quoting adapté au shell actif.
- Étend les propositions atomiques avec création de Specifications, progression persistée et récupération des effets
  réversibles sur Files et Specifications.
- Chaque Kavor Skill indique désormais l'appel exact `kavor.skill.get("<name>")` utilisé pour la charger.

## Correctifs

- Préserve champs, commentaires et ordre du frontmatter YAML, noms et chemins relatifs lors de l'édition de Specifications.
- Stabilise l'hydratation Terminal/CodingAgent : un état PTY tardif ne perd plus le contenu restauré et ne duplique pas
  l'ownership lors d'un changement de Workspace.
- Conserve les ajouts de Sticky Notes comme blocs Markdown distincts, ignore les ajouts vides et compte en code points Unicode.
- Sécurise les mutations File/Specification par sérialisation, confinement des chemins, invalidation et erreurs explicites.
- Corrige les avis de sécurité du précédent graphe de dépendances de production.

## Installation

Téléchargez Kavor sur <https://download.agentkavor.com>. Windows x64 utilise NSIS sans signature. macOS 13+ fournit des
DMG arm64/x64 signés ad-hoc mais non notariés et des mises à jour par ZIP revalidé. Linux x64 fournit AppImage avec mise
à jour et DEB manuel. Le téléchargement manuel reste toujours disponible.

## Limites connues

- Windows ARM64 et Linux ARM64 attendent des gates CI natifs PTY, SQLite, confinement et runtime empaqueté.
- Les téléchargements Windows n'ont pas encore de certificat Authenticode.
- macOS n'a pas encore de Developer ID ni de notarisation ; Gatekeeper et Keychain peuvent demander confirmation.
- Microsoft Store ne fait pas partie de cette version.
