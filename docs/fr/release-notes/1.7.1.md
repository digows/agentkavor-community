# Kavor 1.7.1

## Nouveautés

- Met à jour Electron, Chromium, React, les outils UI et les dépendances de runtime vers des versions stables
  compatibles. Ce hotfix conserve les workflows Canvas et CodingAgent existants sans exposer d'interfaces expérimentales.

## Corrections

- Rétablit les entrées natives de la souris et du clavier dans WebBrowser après un changement de Workspace, sans
  recharger la page conservée active ni bloquer les commandes interactives du navigateur.
- Efface l'état de popup de la page d'origine lorsqu'un popup WebBrowser se ferme, retire son cadre et permet
  l'ouverture des popups suivants sans effacer un popup qui l'aurait remplacé.
- Corrige les couleurs Markdown en mode de lecture clair, notamment les titres, liens, code, citations et tableaux.
  Le passage entre les modes de lecture clair et sombre applique désormais un style cohérent aux vues compacte et normale.
- Préserve la précision à la minute des horaires des Triggers à exécution unique après la mise à jour des dépendances.
- Traite les chemins surveillés du Workspace littéralement, sans développer la syntaxe glob, tout en préservant la
  détection récursive des nouveaux répertoires.
- Rétablit la compatibilité avec l'exécutable natif de pnpm pour compiler les packages du Workspace, recompiler les
  dépendances natives et générer les notices de tiers incluses dans l'application empaquetée.
- Met à jour les dépendances gRPC et FTP concernées et préserve le contrat révisé des schemas de tools de CodingAgent.

## Installation

Téléchargez Kavor depuis <https://download.agentkavor.com>. Les installations directes existantes peuvent rechercher
cette version dans les paramètres Software Update. Aucune migration manuelle des données du Workspace n'est nécessaire.

- Windows x64 est disponible dans Microsoft Store ou via l'installateur NSIS assisté par utilisateur. Microsoft signe
  et met à jour les installations Store. L'installateur direct reste non signé ; Microsoft SmartScreen peut donc
  demander une confirmation explicite.
- macOS 13+ propose des DMG distincts pour Apple Silicon et Intel, signés avec l'Apple Developer ID de Kavor et
  notarisés par Apple. Les mises à jour automatiques utilisent le ZIP correspondant à l'architecture et conservent
  le DMG comme solution manuelle.
- Linux x64 propose AppImage et DEB. AppImage prend en charge les mises à jour gérées par Kavor avec un redémarrage
  coordonné explicite ; les mises à jour DEB s'installent manuellement depuis la page de téléchargement.

## Limitations connues

- Un avis de sécurité concernant la dépendance upstream `braces` reste sans correctif publié. La surveillance
  récursive du Workspace désactive désormais l'expansion glob ; il s'agit d'une atténuation, pas d'une dépendance corrigée.
- Le Browser Profile dédié et partagé de Kavor accepte tous les certificats serveur pour permettre le développement
  local. Un réseau hostile peut donc usurper les sites ouverts dans ce profil, y compris ceux auxquels l'utilisateur
  se connecte. La session de l'application Kavor conserve la vérification normale des certificats de Chromium.
- Les Nodes WebBrowser ne réutilisent pas le profil, les extensions, l'historique ni les cookies du Chrome externe
  de l'utilisateur. Supprimer un Node n'efface pas les données partagées des sites ; les paramètres globaux de Kavor
  permettent de vider explicitement le cache, les cookies et les données des sites.
- Les frames intersites isolées dans un autre processus Chromium sont signalées comme omises et ne peuvent pas être
  contrôlées à travers la frontière de sécurité du guest.
- Les packages Windows ARM64 et Linux ARM64 ne sont pas inclus tant que leurs gates natifs PTY, SQLite, de confinement
  des processus et de runtime empaqueté ne peuvent pas s'exécuter dans des environnements CI correspondants.
- Les téléchargements directs Windows n'ont pas encore de certificat d'éditeur Authenticode ; Microsoft signe les
  packages Microsoft Store. La disponibilité dans Store peut suivre la release stable directe après la certification
  indépendante de Microsoft.
