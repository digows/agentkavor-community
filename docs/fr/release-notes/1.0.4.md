# Kavor 1.0.4

## Points forts

- Ajoute les mises à jour Kavor à macOS arm64/x64 avec ZIP par architecture, blockmaps différentiels et canal stable consolidé.
- Garde le DMG pour le téléchargement humain tandis que l'updater choisit le ZIP, télécharge et installe lors de la fermeture coordonnée.
- Conserve <https://download.agentkavor.com> comme repli permanent sur chaque plateforme et pour toute panne.

## Correctifs

- Corrige le contrat macOS qui activait l'updater sans publier ZIP et `latest-mac.yml` requis par Electron Updater.
- Empêche un job d'écraser les métadonnées de l'autre architecture en validant chaque ZIP puis en consolidant les deux.
- Ajoute SHA-256 immuable pour ZIP et blockmaps, vérification exacte avant promotion et gates natifs des métadonnées.
- Renomme l'ancienne configuration initiale selon le contrat actuel de distribution directe.

## Installation

Téléchargez Kavor sur <https://download.agentkavor.com>. Windows x64 utilise NSIS non signé. macOS 13+ fournit des DMG
arm64/x64 ad-hoc non notariés ; après cette version, les releases acceptées peuvent s'installer à la fermeture normale.
Linux x64 fournit AppImage avec update et DEB manuel. Le téléchargement manuel reste disponible.

## Limites connues

- Windows ARM64/Linux ARM64 attendent leurs gates natifs ; Windows attend Authenticode ; macOS Developer ID/notarisation.
- Gatekeeper ou Keychain peuvent demander confirmation sur macOS.
- Microsoft Store ne fait pas partie de cette version.
