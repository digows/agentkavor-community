# Kavor 1.0.3

## Points forts

- Restaure Terminal/CodingAgent empaquetés sur macOS avec Electron Helper pour la bridge et Job Object seulement sous Windows.
- Rend leur présentation résiliente au pan, zoom, remount et startup ; l'output apparaît après le checkpoint sans perdre la session.
- Ajoute les canaux stable et prerelease, stable par défaut et prerelease en opt-in hors des données Workspace.
- Inclut une identité de build vérifiable et renforce les validations natives avant stable.

## Correctifs

- Évite l'échec du Process Host avant handshake sur macOS/Linux lorsque Job Object et `koffi` Windows sont absents.
- Corrige le runtime de bridge macOS afin que l'exécutable n'écarte plus le point d'entrée Node en arrière-plan.
- Ajoute un gate qui attend le handshake et vérifie le runtime par plateforme sans masquer un crash en timeout.
- Revoit hydratation PTY et ownership pour préserver output, readiness, acknowledgements, focus et contrôles entre couches.
- Retire l'état de présentation persistant et migre les bases vers les ressources vivantes.
- Améliore startup, restart, worktree, disponibilité et récupération des CodingAgents.
- Borne Antigravity à la requête terminée et accepte les variantes prises en charge sans réponse périmée.
- Empêche les vieux checks de remplacer le nouvel état, conserve les détails après reload et ajoute l'icône aux notifications.
- Améliore placement, Connections, transitions, startup, Settings, Git, Specifications et présentation des Nodes.
- Tolère les écritures Chromium transitoires dans le canary, évitant un échec sur `ENOTEMPTY` temporaire.
- Simplifie la CI : diagnostic manuel d'une plateforme, tag pour la matrice et stable à 100 % avec pause réversible.

## Installation

Téléchargez Kavor sur <https://download.agentkavor.com>. Windows x64 : NSIS non signé. macOS 13+ : DMG arm64/x64
ad-hoc non notariés, update manuel. Linux x64 : AppImage avec update et DEB manuel.

## Limites connues

- Windows ARM64/Linux ARM64 attendent leurs gates natifs ; Windows Authenticode ; macOS Developer ID/notarisation.
- Microsoft Store ne fait pas partie de cette version.
