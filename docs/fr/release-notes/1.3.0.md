# Kavor 1.3.0

## Points forts

- Ajoute des Trigger Nodes de type Schedule pour les travaux ponctuels et récurrents. Connectez un Trigger à un
  CodingAgent ou Terminal, prévisualisez les prochaines occurrences dans le fuseau enregistré, suspendez ou reprenez
  immédiatement, exécutez à la demande et consultez un historique durable des résultats manqués, bloqués, échoués et
  terminés.
- Ajoute des fenêtres Workspace indépendantes reposant sur un runtime partagé. Ouvrez plusieurs Workspaces côte à
  côte, restaurez la session de fenêtres précédente, isolez les sessions Terminal et CodingAgent par Workspace et,
  si vous le souhaitez, gardez Kavor dans la zone de notification et lancez-le en arrière-plan à la connexion.
- Remplace la file de propositions du Canvas par l'édition atomique directe des CodingAgents autorisés. Un lot validé
  de changements de Nodes, Connections, Files et Specifications est désormais validé en une opération ou entièrement
  annulé.
- Fait du graphe connecté la frontière de contexte partagé des CodingAgents. Les agents accessibles peuvent échanger
  des messages durables et inspectables, tandis que les Guardrails des Connections directes continuent à restreindre
  chaque paire de ressources concernée.
- Ajoute une recherche bornée des fichiers du Workspace avec le binaire ripgrep inclus, des aperçus enrichis pour les
  liens de fichiers et la documentation officielle de Kavor dans le catalogue MCP local.
- Unifie le statut des CodingAgents, Specifications et Triggers dans le Header du Workspace et ajoute une fenêtre À
  propos avec version installée, provenance du build, mise à jour, support, sécurité et informations juridiques.

## Correctifs

- Dirige l'activation d'une notification native vers la fenêtre existante qui possède le Workspace concerné, sans
  créer de doublon ni basculer une fenêtre sans rapport.
- Stabilise la découverte de l'environnement des providers, le démarrage des CodingAgents, les diagnostics du PTY
  Host, la récupération des Terminals et la présentation PTY lors de l'ouverture, fermeture, restauration ou bascule
  de plusieurs fenêtres Workspace.
- Préserve les signaux d'achèvement et d'attention des CodingAgents en arrière-plan pendant les changements de
  Workspace et n'envoie une notification native que lorsque le travail concerné n'est pas déjà visible.
- Sérialise les messages CodingAgent en attente et les livraisons de Triggers afin qu'ils n'écrasent pas la saisie
  humaine et ne dépassent pas le travail déjà accepté par la session cible.
- Diffère le renommage de session du provider lorsque Claude Code est temporairement indisponible, au lieu de faire
  échouer une session encore utilisable.
- Contient les erreurs de suivi d'écran du Terminal et affiche les véritables échecs de démarrage du host sans les
  masquer par un timeout générique.

## Installation

Téléchargez Kavor sur <https://download.agentkavor.com>. La page détecte la plateforme actuelle et présente aussi
tous les paquets disponibles. Les installations directes existantes peuvent rechercher cette version dans Software
Update. Aucune migration manuelle des données Workspace n'est nécessaire ; Kavor sauvegarde les bases locales prises
en charge avant les mises à niveau du schema.

- Windows x64 utilise l'installateur NSIS assisté par utilisateur. Il n'est pas encore signé ; Microsoft SmartScreen
  peut demander une confirmation explicite.
- macOS 13+ fournit des DMG séparés arm64 et x64. Les builds sont signés ad-hoc mais non notariés ; suivez les
  instructions Gatekeeper. Les mises à jour gérées utilisent le ZIP correspondant à l'architecture et proposent un
  redémarrage coordonné après revalidation. Le téléchargement manuel reste toujours disponible.
- Linux x64 fournit AppImage et DEB. AppImage accepte les mises à jour gérées avec redémarrage explicite ; DEB est
  remplacé manuellement depuis la page de téléchargement.

## Limites connues

- Les Triggers Schedule exigent que le runtime Kavor soit actif, que la machine soit éveillée, que l'utilisateur soit
  connecté et que la session cible soit active. Une occurrence manquée lorsque Kavor était arrêté est enregistrée et
  proposée comme exécution manuelle explicite ; elle ne s'exécute jamais automatiquement au prochain lancement.
- Windows ARM64 et Linux ARM64 attendent des gates CI natifs pour PTY, SQLite, le confinement des processus et le
  runtime empaqueté.
- Les téléchargements Windows n'ont pas encore de certificat Authenticode.
- macOS n'a pas encore de signature Developer ID ni de notarisation. Gatekeeper peut demander une confirmation et le
  remplacement d'un build ad-hoc peut redemander l'accès à `Kavor Safe Storage` dans Keychain.
- Microsoft Store ne fait pas partie de cette version.
