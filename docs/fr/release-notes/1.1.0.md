# Kavor 1.1.0

## Points forts

- Remplace dans les nouveaux paquets le protocole privé de connexion par un callback bref `127.0.0.1` lié à la
  tentative. Google, GitHub et l'e-mail sans mot de passe reviennent directement dans Kavor via le navigateur, avec
  PKCE pour les providers et un repli explicite par presse-papiers.
- Ajoute le consentement légal à la première Authentication et place la synchronisation du compte derrière l'API
  publique versionnée de Kavor.
- Permet aux CodingAgents de proposer File et Specification Nodes via le catalogue atomique du Canvas. Les Connection
  Skills commencent par les règles applicables et le contexte Git-aware.
- Améliore présentation, changement de Workspace, démarrage et récupération des Terminals/CodingAgents sous activité PTY.
- Simplifie navigation et actions des Specifications en gardant l'accès direct aux Files depuis le Workspace.

## Correctifs

- Corrige les échanges Google Desktop et GitHub confidentiel server-side pour un loopback direct sans embarquer les secrets GitHub.
- Retire le protocole privé des nouveaux paquets, évite les handlers Linux défaillants et maintient les routes de compatibilité.
- Protège les callbacks contre les tentatives anciennes, répétées, invalides ou incompatibles et exclut secrets et réponses du stockage et des logs.
- Corrige hydratation PTY et ownership pendant les changements de Workspace, y compris les handshakes retardés, sans inventer de sorties.
- Réduit le travail Canvas/panneaux autour des Terminal, CodingAgent, File et Specification Nodes et clarifie les actions.
- Fait passer la découverte des releases par l'API stable de téléchargement de Kavor plutôt que par l'hôte de releases.

## Installation

Téléchargez Kavor sur <https://download.agentkavor.com>. Windows x64 utilise NSIS sans signature ; macOS 13+ fournit des
DMG arm64/x64 ad-hoc non notariés avec mise à jour ZIP revalidée ; Linux x64 fournit AppImage et DEB manuel.

## Limites connues

- Les versions jusqu'à 1.0.6 ne peuvent plus ouvrir une nouvelle connexion GitHub, l'ancien OAuth App ayant été retiré.
  Les sessions existantes restent valides ; installez 1.1.0 pour vous reconnecter.
- Windows ARM64 et Linux ARM64 attendent leurs gates natifs.
- Windows n'a pas encore Authenticode ; macOS n'a pas Developer ID ni notarisation.
- Microsoft Store ne fait pas partie de cette version.
