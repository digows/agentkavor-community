# Kavor 1.7.0

## Points forts

- Ajoute le copier, couper et coller des sous-graphes sélectionnés du Canvas à l'aide des raccourcis clavier standard
  et des menus contextuels. Le transfert peut rester dans un Canvas ou traverser des Workspaces et des fenêtres tout
  en préservant les Nodes compatibles, les Connections internes, leur placement et les actions annuler ou rétablir.
- Maintient les pages WebBrowser actives lorsque la personne change de Workspace, conserve leur état et permet à un
  CodingAgent connecté de poursuivre son travail dans le navigateur. Le retour au Workspace présente la même page
  active sans la recharger.
- Colle les fichiers du presse-papiers du système et les images PNG ou JPEG dans Terminal et CodingAgent sous forme de
  références de fichiers sûres pour le shell. Les images copiées sont matérialisées de manière privée dans le profil
  local de l'application Kavor.

## Correctifs

- Restaure à chaque démarrage de l'application les cibles Terminal et CodingAgent ouvertes appartenant aux Triggers
  actifs, afin que les tâches planifiées ne dépendent plus d'un démarrage explicite de Kavor en arrière-plan.
- Affine les instructions Sticky Note afin qu'un CodingAgent ne réécrive pas de façon proactive le contenu de
  l'utilisateur ou d'un autre agent et ne mette à jour que ses propres entrées clairement identifiées lorsqu'il y est
  autorisé.
- Met à jour Electron, Chromium, les outils de bureau et les dépendances d'exécution vers leurs dernières versions
  stables compatibles, en ne conservant que les binaires natifs nécessaires à chaque plateforme empaquetée.

## Installation

Téléchargez Kavor sur <https://download.agentkavor.com>. La page détecte la plateforme actuelle et affiche également
tous les paquets disponibles. Les installations directes existantes peuvent rechercher cette version dans les
paramètres Software Update de Kavor. Aucune migration manuelle des données du Workspace n'est nécessaire.

- Windows x64 est disponible dans le Microsoft Store ou via l'installateur NSIS assisté par utilisateur. Microsoft
  signe et met à jour les installations du Store. L'installateur direct reste non signé ; Microsoft SmartScreen peut
  donc demander une confirmation explicite.
- macOS 13+ propose des DMG distincts pour Apple Silicon et Intel, signés avec l'Apple Developer ID de Kavor et
  notariés par Apple. Les mises à jour automatiques utilisent le ZIP correspondant à l'architecture et conservent le
  DMG comme solution manuelle.
- Linux x64 propose des paquets AppImage et DEB. AppImage prend en charge les mises à jour gérées par Kavor avec un
  redémarrage coordonné explicite ; les mises à jour DEB sont installées manuellement depuis la page de téléchargement.

## Limites connues

- Le presse-papiers de graphe du Canvas est local au processus. Une copie ou une coupe peut traverser des Workspaces
  et des fenêtres Kavor, mais ne survit pas au redémarrage de l'application et ne copie ni fichiers physiques,
  sessions de fournisseur, ni historique d'exécution.
- Le Browser Profile dédié et partagé de Kavor accepte tous les certificats de serveur pour prendre en charge le
  développement local. Un réseau hostile peut donc usurper les sites ouverts dans ce profil, y compris ceux auxquels
  l'utilisateur se connecte. La session de l'application Kavor conserve la validation normale de Chromium.
- Les Nodes WebBrowser ne réutilisent pas le profil Chrome externe, ses extensions, son historique ou ses cookies.
  Supprimer un Node n'efface pas les données de site partagées ; les paramètres globaux de Kavor permettent de vider
  explicitement le cache, les cookies et les données de site.
- Les frames intersites isolées dans un autre processus Chromium sont signalées comme omises et ne peuvent pas être
  contrôlées via la frontière de sécurité du guest.
- Les paquets Windows ARM64 et Linux ARM64 ne sont pas inclus tant que leurs gates natifs PTY, SQLite, confinement de
  processus et runtime empaqueté ne peuvent pas s'exécuter dans des environnements CI correspondants.
- Les téléchargements directs Windows ne disposent pas encore d'un certificat d'éditeur Authenticode ; les paquets
  Microsoft Store sont signés par Microsoft. Leur disponibilité dans le Store peut suivre la version stable directe
  après la certification indépendante de Microsoft.
