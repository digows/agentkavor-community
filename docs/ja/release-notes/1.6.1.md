# Kavor 1.6.1

## ハイライト

- オプションを有効にすると、プレリリース更新の確認で Kavor の公開 prerelease チャネルが直ちに使用されます。
  手動確認では stable と prerelease のマニフェストを比較し、利用可能な最新バージョンを選択します。
- WebBrowser Node の chrome を改善し、安定した高めの header、読みやすいアドレス欄、ページの viewport を
  動かさず header 内に留まる読み込みインジケーターを提供します。

## 修正

- ナビゲーションの開始または終了時に WebBrowser の内容が移動したりサイズ変更されたりする問題を修正しました。
- Canvas ツールバーの Terminal アイコンに意図した高いコントラストを復元しました。
- Workspace 設定の折りたたみ可能なセクションで一貫したアイコンを使用します。
- 完了した Store rollout を次のパッケージ送信前に確実に終了させるよう、直接更新の配信と Microsoft Store
  への提出順序を強化しました。

## インストール

Kavor は <https://download.agentkavor.com> からダウンロードできます。ページは現在のプラットフォームを検出し、
すべての利用可能なパッケージも表示します。既存の直接インストールでは Kavor の Software Update 設定からこの
バージョンを確認できます。Workspace データの手動移行は不要です。

- Windows x64 は Microsoft Store、またはユーザー単位の NSIS インストーラーで利用できます。Store 版は
  Microsoft が署名および更新します。直接インストーラーは未署名のため、Microsoft SmartScreen で明示的な確認が
  必要になる場合があります。
- macOS 13+ では Apple Silicon と Intel 向けに別々の DMG を提供し、Kavor の Apple Developer ID で署名して
  Apple の公証を受けています。自動更新は対応するアーキテクチャの ZIP を使用し、手動用の DMG も維持します。
- Linux x64 では AppImage と DEB を提供します。AppImage は明示的に調整された再起動による Kavor 管理更新を
  サポートし、DEB はダウンロードページから手動で更新します。

## 既知の制限事項

- WebBrowser Nodes は Kavor 専用の共有 Browser Profile を使用し、ユーザーの外部 Chrome の profile、拡張機能、
  履歴、Cookie は再利用しません。Node を削除しても共有サイトデータは消去されません。Kavor のグローバル設定で
  キャッシュ、Cookie、サイトデータを明示的に消去できます。
- CodingAgent による操作には WebBrowser Node が Canvas 上で稼働している必要があります。別の Chromium
  プロセスに分離されたクロスサイト frame は省略として報告され、guest セキュリティ境界を越えて操作できません。
- Windows ARM64 と Linux ARM64 のパッケージは、ネイティブ PTY、SQLite、プロセス封じ込め、パッケージ済み
  runtime の gate を対応する CI 環境で実行できるようになるまで提供されません。
- Windows の直接ダウンロードには Authenticode publisher 証明書がまだありません。Microsoft Store
  パッケージは Microsoft が署名します。Store での提供は Microsoft の独立した認証後になる場合があります。
