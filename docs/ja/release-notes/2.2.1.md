# Kavor 2.2.1

## 修正

- CodingAgent で設定した場合も Workspace から継承した場合も、実効モードが **Manual** なら、ターン完了時に
  ローテーション用の容量を照会しません。表示中の使用量の読み取りと **Refresh** は引き続き利用できます。
- **Automatic** は、元の 30 秒間の期限内で同じアカウントの最近の読み取りを Workspaces 間で再利用します。
  期限切れ、利用枠の更新、認証または quota の失敗確認に伴う再評価を遅らせません。
- アカウント名の表示や、Agent Kavor コマンドで既知の名前・識別情報を解決する際の不要な使用量照会をなくします。
  未知の識別情報には照会が必要な場合があります。
- メモリ内に読み取りがないアカウントの手動更新で、初回照会が重複する問題を修正します。

ローテーションは引き続き予防的で、既定のしきい値は**使用済み容量 95%** です。参加設定、モデル、支出権限の規則は
変わりません。アカウントの切り替えも、ターン間の安全な境界とセッションの継続性を維持します。

Manual、Automatic、読み取り時刻については [CodingAgent Accounts](../coding-agent-accounts.md) を参照してください。

## 更新

<https://download.agentkavor.com> から Kavor をダウンロードするか、Software Update 設定で更新を確認してください。
利用上限、認証、サービスの可用性は引き続き providers が管理します。
