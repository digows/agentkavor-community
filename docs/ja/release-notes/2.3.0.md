# Kavor 2.3.0

## 主な変更

- **Canvas のダイアグラム：**Mermaid、C4 を含む PlantUML、Graphviz、D2、Excalidraw、draw.io など、13 の形式
  ファミリーのファイルに対応します。Diagram、Source、Split を切り替え、描画エラーを確認し、SVG または PNG に
  書き出せます。Excalidraw は視覚的に編集でき、draw.io は Kavor 内では表示専用です。
- **ファイルシステムで整理するドキュメント：**Specifications と Diagrams は Documentation roots を共有します。
  最初のルートからの相対位置として Diagrams folder を設定し、実際のフォルダーツリーを参照し、toolbar または
  インラインフォームから作成できます。既定の場所は引き続き `docs/diagrams/` で、変更しても既存ファイルは移動しません。
- **コンテキストを追加する方法の拡充：**システムのファイルを Canvas にドラッグするほか、ファイル、画像データ、単独の
  URL、テキストを貼り付けられます。ファイルは元の場所に残り、貼り付けた画像は Workspace に PNG として保存されます。
  外部の参照元もディスク上の変更を反映し、リッチプレビューのないファイルには詳細と操作を備えたカードを表示します。

## 修正

- Auto は Workspace で自動選択の対象から外したアカウントを尊重し、Manual の選択を保ちます。対象となる別の
  アカウントが利用できない間は既存セッションを維持し、利用可能な適格アカウントが回復した時点で再検討します。
  対象からの除外が、新しい実行を許可することにはなりません。
- Codex の利用状況の照会は、認証情報が確実に取り消された後に自動で再試行を繰り返さなくなりました。人が開始する
  Refresh からの明示的な復旧は引き続き利用できます。
- 事前起動した Terminals や CodingAgents のセッションを表示するときやズーム変更時の寸法調整を修正しました。
  表示を調整するために作り直すのではなく、ネイティブセッションを維持します。

## インストール

Kavor 内から更新するか、[ダウンロードページ](https://agentkavor.com/downloads)を利用してください。更新機能を
利用できない場合も、[download.agentkavor.com](https://download.agentkavor.com)からパッケージを入手できます。

## 既知の制限

- ダイアグラムのエンジンとリソースは必要に応じて取得します。初回はインターネット接続が必要な場合があります。
  ダウンロード済みのリソースはキャッシュから再利用できますが、外部 URL を参照するコンテンツは引き続きネットワークに
  依存する場合があります。
- draw.io のエディターは Kavor に含まれず、D2 は TALA に対応しません。モデルの利用可否、利用状況の読み取り、
  セッションの再開は、選択した harness の機能と認証状態に依存します。
