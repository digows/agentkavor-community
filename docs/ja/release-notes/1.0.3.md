# Kavor 1.0.3

## ハイライト

- CodingAgent context bridge を専用 Electron Helper で起動し Job Object を Windows だけで読み込み、macOS package の Terminal/CodingAgent を復旧しました。
- pan、zoom、remount、Workspace startup に強い presentation とし、authoritative checkpoint 後に hydrated output を表示して session を維持します。
- stable/prerelease channel を明示し、stable を default、prerelease を Workspace data と独立した opt-in にしました。
- package に検証可能な build identity を含め、stable 前の native validation を強化しました。

## 修正

- Windows-only Job Object と `koffi` がない macOS/Linux で Process Host が handshake 前に失敗する問題を修正しました。
- macOS bridge runtime を修正し main executable が background Node entry point を拒否しないようにしました。
- handshake を待ち platform runtime を検証する startup gate で early crash を timeout として隠しません。
- PTY hydration/ownership を再構築し、layer 間移動でも output、readiness、ack、focus、controls を保ちます。
- persisted presentation status を削除し、live resources から可用性を導出するよう DB を移行しました。
- CodingAgent startup、restart、worktree、resource availability と recovery を改善しました。
- Antigravity extraction を completed request に限定し、古い応答を漏らさず対応 variant を受け入れます。
- old update check による上書きを防ぎ、reload 後の詳細を保持し、OS 通知に Kavor icon を追加しました。
- Canvas placement、Connection guidance、panel、Workspace startup、Settings、Git、Specification、Node presentation を改善しました。
- telemetry canary が一時 Chromium write を許容し、temporary `ENOTEMPTY` だけで release を失敗させません。
- native CI を簡素化し、manual は 1 platform、tag は full matrix、stable は default 100% かつ reversible pause としました。

## インストール

<https://download.agentkavor.com> からダウンロードしてください。Windows x64 は未署名 NSIS、macOS 13+ は
未 notarize DMG と手動 update、Linux x64 は AppImage と手動 DEB です。

## 既知の制限

- Windows ARM64/Linux ARM64 は native gate 待ち、Windows は Authenticode、macOS auto install は Developer ID/notarization 待ちです。
- Microsoft Store 配布は含まれません。
