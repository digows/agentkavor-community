# Kavor 1.7.0

## ハイライト

- 標準のキーボードショートカットとコンテキストメニューで、Canvas 上の選択したサブグラフをコピー、
  カット、ペーストできるようになりました。同じ Canvas 内でも Workspace やウィンドウをまたいでも、
  対応する Nodes、内部 Connections、配置、取り消しとやり直しの動作を維持します。
- ユーザーが Workspace を切り替えてもライブ WebBrowser ページを実行し続け、ページ状態を保持し、接続した
  CodingAgent がブラウザー作業を継続できるようになりました。Workspace に戻ると再読み込みせず同じページを
  表示します。
- OS のクリップボードにあるファイルと PNG または JPEG 画像を、shell で安全なファイル参照として Terminal
  と CodingAgent に貼り付けられます。コピーした画像は Kavor のローカルアプリケーションプロファイル内に
  非公開で保存されます。

## 修正

- 実行中の Triggers が所有する開いた Terminal と CodingAgent の対象をアプリケーション起動のたびに復元し、
  スケジュール処理が Kavor の明示的なバックグラウンド起動に依存しないようにしました。
- Sticky Note のガイダンスを改善し、CodingAgent がユーザーや他の Agent の内容を自発的に書き換えず、許可
  された場合にも自分が明確にラベル付けした項目だけを更新するようにしました。
- Electron、Chromium、デスクトップツールチェーン、ランタイム依存関係を最新の互換安定版へ更新し、各配布
  プラットフォームに必要なネイティブバイナリだけを保持します。

## インストール

<https://download.agentkavor.com> から Kavor をダウンロードしてください。ページは現在のプラットフォームを
検出し、利用可能なすべてのパッケージも表示します。既存の直接インストールは Kavor の Software Update
設定からこのバージョンを確認できます。Workspace データの手動移行は不要です。

- Windows x64 は Microsoft Store またはユーザー単位の NSIS インストーラーで利用できます。Store 版は
  Microsoft が署名して更新します。直接インストーラーは未署名のため、Microsoft SmartScreen が明示的な
  確認を求める場合があります。
- macOS 13+ では Apple Silicon と Intel 用の DMG を個別に提供し、Kavor の Apple Developer ID で署名して
  Apple の公証を受けています。自動更新は対応アーキテクチャの ZIP を使用し、手動 DMG も利用できます。
- Linux x64 では AppImage と DEB を提供します。AppImage は明示的に調整された再起動による Kavor 管理更新
  をサポートし、DEB はダウンロードページから手動で更新します。

## 既知の制限

- Canvas グラフのクリップボードは現在のプロセス内だけに存在します。コピーまたはカットは Workspace や
  Kavor ウィンドウをまたげますが、アプリ再起動後は残らず、実ファイル、Provider セッション、ランタイム履歴
  はコピーしません。
- ローカル開発を支援するため、Kavor 専用の共有 Browser Profile はすべてのサーバー証明書を受け入れます。
  そのため、悪意あるネットワークはユーザーがログインするサイトを含め、このプロファイルで開いたサイトを
  偽装できます。Kavor アプリケーションセッションでは Chromium の通常の証明書検証を維持します。
- WebBrowser Nodes は外部 Chrome のプロファイル、拡張機能、履歴、Cookie を再利用しません。Node を削除
  しても共有サイトデータは消去されません。Kavor のグローバル設定からキャッシュ、Cookie、サイトデータを
  明示的に消去できます。
- 別の Chromium プロセスに分離されたクロスサイト frame は省略として報告され、guest 単位のセキュリティ
  境界から操作できません。
- Windows ARM64 と Linux ARM64 は、対応 CI 環境でネイティブ PTY、SQLite、プロセス封じ込め、パッケージ済み
  runtime の gates を実行できるまで提供しません。
- Windows の直接ダウンロードにはまだ Authenticode 発行者証明書がありません。Microsoft Store パッケージは
  Microsoft が署名します。Store での提供は Microsoft の独立認証により直接 stable release より遅れる場合があります。
