# Kavor 2.4.1

## 主な変更

- **Skip trust prompts：**CodingAgent の Node ごとの起動設定で、既定で有効です。対応する harness は、選択した
  フォルダーやその hooks を信頼するか確認せずに起動します。Startup で無効にすると、次回の起動から反映されます。
  明示的なネイティブ引数が引き続き優先され、ツールの権限と認証は別扱いです。フォルダーを信頼すると、harness が
  プロジェクトの hooks やその他のネイティブ設定を読み込むことも許可されます。
- **Diagrams パネルでの整理：**パネルからフォルダーやファイルを作成し、既存のドキュメントツリー内で整理できます。
  操作を完了できない場合のメッセージもわかりやすくなりました。
- **必要なときに読み込む Canvas コンテンツ：**テキストエディター、言語サポート、Connection Inspector を必要に
  応じて読み込み、従来の編集・確認の動作を維持します。

## 修正

- Canvas 上でのドラッグは、Diagram のプレビュー上を通過しても引き続き機能します。テキストドキュメントを指定した
  行で開くと、その行が初回読み込み時から表示されます。
- Windows での provider の検出とプロセスの起動で、npm の `.cmd` と `.bat` ランチャーに渡した引数を保持します。
  スペースを含むパスや引用符で囲んだ値も保持されます。
- Codex の管理対象アカウントを削除しても、ネイティブのセッションインデックスが使用する履歴の保存場所は保持されます。
  一方、アカウントのローカル認証情報と状態は削除されます。これにより新たな履歴リンク切れを防ぎますが、以前から
  壊れていたリンクは修復しません。
- ACP の初期化では、プロセスのクリーンアップに失敗しても、元の初期化エラーを報告します。
- プロセスホストはランタイムの専用エントリーポイントを使用し、デスクトップパッケージには Claude SDK の未使用の
  エントリーポイント 2 つを含めなくなりました。Kavor が使用する SDK の機能は引き続き利用できます。

## インストール

Kavor 内から更新するか、[download.agentkavor.com](https://download.agentkavor.com) を利用してください。macOS の
パッケージは Developer ID で署名され、Apple の公証を受けています。Windows の直接配布インストーラーは引き続き
未署名で、SmartScreen の警告が表示される場合があります。Microsoft Store は別の配布チャネルで、更新は Store が
管理します。

## 既知の制限

- Skip trust prompts は、認証、ツールの権限、Claude Code のリポジトリ固有の MCP 確認プロンプトを承認しません。
  認識できない信頼確認画面には、引き続きユーザー自身が応答できます。OpenCode はこの設定を必要としません。
- Diagram のエンジンとリソースは必要に応じて取得します。初回の利用時にはインターネット接続が必要な場合があり、
  外部リソースは引き続きネットワーク接続に依存する場合があります。draw.io は引き続き表示専用で、D2 は TALA に
  対応しません。
