# Kavor 2.0.1

## 主な変更

- **結果をあなたのもとへ。** desktop のセッションからでも、Workspace で有効な会話へ要約や結果を送るよう
  CodingAgent に依頼できます。agent が宛先を明示的に選び、先行する WhatsApp メッセージは不要です。受信した依頼への
  返答は、後から Workspace や既定の agent が変わっても元の会話へ戻ります。ターミナル全体の転送や、全グループへの
  自動投稿ではありません。
- **agents に音声を送る。** Kavor は宛先の CodingAgents に依頼を渡す前に自動で文字起こしを準備し、元の録音、
  キャプション、agent の選択を保ちます。音声から生成されたテキストとして示され、誤りを含む場合があります。
  同じ依頼の宛先は全員同じ結果を使います。準備に失敗すると元の会話に案内が届き、待機中の agents には依頼が渡されません。
- **Channels の状態表示をコンパクトに。** 短い通知はコンテキストと本文を一行にまとめ、画面幅に応じて自然に折り返します。
  完全な返答、質問、長い内容は独自の書式を保ちます。

## 修正

- Undo または Redo の実行中に受け付けた Canvas の編集を保持し、先行操作の完了時に新しい履歴を上書きしません。
  途中の編集が入ると、以前の Redo 経路も無効になります。
- **Restart** 後の更新準備を見えるようにし、その段階ではアプリを開いたままにして、ファイルの保存・破棄・キャンセルの
  判断を尊重します。終了をキャンセルした場合や準備に失敗した場合はアプリへ操作を戻します。通常の終了ではインストールを開始しません。
- WhatsApp の Workspace グループの復旧を改善します。**Check group** は連携アカウントからの利用可否を確認し、
  **Remove group link** は確認済みの関連付けだけを解除します。グループ、電話の連携、受理済みの履歴、他の Workspaces は
  保持され、一時的な障害で関連付けが自動消去されることはありません。
- Sticky Note のリストで、書体、マーカーの位置、折り返しを修正します。

## インストール

<https://download.agentkavor.com> から Kavor をダウンロードしてください。既存の直接インストールでは Software Update
設定からこのバージョンを確認できます。Workspace データベースの更新は、バックアップを伴う Kavor の移行フローを使います。

- **Windows x64：** Microsoft Store、またはユーザー操作を伴う NSIS インストーラー。Store 版の署名と更新は Microsoft が
  提供します。直接配布版はまだ発行元署名がないため、SmartScreen が明示的な確認を求める場合があります。
- **macOS 13+：** Apple Silicon と Intel 用の個別の署名・公証済み DMG。自動更新は該当アーキテクチャの ZIP を使い、
  手動インストール用の DMG も引き続き利用できます。
- **Linux x64：** AppImage と DEB。AppImage は明示的な協調再起動を伴う Kavor 管理の更新に対応し、DEB はダウンロード
  ページから手動で更新します。

## 既知の制限

- WhatsApp には連携済みアカウント、ネットワーク、起動して認証済みの Kavor とスリープしていないコンピューターが必要です。
  Meta がホストする WhatsApp Business API ではなく、連携済みデバイスを使います。desktop 上の承認待ちは引き続き人の操作が必要です。
- 音声の文字起こしは認証付きクラウドサービスを使い、完全なオフライン処理ではありません。上限は**音声一件あたり 25 MB
  （25,000,000 バイト）**で、添付ストレージの上限とは別です。音声を Kavor の制御コマンドに変えたり、原本を置き換えたり、
  アップロードから七日間のアクセス期間を延長したりはしません。
- 画像は harness とモデルの対応に依存します。動画は元ファイルを可能な範囲で渡すもので、自動変換やフレーム抽出はなく、
  どの CodingAgent でも解釈できるという保証はありません。
- ポインターがある行に Terminal の OSC 8 リンクが出力された場合、xterm のホバーキャッシュにより、一度別の行へ移動して
  戻るまで開けないことがあります。
- [braces](https://github.com/advisories/GHSA-vfj7-8cjw-p6xm) と
  [sprintf-js](https://github.com/advisories/GHSA-hp3w-g68c-fv3c) の上流のサービス拒否アドバイザリは残っています。
  Workspace の再帰監視は braces を使う経路の glob 展開を無効にしますが、この緩和策は依存関係の修正を意味しません。
- 専用の共有 Browser Profile はローカル開発のため任意のサーバー証明書を受け入れます。悪意あるネットワークは、この
  プロファイルで開いたサイトになりすます可能性があります。アプリ自身のセッションは通常の証明書検証を維持します。
  WebBrowser Nodes は外部 Chrome のプロファイルや拡張を再利用しません。Node を削除しても共有サイトデータは消えないため、
  設定で明示的に消去してください。別プロセスに隔離されたクロスサイトフレームは省略として報告され、guest の安全境界を
  越えて操作できません。
- Windows ARM64 と Linux ARM64 パッケージは含まれません。Microsoft Store での公開は Microsoft の独立した認証により、
  直接配布より遅れる場合があります。
