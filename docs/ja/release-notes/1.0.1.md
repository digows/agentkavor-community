# Kavor 1.0.1

## ハイライト

- Workspace を離れず不足ツールを復旧できます。Git/provider install を案内し、progress/error を表示して restart なしで detection を更新します。
- global `Auto`、`Full`、`Reduced` profile を追加しました。`Auto` は OS の reduced motion や Chromium software rendering 時に optional effect を減らします。
- Settings で一貫した update status、explicit check、manual fallback を提供し、Header/Settings badge が download から install ready まで表示します。
- provider が提供する最新 CodingAgent response の bounded plain-text preview を OS notification に任意表示し、privacy setting で lock screen 向けに無効化できます。
- Node から CodingAgent を start、stop、restart、configure し、provider 対応時は rename を native session name に同期します。
- 不要な locale、dev artifact、source map、test、他 OS binary を除き、runtime と notice を残して package を小型化しました。

## 修正

- bounded backpressure、ordered batch、attachment-scoped ack、final exit checkpoint で output delivery を再構築しました。
- pan、zoom、remount、startup で PTY surface を zoom compositor 外に固定し、checkpoint 後に hydrated content を表示します。
- transparent decoration と Locate が Terminal/CodingAgent portal を occlude しないようにしました。
- 全 zoom level の Node placement/drag preview を修正し、pointer が静止した viewport change にも対応します。
- Workspace/repository/target 切替で stale Git result を破棄し、valid repository に限定し、discovery/scan を共有します。
- Electron main と Process Host の native-tool refresh を atomic にし、fresh `PATH` で新ツールを検出します。
- Windows の PowerShell hook、environment、user-local Git、`winget`、concurrent Job Object を強化しました。
- installer feedback、retry、manual install、fresh detection、provider early exit の explicit error で CodingAgent recovery を改善しました。
- async provider activity を session ごとに isolate/bound し、Antigravity が stale/unrelated preview を拒否します。
- deletion teardown failure 時は Terminal Node を保持し、成功時は Node より先に process を閉じます。
- Sticky Note revision を concurrent Canvas move/resize から分離しました。
- competing update check と stale initial state が新しい availability/download/error を上書きしません。
- Authentication、onboarding、Workspace activation、Canvas startup を滑らかにし、flash/blank scene を防ぎます。
- development と packaged profile の SQLite、credential、window、cookie、cache、Browser storage を隔離しました。
- 最終 session 解放後に idle Codex app-server connection を確実に閉じます。
- anonymous startup Analytics を reload/network failure に強くし、detailed Analytics/Performance は user setting に従い、content、prompt、command、path、output、identity は除外します。

## インストール

<https://download.agentkavor.com> からダウンロードしてください。Windows x64 は未署名 NSIS、macOS 13+ は
未 notarize DMG と手動 update、Linux x64 は AppImage と手動 DEB です。

## 既知の制限

- Windows ARM64/Linux ARM64 は native gate 待ち、Windows は Authenticode、macOS auto install は Developer ID/notarization 待ちです。
- Microsoft Store 配布は含まれません。
