# Kavor 2.1.2

## 主な変更

- CodingAgents のアカウント、Channels の添付ファイル、Browser の利用に関する hotfix です。

## 修正

- 通常の Codex アカウント情報の読み取りで OAuth トークンを強制更新することと、同じ選択判断の中で
  重複して問い合わせることを防ぎます。Automatic によるアカウント選択と Auto Rotate の動作は維持します。
- 新しく作成する Codex、Claude Code、Grok の管理対象アカウントは、個人設定を複製しなくなります。
  各アカウントの認証は引き続き分離され、ネイティブの履歴は provider の正規の場所に維持されます。
  Kavor の統合は別途準備されます。
- Channels の添付ファイルの準備と整理を修正します。準備に失敗しても元ファイルやメッセージに紐付け済みの
  添付ファイルを保持し、送信用の一時ファイルを削除します。一時的な障害後は期限切れコピーの削除を再試行します。
- Browser では、`target="_blank"` リンクなどの匿名の新規ページ要求を、同じ Node のタブで開くようにします。
  明示的なポップアップ、名前付きターゲット、POST 送信は引き続きネイティブウィンドウで開きます。
- バックグラウンドページでの制御操作、操作座標の追跡、監視処理の解放を修正します。座標・サイズの常時
  ポーリングを廃止し、Browser が保持するネットワーク応答プレビューに上限を設けます。

## インストール

<https://download.agentkavor.com> から Kavor をダウンロードするか、Software Update 設定で更新を確認してください。

- **Windows x64：** Microsoft Store、またはユーザー操作を伴う NSIS インストーラー。Store 版の署名と更新は Microsoft が
  提供します。直接配布のインストーラーは引き続き未署名で、SmartScreen の警告が表示される場合があります。
- **macOS 13+：** Apple Silicon と Intel 用の個別の署名・公証済み DMG。自動更新は該当アーキテクチャの ZIP を使い、
  手動インストール用の DMG も引き続き利用できます。
- **Linux x64：** AppImage と DEB。AppImage は明示的な協調再起動を伴う Kavor 管理の更新に対応し、
  DEB の更新は手動でインストールします。

## 既知の制限

- 使用状況の報告と認証の復旧は、引き続き provider に依存します。アカウント使用状況の更新間隔、
  アカウントの適格性、ローテーションのしきい値、provider の上限は変更しません。
- 既存の管理対象プロファイルは自動で移行・整理しません。以前に複製された設定は保持されます。
- 匿名の新規ページ要求で作成するタブは、`WindowProxy` と `window.opener` によるネイティブの通信を
  維持しません。この通信に依存するサイトでは、一部のログインや決済などの処理がこの経路では完了しない
  場合があります。
- Windows ARM64 と Linux ARM64 パッケージは含まれません。Microsoft Store での公開は Microsoft の独立した認証により、
  直接配布より遅れる場合があります。
