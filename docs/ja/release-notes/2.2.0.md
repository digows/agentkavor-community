# Kavor 2.2.0

## 主な変更

- **Allow workspace editing** と許可された依頼に従い、CodingAgents が到達可能なセッションを開始・再起動・停止・Fork できます。Fork の対応は provider と利用可能なネイティブ履歴に依存します。
- Canvas の原子的編集で到達可能な Nodes を削除でき、実行を終了し、Connections と保留メッセージを調整します。正規のソースや Git worktrees は削除しません。

## 修正

- CodingAgent の起動前に準備済み worktree への関連付けを検証し、Workspace のルート、agent の作業ディレクトリ、各 checkout の Git 状態を区別します。
- worktree の作成・選択・解除に伴う実行中セッションの切り替えを修正します。対応している場合は既存のネイティブ識別情報で再開し、意図的に停止したセッションは停止したままです。
- 並行操作から Git 関連付けを保護し、ほかの CodingAgents が参照する worktrees の削除や完了処理を防ぎます。失敗しても、ユーザーが準備した worktrees を試行用の一時リソースとして削除しません。
- provider の早期終了や画面が空白のままになる場合など、起動失敗の段階と診断を保持します。修正後は同じ Node で再び開始できます。
- 起動失敗と再試行をまたいで保留中の最初のメッセージを保持し、消費済みの配信を繰り返さないようにします。
- Claude Code で表示上の提案とユーザー入力を混同せずに、入力可能状態を検出します。人間の下書き、質問、承認は引き続き保護されます。

## インストール

<https://download.agentkavor.com> から Kavor をダウンロードするか、Software Update 設定で更新を確認してください。

- **Windows x64：** Microsoft Store、またはユーザー操作を伴う NSIS インストーラー。Store 版の署名と更新は Microsoft が提供します。直接配布のインストーラーは未署名で、SmartScreen の警告が表示される場合があります。
- **macOS 13+：** Apple Silicon と Intel 用の個別の署名・公証済み DMG。自動更新は該当アーキテクチャの ZIP を使い、手動インストール用の DMG も引き続き利用できます。
- **Linux x64：** AppImage と DEB。AppImage は明示的な協調再起動を伴う Kavor 管理の更新に対応し、DEB の更新は手動でインストールします。

## 既知の制限

- Fork は provider の機能とインストール済みバージョンに依存します。Antigravity 統合は Fork を提供しません。履歴のない別セッションの作成は同等の代替にはなりません。
- Git worktree は依存関係をインストールせず、ローカル設定や認証情報も自動ではコピーしません。環境の準備はプロジェクトごとに必要です。
- provider の準備完了やメッセージの配信はタスクの完了を証明しません。利用上限、認証、サービスの可用性は引き続き providers が管理します。
- Windows ARM64 と Linux ARM64 パッケージは含まれません。Microsoft Store での公開は、独立した認証により直接配布より遅れる場合があります。
