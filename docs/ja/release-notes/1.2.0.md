# Kavor 1.2.0

## ハイライト

- 画像と PDF の File Node にリッチプレビューを追加しました。大きな PDF は表示中のページだけを描画し、
  画像、Canvas、ファイルの上限によって Workspace の無制限なメモリ使用を防ぎます。
- File と Specification のライフサイクルを完成させました。Canvas メニューからの Specification 作成、
  Workspace 上での名前変更・削除、フォルダー整理、ファイルシステム変更との Node 同期に対応します。
- Files パネルのパスを Terminal/CodingAgent にドロップでき、アクティブな shell に合わせて引用します。
- Specification 作成、アプリ進捗の永続化、File/Specification の可逆な副作用の回復を原子的提案に追加しました。
- すべての Kavor Skill が、読み込みに使う正確な `kavor.skill.get("<name>")` を示します。

## 修正

- Specification 編集時に YAML frontmatter のカスタム項目、コメント、順序、ファイル名、Workspace 相対パスを保持します。
- Terminal/CodingAgent の hydration を安定化し、遅延 PTY 状態が Workspace 変更時に内容を失ったり ownership を重複したりしません。
- Sticky Note の append を別々の Markdown ブロックとして保持し、空 append の revision を作らず、Unicode code point で制限します。
- 直列化、パス封じ込め、source invalidation、明示的な失敗処理で File/Specification 変更を強化しました。
- 以前の本番依存グラフにあったセキュリティ勧告を解消しました。

## インストール

<https://download.agentkavor.com> からダウンロードしてください。Windows x64 は未署名 NSIS、macOS 13+ は
ad-hoc 署名・未 notarize の arm64/x64 DMG と再検証 ZIP update、Linux x64 は更新可能な AppImage と手動 DEB
を提供します。手動ダウンロードは常に利用できます。

## 既知の制限

- Windows ARM64/Linux ARM64 は PTY、SQLite、process containment、packaged runtime のネイティブ CI gate 待ちです。
- Windows は Authenticode、macOS は Developer ID と notarization がまだありません。
- Gatekeeper や Keychain が確認を求める場合があります。Microsoft Store 配布は含まれません。
