# Kavor 1.0.6

## ハイライト

- 継続 output、並行処理、複数 Workspace で Terminal/CodingAgent を大幅に強化しました。PTY は Git、installer、probe、他の bounded operation から隔離した専用 host で動きます。
- live process と Canvas presentation を分離しました。Workspace 切替、pan、zoom、remount、offscreen で viewport を detach/restore しても process を再起動せず output を失いません。
- Software Update を明示的に検証する `Restart & update` 中心に再構築しました。進捗、readiness、error、recovery は Settings、Header/通知は passive attention を担います。
- offline post-update dialog を追加し、healthy launch 後に skip した全 release の Highlights、Fixes、Known limitations を一度表示します。
- Workspace preference は変更時に適用し、明示的 Save は Workspace name だけになりました。

## 修正

- 別 operation の stall で無関係な Terminal/CodingAgent まで終了する shared process-host failure domain を削除しました。
- fair bounded PTY output と直接型付き channel で noisy session が他 session の操作を独占しません。
- visibility/Workspace 切替時は authoritative checkpoint を先に描画し、duplicate、stale viewport、hidden restart を防ぎます。
- PTY host interruption から自動回復し、Stop intent を守り、duplicate launch や fabricated exit を避けます。
- operation host と PTY を分離し login environment refresh を集約して detection と PTY の競合を防ぎます。
- Node-based launch の CodingAgent context-hook process identity を修正しました。
- 通常終了で update を暗黙インストールせず、SHA-512 で cache を再検証し、失敗時は Kavor を開いたまま回復できます。
- stale readiness、重複 restart を修正し、bounded rotating diagnostics を追加しました。
- global toast を廃止し prerelease channel を即時反映、Header/restart に pulsing ready state を追加しました。
- 即時適用 preference が永続化に失敗した場合に rollback します。
- signed idempotent Firebase account sync、bounded retry、daily reconciliation を追加しました。
- lazy host に startup verification を合わせ、必要になるまで PTY/operation host を起動しません。

## インストール

<https://download.agentkavor.com> からダウンロードしてください。Windows x64 は未署名 NSIS、macOS 13+ は
未 notarize DMG と再検証 ZIP update、Linux x64 は AppImage と手動 DEB です。

## 既知の制限

- Windows ARM64/Linux ARM64 は native gate 待ち、Windows は Authenticode、macOS は Developer ID/notarization 待ちです。
- Gatekeeper/Keychain の確認が必要な場合があります。Microsoft Store 配布は含まれません。
