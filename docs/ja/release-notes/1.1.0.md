# Kavor 1.1.0

## ハイライト

- 新しいパッケージの private protocol sign-in を、試行に紐づく短時間の `127.0.0.1` callback に置き換えました。
  Google、GitHub、passwordless email は system browser から Kavor に直接戻り、provider flow は PKCE と clipboard fallback を使います。
- 初回 Authentication に法的同意を追加し、account lifecycle sync を versioned public API の背後に置きました。
- CodingAgents が原子的 Canvas catalog で File/Specification Nodes を提案できます。Connection Skills は適用ルールと Git-aware context から始まります。
- PTY 並行処理下の Terminal/CodingAgent 表示、Workspace 切替、startup、recovery を改善しました。
- Workspace から File-backed work に直接アクセスしたまま Specification のナビゲーションと操作を簡素化しました。

## 修正

- Google Desktop と GitHub の confidential server-side exchange を修正し、GitHub credentials を同梱せず loopback Authentication を完了します。
- 新しい desktop package から private protocol 登録を削除し、Linux handler failure を避けつつ旧版の hosted compatibility を維持します。
- stale、repeated、malformed、mismatched callback を拒否し、provider credentials と callback response を保存・ログしません。
- Workspace 変更時の PTY hydration/ownership を修正し、遅延または中断 handshake から偽の process exit なしで回復します。
- Terminal、CodingAgent、File、Specification Nodes 周辺の不要な Canvas/panel work を減らし、操作を明確化しました。
- release discovery を stable download API 経由にし、desktop client と release host の直接依存を解消しました。

## インストール

<https://download.agentkavor.com> からダウンロードしてください。Windows x64 は未署名 NSIS、macOS 13+ は
未 notarize の arm64/x64 DMG と再検証 ZIP update、Linux x64 は AppImage と手動 DEB です。

## 既知の制限

- 1.0.6 以前は旧 GitHub OAuth App 廃止により新規 GitHub sign-in ができません。既存 session は有効です。1.1.0 をインストールしてください。
- Windows ARM64/Linux ARM64 は native gate 待ち、Windows は Authenticode、macOS は Developer ID/notarization 待ちです。
- Microsoft Store 配布は含まれません。
