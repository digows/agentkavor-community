# Kavor 1.0.0

## ハイライト

- 永続的 local-first Canvas で CodingAgents、Terminals、Specifications、Files、Sticky Notes を調整します。
- Nodes を接続して明示的な capability を付与し、human-owned Guardrails と review boundary を維持します。
- CodingAgents が atomic Canvas change を提案し、Header から全体を locate、review、apply、reject できます。
- connected CodingAgents 間で durable message を交換し、reviewed operation catalog を local MCP bridge で公開します。
- restart 後も Workspace、Canvas、Terminal、provider session context を保ち、data はユーザーの machine に置きます。
- update availability と <https://download.agentkavor.com> の permanent manual fallback を提供します。

## 修正

- rich Node rendering を viewport scale に比例させ pan/zoom responsiveness を改善しました。
- Canvas visibility optimization と独立して Terminal state/counter を保持します。
- 対応 platform の PTY startup、process containment、cleanup、packaged runtime を強化しました。
- dependent Node/Connection change を 1 回の human decision と共同 rollback を持つ atomic proposal にしました。
- Workspace content、path、prompt、command、Terminal output、Authentication identity を集めず bounded anonymous Analytics と optional Performance を追加しました。

## インストール

<https://download.agentkavor.com> からダウンロードしてください。Windows x64 は初期未署名 NSIS、macOS 13+ は
未 notarize arm64/x64 DMG と手動 update、Linux x64 は AppImage と手動 DEB です。

## 既知の制限

- Windows ARM64/Linux ARM64 は native gate 待ち、Windows は Authenticode、macOS auto install は Developer ID/notarization 待ちです。
- Microsoft Store 配布は含まれません。
