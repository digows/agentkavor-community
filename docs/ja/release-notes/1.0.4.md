# Kavor 1.0.4

## ハイライト

- architecture-specific ZIP、differential blockmap、統合 stable channel で macOS arm64/x64 に Kavor-managed update を追加しました。
- 人向け download は DMG のまま、updater が適切な ZIP を background download し、通常終了の coordinated path で install します。
- 全 platform・全 updater failure で <https://download.agentkavor.com> を恒久 fallback として維持します。

## 修正

- Electron Updater に必要な ZIP と `latest-mac.yml` を公開せず updater を有効にしていた macOS release contract を修正しました。
- 各 native ZIP を検証して metadata を統合し、一方の architecture job が他方を上書きしないようにしました。
- 両 ZIP/blockmap の immutable SHA-256、promotion 前の exact asset verification、generated metadata の native gate を追加しました。
- obsolete initial package configuration を現在の direct-distribution contract に改名しました。

## インストール

<https://download.agentkavor.com> からダウンロードしてください。Windows x64 は未署名 NSIS。macOS 13+ は
未 notarize の arm64/x64 DMG で、この版以降は accepted release を通常終了時に自動 install できます。
Linux x64 は AppImage と手動 DEB です。手動 download は常に利用できます。

## 既知の制限

- Windows ARM64/Linux ARM64 は native gate 待ち、Windows は Authenticode、macOS は Developer ID/notarization 待ちです。
- Gatekeeper/Keychain の確認が必要な場合があります。Microsoft Store 配布は含まれません。
