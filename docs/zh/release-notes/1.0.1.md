# Kavor 1.0.1

## 主要亮点

- 不离开 Workspace 即可恢复缺失工具：引导安装 Git/CodingAgent provider，显示实时进度和可执行错误，并刷新检测而无需重启。
- 提供全局 `Auto`、`Full`、`Reduced` 性能档；系统要求减少动态效果或 Chromium 使用软件渲染时，`Auto` 保留操作反馈并降低可选效果。
- 从 Settings 管理 update，使用一致状态、显式检查和永久手动 fallback；Header/Settings badge 从下载到可安装都持续可见。
- provider 提供时，可在系统通知显示有界纯文本的最新 CodingAgent 回复预览；隐私设置可在 lock screen 机器上关闭内容。
- 从 Node 启动、停止、重启、配置 CodingAgent；provider 支持时，重命名 Node 会同步原生 session 名称。
- 显著缩小桌面包：移除不用的 locale、开发产物、source map、测试及其他系统二进制，同时保留生产 runtime 和第三方声明。

## 修复

- 用有界 backpressure、有序 batch、attachment ack 和最终 exit checkpoint 重构 output；大流量不再阻塞控制，旧 attachment 不再消费新 output。
- 改善 pan、zoom、remount 和 startup 中的显示；PTY 不继承缩放 compositor，hydrated 内容只在权威 checkpoint 后显示。
- 透明 Canvas 装饰和 Locate 不再被视为不透明遮挡，焦点变化时 portals 保持可见可操作。
- 修正所有 zoom 下的 Node 放置/drag preview，包括指针静止而 viewport 变化的情况。
- 切换 Workspace、仓库或 target 时丢弃旧 Git 结果，只对有效仓库显示控制，并共享 discovery、合并重复 scan。
- Electron main 与 Process Host 原子刷新工具环境，以新 `PATH` 检测刚安装的 Git/provider。
- 强化 Windows PowerShell hook、环境传播、用户 Git/`winget` 检测和并发 Job Object 初始化。
- 改善 CodingAgent 恢复：即时 installer 反馈、retry、手动安装、新 provider 检测和启动早退的明确错误。
- 按 session 隔离并限制异步 activity；Antigravity 拒绝过期或无关的响应预览。
- 删除时 teardown 失败会保留 Terminal Node；成功则先关进程再删 Node。
- Sticky Note 内容修订不受并发移动和 resize 影响。
- 并发 update check 或旧初始状态不再覆盖较新的可用性、下载或错误。
- 平滑 Authentication、onboarding、Workspace 激活和 Canvas startup，避免闪屏或空白中间场景。
- 开发与打包 profile 完全隔离 SQLite、凭据、窗口、cookie、cache 和 Browser storage。
- 最后一个 session 释放后确定性关闭空闲 Codex app-server 连接。
- 匿名 startup Analytics 可承受 renderer reload 与暂时网络故障；详细 Analytics/Performance 仍由用户控制，且排除内容、prompt、命令、路径、output 和身份。

## 安装

请从 <https://download.agentkavor.com> 下载。Windows x64：未签名 NSIS；macOS 13+：未公证 arm64/x64 DMG
并手动更新；Linux x64：AppImage 与手动 DEB。

## 已知限制

- Windows ARM64/Linux ARM64 尚待原生 gate；Windows 尚无 Authenticode；macOS 自动安装尚待 Developer ID/公证。
- 本版本不通过 Microsoft Store 分发。
