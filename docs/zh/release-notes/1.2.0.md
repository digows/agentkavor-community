# Kavor 1.2.0

## 主要亮点

- 为图像和 PDF 增加丰富的 File Node 预览。大型 PDF 只渲染可见页面，并通过有界的图像、Canvas 和文件限制
  防止 Workspace 无限占用内存。
- 完成 File 与 Specification 的生命周期：从 Canvas 菜单创建 Specification，在 Workspace 中重命名或删除
  源文件、整理文件夹，并让已有 Nodes 与文件系统变化保持同步。
- 可把 Files 面板中的路径直接拖入 Terminal 和 CodingAgent 会话，并按照当前 shell 正确引用。
- 扩展 Canvas 原子提案，支持创建 Specification、持久化应用进度，以及恢复 File/Specification 的可逆副作用。
- 每个 Kavor Skill 都会给出 CodingAgent 加载它所需的准确 `kavor.skill.get("<name>")` 调用。

## 修复

- 编辑 Specification 时保留 YAML frontmatter 的自定义字段、注释、顺序、文件名和 Workspace 相对路径。
- 稳定 Terminal/CodingAgent 的 hydration，避免延迟 PTY 状态在切换 Workspace 时丢失恢复内容或重复 ownership。
- Sticky Note 的每次追加保持为独立 Markdown 块；空追加不再产生修订；文本限制按 Unicode code point 计算。
- 通过串行化 Workspace 变更、路径限制、源失效和显式错误处理强化 File/Specification 修改。
- 解决上一版生产依赖图中的安全公告。

## 安装

请从 <https://download.agentkavor.com> 下载。Windows x64 使用尚未签名的 NSIS；macOS 13+ 提供 arm64/x64
DMG（ad-hoc 签名、未公证）并通过重新验证的对应 ZIP 更新；Linux x64 提供可更新的 AppImage 和手动 DEB。
手动下载始终可用。

## 已知限制

- Windows ARM64 和 Linux ARM64 尚待可运行原生 PTY、SQLite、进程限制及打包 runtime gate 的对应 CI。
- Windows 直接下载尚无 Authenticode 证书。
- macOS 尚无 Developer ID 签名和公证；Gatekeeper 或 Keychain 可能要求手动确认。
- 本版本不通过 Microsoft Store 分发。
