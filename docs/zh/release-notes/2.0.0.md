# Kavor 2.0.0

## 主要更新

- 你的 agents，现在也能在 WhatsApp 上联系。通过个人聊天或每个 Workspace 专属的群组与本地 agents 对话。
  在顶部栏打开 Channels 设置以关联账户；关联后会显示 Workspace Channels，设置会自动保存。
- Kavor Chat 将人与 agent 的对话带入 Workspace。选择 Workspace 和 CodingAgent，跟进进度、回答问题、
  交换附件，同时保留对话上下文。
- CodingAgent 通信现在支持通过 provider 原生提交、在回合结束后投递，以及在获准时显式中断。
  投递遵守 Connection Guardrails 并保留人的草稿；已连接的 agents 还可以通过有界、分页的历史记录
  读取其他 agents 会话中已完成的回合。
- 已连接的 agents 可以控制可见 Canvas 之外的活动 WebBrowser 标签页。浏览器设置现在会保留明确的
  Start 和 Shutdown 选择以及音频静音状态，不删除已保存的标签页或共享站点数据。
- 使用 Inter 和 Geist Mono 更新 desktop 字体，优化应用视觉素材，并恢复 macOS 应用图标的透明效果。
- 按需启动辅助进程并释放不活跃资源，同时保留 Workspace、Terminal、CodingAgent 和 Browser 的持久化状态。

## 修复

- 保留 CodingAgent 的原生启动选项，包括明确指定的模型、权限、会话和工作目录参数，
  不会静默替换用户的选择。
- 修正 Grok 回合完成和经过验证的被动会话读取场景，改善跨 Workspace 窗口的原生消息投递关联和通知确认。
- 显示 CodingAgent 的原生问题，并在操作系统通知标题中包含来源 Workspace，让多个 Workspace 的并行活动更易辨认。
- 改善 WhatsApp 配对、个人聊天与群组设置、上下文选择、重连和附件传输。
  Motion Photo 请求在原生重放过程中保留原始内容和关联信息。
- 统一 Chat 和 WhatsApp 中的命令、状态、问题、取消和错误反馈，明确处理过期选择和不可用的引用消息。
- 在 UI 生命周期变化期间保留 Browser 关闭意图和活动标签页状态，并改善 PTY 与辅助进程的清理。

## 安装

从 <https://download.agentkavor.com> 下载 Kavor。现有直接安装版可以在 Software Update 设置中检查此版本。
Workspace 数据库升级通过 Kavor 带有备份的迁移流程执行。

- Windows x64 可通过 Microsoft Store 或按用户安装的引导式 NSIS 安装程序获取。
  Microsoft 为 Store 安装版签名并提供更新。直接安装程序仍未签名，因此 Microsoft SmartScreen 可能要求明确确认。
- macOS 13+ 分别提供 Apple Silicon 和 Intel DMG，使用 Kavor 的 Apple Developer ID 签名并经过 Apple 公证。
  自动更新使用对应架构的 ZIP，同时保留手动使用 DMG 的备用方式。
- Linux x64 提供 AppImage 和 DEB 包。AppImage 支持由 Kavor 管理的更新，并要求明确的协调重启；
  DEB 更新需从下载页面手动安装。

## 已知限制

- 如果 Terminal 的 OSC 8 超链接输出到指针已经停留的行，可能需要先将指针移到另一行再移回来才能打开。
  本版本仍存在这一上游 xterm 悬停缓存限制。
- 生产依赖审计报告了上游尚未解决的拒绝服务安全公告：
  [braces](https://github.com/advisories/GHSA-vfj7-8cjw-p6xm) 和
  [sprintf-js](https://github.com/advisories/GHSA-hp3w-g68c-fv3c)。这些依赖版本已存在于 Kavor 1.7.1。
  Workspace 递归监听对使用 braces 的路径禁用 glob 展开；这是缓解措施，并不表示依赖已修复。
- WhatsApp 需要已关联的账户、网络连接，以及在 desktop 上运行的 Kavor。其关联设备集成不是 Meta 托管的
  WhatsApp Business API；WhatsApp 账户限制仍由 Meta 控制。
- Kavor 专用的共享 Browser Profile 为支持本地开发而接受所有服务器证书。
  恶意网络因此可能冒充该配置中打开的网站，包括用户登录的网站。
  Kavor 应用会话仍保留 Chromium 的正常证书验证。
- WebBrowser Nodes 不复用用户外部 Chrome 的配置、扩展、历史记录或 cookies。
  删除 Node 不会清除共享站点数据；Kavor 全局设置提供明确的缓存、cookies 和站点数据清理操作。
- 被隔离到另一个 Chromium 进程的跨站 frame 会被报告为已省略，无法跨越 guest 安全边界进行控制。
- 不提供 Windows ARM64 和 Linux ARM64 包。Windows 直接下载版尚无 Authenticode 发布者证书；
  Microsoft Store 包由 Microsoft 签名。Store 上架时间可能晚于直接发布的 stable 版本，
  需等待 Microsoft 完成独立认证。
