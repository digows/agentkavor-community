# Kavor 1.0.6

## 主要亮点

- Terminal/CodingAgent 在持续 output、并发及多 Workspace 下更可靠；PTY 使用独立 host，与 Git、安装器、probe
  和其他有界操作隔离。
- 活跃进程与 Canvas 显示分离；切换 Workspace、pan、zoom、remount 或暂时离屏时可分离并恢复 viewport，
  无需重启进程且不会丢失有序 output。
- Software Update 围绕显式且经过验证的 `Restart & update` 重构。进度、就绪、错误和恢复留在 Settings，
  Header badge 与系统通知只负责提示。
- 增加离线更新后对话框：新版首次健康启动后只显示一次所有跨过版本的 Highlights、Fixes 和 Known limitations。
- Workspace 偏好修改后立即生效，只有 Workspace 名称保留显式 Save。

## 修复

- 移除可能因另一项操作阻塞而终止无关 Terminal/CodingAgent 的共享 process-host 故障域。
- 增加公平、有界的 PTY output 处理和直接类型化显示通道，避免嘈杂会话垄断其他会话的控制。
- 修正 Canvas 可见性与 Workspace 切换时的 PTY hydration：先绘制权威 checkpoint，不重复、不保留旧 viewport、不暗中重启。
- PTY host 中断后自动恢复，同时尊重 Stop 并避免重复 launch 或伪造退出。
- 分离 operation host 与 PTY，并集中刷新登录环境，避免工具检测与 PTY 竞争。
- 修正基于 Node 启动时 CodingAgent context hook 的进程身份。
- 普通退出不再隐式安装 update；关闭前按 SHA-512 重验缓存，失败时保持 Kavor 打开并提供手动恢复。
- 修正过期 updater readiness、合并重复 restart，并加入有界轮转的本地诊断。
- 移除全局 update toast，立即应用 prerelease channel，并为 Header 与 restart 加入脉冲就绪状态。
- 即时应用的动画、telemetry、performance、path 和 update channel 若保存失败会回滚。
- 加入签名、幂等的 Firebase 账户生命周期同步，有界重试并每日对账。
- 打包启动验证适配 lazy host，空闲启动在需要前不会开启 PTY 或 operation host。

## 安装

请从 <https://download.agentkavor.com> 下载。Windows x64：未签名 NSIS；macOS 13+：未公证 arm64/x64 DMG
和重验 ZIP 更新；Linux x64：可更新 AppImage 与手动 DEB。

## 已知限制

- Windows ARM64/Linux ARM64 尚待原生 gate；Windows 尚无 Authenticode；macOS 尚无 Developer ID/公证。
- Gatekeeper 或 Keychain 可能要求确认；本版本不通过 Microsoft Store 分发。
