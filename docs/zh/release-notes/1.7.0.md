# Kavor 1.7.0

## 主要亮点

- 支持通过标准键盘快捷键和上下文菜单复制、剪切和粘贴 Canvas 中选定的子图。传输既可在同一 Canvas
  内完成，也可跨 Workspace 和窗口进行，同时保留受支持的 Nodes、内部 Connections、位置以及撤销或重做行为。
- 用户切换 Workspace 时，实时 WebBrowser 页面会继续运行，页面状态得以保留，已连接的 CodingAgent
  也可以继续浏览器工作。返回 Workspace 后会显示同一个实时页面，而不是重新加载。
- 可将操作系统剪贴板中的文件以及 PNG 或 JPEG 图像粘贴到 Terminal 和 CodingAgent 中，并转换为对 shell
  安全的文件引用。复制的图像会私密地保存到 Kavor 的本地应用配置目录中。

## 修复

- 每次应用启动时都会恢复由正在运行的 Triggers 所拥有且处于打开状态的 Terminal 和 CodingAgent 目标，
  因此计划任务不再依赖 Kavor 是否以后台模式明确启动。
- 改进 Sticky Note 指引，使 CodingAgent 不会主动改写用户或其他 Agent 的内容；获得授权时，它只更新自己
  清晰标记的条目。
- 将 Electron、Chromium、桌面工具链和运行时依赖更新到最新的兼容稳定版本，同时每个安装包仅保留对应平台
  所需的原生二进制文件。

## 安装

请从 <https://download.agentkavor.com> 下载 Kavor。该页面会检测当前平台，也可显示所有可用安装包。
现有的直接安装可在 Kavor 的 Software Update 设置中检查此版本。无需手动迁移 Workspace 数据。

- Windows x64 可从 Microsoft Store 获取，也可使用按用户安装的 NSIS 安装程序。Microsoft 会签名并更新
  Store 安装。直接安装程序仍未签名，因此 Microsoft SmartScreen 可能要求明确确认。
- macOS 13+ 分别提供 Apple Silicon 和 Intel DMG，使用 Kavor 的 Apple Developer ID 签名并经 Apple 公证。
  自动更新使用匹配架构的 ZIP，同时保留手动 DMG 作为备用方式。
- Linux x64 提供 AppImage 和 DEB。AppImage 支持由 Kavor 管理并明确协调重启的更新；DEB 更新需从下载页面
  手动安装。

## 已知限制

- Canvas 图剪贴板仅存在于当前进程中。复制或剪切内容可以跨 Workspace 和 Kavor 窗口，但无法在应用重启后
  保留，也不会复制实体文件、Provider 会话或运行时历史。
- 为支持本地开发，Kavor 专用的共享 Browser Profile 接受所有服务器证书。因此，恶意网络可能冒充该配置
  中打开的网站，包括用户登录的网站。Kavor 应用会话仍保持 Chromium 的正常证书验证。
- WebBrowser Nodes 不会复用用户外部 Chrome 的配置、扩展、历史记录或 Cookie。删除 Node 不会清除共享的
  网站数据；Kavor 全局设置提供明确的缓存、Cookie 和网站数据清理功能。
- 被 Chromium 隔离到另一个进程中的跨站 frame 会报告为已省略，且无法通过 guest 范围的安全边界控制。
- 在 Windows ARM64 和 Linux ARM64 的原生 PTY、SQLite、进程隔离与打包运行时 gates 能够在对应 CI
  环境中运行之前，不提供这些架构的安装包。
- Windows 直接下载目前没有 Authenticode 发布者证书；Microsoft Store 安装包由 Microsoft 签名。
  由于 Microsoft 的独立认证流程，Store 上线时间可能晚于直接稳定版本。
