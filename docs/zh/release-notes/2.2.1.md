# Kavor 2.2.1

## 修复

- 实际生效的 **Manual** 模式，无论在 CodingAgent 上设置还是继承自 Workspace，都不会在轮次完成时查询轮换容量。
  可见的用量读数和 **Refresh** 仍然可用。
- **Automatic** 在原有 30 秒期限内跨 Workspaces 复用同一账户的近期读数，不会推迟因期限届满、用量窗口重置，
  或确认的认证或配额故障而需要的重新评估。
- 显示账户名称，以及在 Agent Kavor 命令中解析已知名称或身份，不再导致不必要的用量查询。
  未知身份仍可能需要查询。
- 修复手动刷新尚无内存读数的账户时重复执行初始查询的问题。

轮换仍是预防性的，默认阈值为**已使用 95%**。参与设置、模型和支出权限规则不变；
账户切换仍遵守轮次之间的安全边界并保持会话连续性。

有关 Manual、Automatic 和读数时间，请参阅 [CodingAgent Accounts](../coding-agent-accounts.md)。

## 更新

从 <https://download.agentkavor.com> 下载 Kavor，或在 Software Update 设置中检查更新。
限制、认证和服务可用性仍由 providers 控制。
