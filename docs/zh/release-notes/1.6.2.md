# Kavor 1.6.2

## 亮点

- 扩展 WebBrowser Node 的人工控制功能：提供明确的 DevTools 开关、在系统浏览器中打开当前 HTTP 或 HTTPS
  页面，以及在地址栏中执行原生剪切、复制、粘贴和全选操作。
- 在 WebBrowser Node 内处理 HTTP 和代理身份验证，并显示每个页面的控制台错误数和 CodingAgent 网络规则数；
  用户可直接检查错误或清除活动规则。
- Kavor 的专用 Browser Profile 可以打开使用自签名、过期或私有机构证书的本地开发服务器，同时不会削弱
  Kavor 应用程序会话的证书验证。

## 修复

- 让 WebBrowser 新标签页画面填满整个 viewport，并将加载进度保持在状态栏边缘，不再移动页面内容。
- 优化 Canvas 创建菜单，使 CodingAgent provider 和 Node 类型采用一致的分组及易于识别的图标颜色。
- Microsoft Store 发布现在会在消耗原生 build 时间之前验证受保护凭据和 Partner Center 访问权限，并串行
  处理提交，避免取消正在进行的 Store 操作。

## 安装

请从 <https://download.agentkavor.com> 下载 Kavor。该页面会检测当前平台，也可以显示所有可用软件包。
现有直接安装版本可在 Kavor 的 Software Update 设置中检查此版本。无需手动迁移 Workspace 数据。

- Windows x64 可通过 Microsoft Store 或按用户安装的 NSIS 安装程序获取。Microsoft 负责签名和更新 Store
  安装版本。直接安装程序仍未签名，因此 Microsoft SmartScreen 可能要求明确确认。
- macOS 13+ 分别提供 Apple Silicon 和 Intel DMG，均使用 Kavor 的 Apple Developer ID 签名并经 Apple
  公证。自动更新使用对应架构的 ZIP，同时保留 DMG 作为手动后备方案。
- Linux x64 提供 AppImage 和 DEB。AppImage 支持由 Kavor 管理并需要明确协调重启的更新；DEB 需要从下载
  页面手动安装更新。

## 已知限制

- 为支持本地开发，Kavor 的专用共享 Browser Profile 接受所有服务器证书。因此，恶意网络可能冒充在该
  Profile 中打开的网站，包括用户登录的网站。Kavor 应用程序会话仍保留 Chromium 的正常证书验证。
- WebBrowser Node 不会复用用户外部 Chrome 的 Profile、扩展、历史记录或 Cookie。删除 Node 不会清除共享
  网站数据；Kavor 全局设置提供明确的缓存、Cookie 和网站数据清理功能。
- CodingAgent 控制要求 WebBrowser Node 在 Canvas 上处于活动状态。被 Chromium 隔离到其他进程的跨站
  frame 会标记为已省略，无法通过 guest 安全边界控制。
- Windows ARM64 和 Linux ARM64 软件包尚未包含；只有在相应 CI 环境通过原生 PTY、SQLite、进程隔离和
  打包 runtime gate 后才会发布。
- Windows 直接下载尚无 Authenticode publisher 证书；Microsoft Store 软件包由 Microsoft 签名。由于
  Microsoft 的独立认证流程，Store 版本可能晚于直接 stable release 上线。
