# Kavor 1.6.0

## 亮点

- 在 Canvas 中新增 WebBrowser Node，作为由用户操作的完整 Chromium 浏览器。它支持持久化标签页、导航、
  历史记录、弹出窗口、下载、权限提示、查找、缩放、DevTools，以及由用户的 WebBrowser Nodes 共享的专用
  Kavor 浏览器配置文件。
- 允许已连接的 CodingAgent 通过有界 Kavor 操作控制用户看到的同一个实时页面，包括页面状态、导航、
  无障碍快照、操作、JavaScript 求值、等待、截图、控制台和网络检查、响应正文，以及页面范围的网络规则。
- 允许 CodingAgents 通过原子 Canvas 更改创建 WebBrowser Nodes，可选择打开初始 URL，随后通过 Kavor 其他
  功能所使用的相同 Connection 和可达性模型发现并操作该 Node。
- 减少自动提供给 CodingAgent 的上下文，同时保留按需访问当前任务所需的完整图、布局、Specification
  元数据、输出和 Skills 的能力。

## 修复

- 启动和分叉 Codex 会话时不再等待 Codex 尚未创建的 rollout 文件；第一个已提交提示建立原生身份后，
  再记录提供方会话。
- 当提供方会话在交互式终端打开后才完成实体化时，保留 Codex 恢复、分叉谱系和同步的会话名称。
- 在领域、Canvas、IPC、MCP 目录、Skills、配置文件分区和内部浏览器方案中统一使用 WebBrowser 术语。
- 为 WebBrowser 操作和等待发布完整输入契约，使 CodingAgents 获得所有支持的字段，而不是空的顶层工具
  schema。

## 安装

请从 <https://download.agentkavor.com> 下载 Kavor。页面会检测当前平台，也可显示所有可用软件包。现有直接
安装可在 Kavor 的软件更新设置中检查此版本。无需手动迁移 Workspace 数据；WebBrowser Node 是本版本的
新增功能，现有 Canvas 数据保持兼容。

- Windows x64 可从 Microsoft Store 获取，也可使用按用户辅助的 NSIS 安装程序。Microsoft 会签名并更新
  Store 安装。直接安装程序仍未签名，因此 Microsoft SmartScreen 可能要求明确确认。
- macOS 13+ 分别提供 Apple Silicon 和 Intel DMG，并使用 Kavor 的 Apple Developer ID 签名及经 Apple
  公证。自动更新使用与架构匹配的 ZIP，并保留手动 DMG 作为后备方式。
- Linux x64 提供 AppImage 和 DEB 软件包。AppImage 支持由 Kavor 管理并明确协调重启的更新；DEB 更新需从
  下载页面手动安装。

## 已知限制

- WebBrowser Nodes 使用 Kavor 专用的共享浏览器配置文件；不会复用用户外部 Chrome 的配置文件、扩展、
  历史记录或 Cookie。删除 Node 不会清除共享站点数据；Kavor 全局设置提供明确清除缓存、Cookie 和站点
  数据的选项。
- CodingAgent 控制要求 WebBrowser Node 在 Canvas 上处于活动状态。隔离到另一 Chromium 进程的跨站
  frame 会被标记为省略，无法跨越 guest 范围的安全边界进行控制。
- 权限提示、保存对话框、CAPTCHA、passkey、客户端证书和操作系统身份验证仍需由用户处理。
- 在原生 PTY、SQLite、进程隔离和打包运行时 gates 能够在匹配的 CI 环境中运行之前，不提供 Windows
  ARM64 和 Linux ARM64 软件包。
- Windows 直接下载尚无 Authenticode 发布者证书；Microsoft Store 软件包由 Microsoft 签名。Store
  版本可能会在直接 stable release 之后、通过 Microsoft 独立认证后提供。
