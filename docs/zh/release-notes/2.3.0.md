# Kavor 2.3.0

## 主要更新

- **Canvas 上的图表：**支持 13 个格式家族的文件，包括 Mermaid、带 C4 的 PlantUML、Graphviz、D2、Excalidraw
  和 draw.io。可在 Diagram、Source 和 Split 之间切换，查看渲染错误，并导出 SVG 或 PNG。Excalidraw 支持可视化
  编辑；draw.io 在 Kavor 中仅供查看。
- **按文件系统组织文档：**Specifications 和 Diagrams 共享 Documentation roots。可配置相对于第一个根目录的
  Diagrams folder、浏览真实的文件夹树，并通过 toolbar 或内联表单创建。默认路径仍为 `docs/diagrams/`；更改目标
  不会移动已有文件。
- **更多上下文添加方式：**将系统文件拖到 Canvas，或粘贴文件、图像数据、单个 URL 或文本。文件保留在原处；粘贴的
  图像会以 PNG 保存在 Workspace 中。外部来源会跟随磁盘变化更新，没有丰富预览的文件会显示包含详情和操作的卡片。

## 修复

- Auto 遵守 Workspace 中不参与自动选择的账户设置，并保留 Manual 选择。当参与的其他账户不可用时，已有会话会被
  保留，并在有合格账户恢复后重新评估；排除账户不会变成允许新执行的授权。
- Codex 使用量查询在凭据被明确撤销后，不再自动反复重试；仍可由人通过 Refresh 明确发起恢复。
- 修复了显示预先启动的 Terminals、CodingAgents 会话以及更改缩放时的尺寸调整，保留原生会话，而不是为了调整
  显示而重新创建会话。

## 安装

通过 Kavor 更新，或使用[下载页面](https://agentkavor.com/downloads)。如果更新器不可用，仍可从
[download.agentkavor.com](https://download.agentkavor.com) 获取安装包。

## 已知限制

- 图表引擎和资源按需获取。首次使用可能需要互联网；缓存可复用已下载资源，但引用外部 URL 的内容仍可能需要网络。
- draw.io 在 Kavor 中没有编辑器，D2 不提供 TALA。模型可用性、使用量读取和会话恢复仍取决于所选 harness 的能力及
  认证状态。
