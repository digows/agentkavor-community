# Kavor 1.0.3

## 主要亮点

- 使用专用 Electron Helper 启动 CodingAgent 上下文 bridge，并只在 Windows 加载 Job Object，恢复 macOS 包中的 Terminal/CodingAgent。
- 显示可承受 Canvas pan、zoom、remount 和 Workspace 启动；只在权威 checkpoint 绘制后显示 hydrated output，且不丢会话。
- 增加明确的 stable/prerelease channel；stable 默认，prerelease 需 opt-in 且独立于 Workspace 数据。
- 打包应用包含可验证 build identity，并强化进入 stable 前的原生验证。

## 修复

- macOS/Linux 包不含 Windows Job Object 与 `koffi` 时，Process Host 不再在 handshake 前失败。
- 修正 macOS CodingAgent bridge runtime，主程序不再拒绝后台 Node entry point。
- 新增打包 startup gate，等待 handshake 并验证平台 bridge，而不是把早期 crash 隐藏成 timeout。
- 重构 PTY hydration/ownership，使 Nodes 跨 Canvas 与 screen-space 层时保持 output、readiness、ack、焦点和控制一致。
- 移除 Terminal 配置中的持久显示状态，并迁移数据库从活资源推导可用性。
- 改善 CodingAgent startup、restart、worktree、资源可用性及 provider/Terminal 失败恢复。
- Antigravity 仅提取已完成请求的响应，接受支持的 transcript/termination 变体且不泄漏旧响应。
- 防止旧 update check 覆盖新状态，reload 后保留详情，并在系统通知中加入 Kavor 图标。
- 改善 Canvas 放置、Connection 引导、面板、Workspace 启动、Settings、Git、Specification 和 Node 显示。
- telemetry canary 容忍成功交付后 Chromium 临时写入，避免仅因暂时 `ENOTEMPTY` 阻断 release。
- 简化原生 CI：手动诊断只构建一个平台，版本 tag 仍运行完整矩阵；stable 默认覆盖 100%，可紧急暂停。

## 安装

请从 <https://download.agentkavor.com> 下载。Windows x64：未签名 NSIS；macOS 13+：未公证 arm64/x64 DMG
并手动更新；Linux x64：AppImage 与手动 DEB。

## 已知限制

- Windows ARM64/Linux ARM64 尚待原生 gate；Windows 尚无 Authenticode；macOS 自动安装尚待 Developer ID/公证。
- 本版本不通过 Microsoft Store 分发。
