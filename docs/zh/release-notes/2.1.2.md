# Kavor 2.1.2

## 主要变化

- 针对 CodingAgents 账户、Channels 附件和 Browser 使用的 hotfix。

## 修复

- 避免在常规 Codex 账户读取时强制续期 OAuth 令牌，以及在同一次选择决策中重复查询。
  保留 Automatic 账户选择和 Auto Rotate 的行为。
- 新建的 Codex、Claude Code 和 Grok 托管账户不再克隆个人配置。各账户的认证仍然隔离；
  原生历史记录保留在 provider 的规范位置，Kavor 集成则单独准备。
- 修复 Channels 附件的准备与清理：准备失败时保留源文件和已经关联到消息的附件，移除发送用的临时文件，
  并在暂时性故障后重试清理已过期的副本。
- 在 Browser 中，匿名的新页面打开请求（例如 `target="_blank"` 链接）现在使用同一个 Node 的标签页。
  显式弹出窗口、具名目标和 POST 提交仍使用原生窗口。
- 修复后台页面的控制操作、交互几何信息跟踪和监听器释放。移除持续进行的几何信息轮询，
  并限制 Browser 保留的网络响应预览。

## 安装

从 <https://download.agentkavor.com> 下载 Kavor，或在 Software Update 设置中检查更新。

- **Windows x64：** Microsoft Store 或需要用户操作的 NSIS 安装程序。Microsoft 负责 Store 安装的签名与更新。
  直接下载的安装程序仍未签名，可能显示 SmartScreen 警告。
- **macOS 13+：** 分别为 Apple Silicon 和 Intel 提供已签名且经过公证的 DMG。自动更新使用对应架构的 ZIP；
  DMG 仍可用于手动安装。
- **Linux x64：** AppImage 和 DEB。AppImage 支持 Kavor 管理的更新，并要求明确协调重启；DEB 更新需手动安装。

## 已知限制

- 使用情况报告和认证恢复仍取决于各 provider。账户使用情况的刷新间隔、账户资格、轮换阈值和 provider 限额不变。
- 现有托管配置不会自动迁移或清理；之前复制的配置会保留。
- 为匿名打开请求创建的新标签页不保留通过 `WindowProxy` 和 `window.opener` 进行的原生通信。
  依赖这种通信的网站，包括某些登录或支付流程，可能无法通过这一路径完成相应流程。
- 不包含 Windows ARM64 和 Linux ARM64 软件包。Microsoft Store 的可用时间可能晚于直接发布，
  因为它取决于 Microsoft 独立的认证流程。
