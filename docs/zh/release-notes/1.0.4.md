# Kavor 1.0.4

## 主要亮点

- 通过架构专用 ZIP、差分 blockmap 和统一 stable channel，为 macOS arm64/x64 增加 Kavor 管理的更新。
- 人工下载仍使用各架构 DMG；updater 自动选择对应 ZIP，在后台下载并通过 Kavor 协调的正常退出流程安装。
- 每个平台及所有 updater 失败都始终可回退到 <https://download.agentkavor.com>。

## 修复

- 修正 macOS 发布契约：此前启用了自动 updater，却未发布 Electron Updater 所需的 ZIP 和 `latest-mac.yml`。
- 分别验证原生 ZIP 并在发布时合并，避免一个 macOS 架构 job 覆盖另一个的更新 metadata。
- 为两个 ZIP 与 blockmap 增加不可变 SHA-256、提升前精确 asset 校验及生成 metadata 的原生 package gate。
- 将过时的初始包配置重命名为当前直接分发契约。

## 安装

请从 <https://download.agentkavor.com> 下载。Windows x64 使用未签名 NSIS。macOS 13+ 提供未公证的 arm64/x64
DMG；安装本版本后，后续认可的 release 可在 Kavor 正常退出时自动安装。Linux x64 提供 AppImage 与手动 DEB。

## 已知限制

- Windows ARM64/Linux ARM64 尚待原生 gate；Windows 尚无 Authenticode；macOS 尚无 Developer ID/公证。
- Gatekeeper 或 Keychain 可能要求确认；本版本不通过 Microsoft Store 分发。
