# Kavor 2.4.2

## 主要更新

- **Skip trust prompts：**每个 CodingAgent Node 的启动偏好设置，默认开启，让受支持的 harness 启动时不再询问
  你是否信任选中的文件夹或其中的 hooks。可在 Startup 中关闭，并于下一次启动生效。
  显式指定的原生参数仍优先生效；工具权限和登录认证仍单独处理。信任文件夹也意味着允许 harness 加载项目的
  hooks 和其他原生配置。
- **Diagrams 面板组织：**在面板中创建文件夹和文件，并在现有文档树中进行整理；操作无法完成时，会显示更清晰的提示。
- **按需加载 Canvas 内容：**文本编辑器、语言支持和 Connection Inspector 均按需加载，编辑与检查行为保持不变。

## 修复

- 在 Canvas 上拖动时，即使经过 Diagram 预览也能正常进行。打开文本文件并定位到指定行时，该行在初次加载时即可见。
- Windows 上的 provider 检测和进程启动会保留经 npm `.cmd` 和 `.bat` 启动器传递的参数，包括含空格的路径和
  带引号的值。
- 移除 Codex 托管账户时，会保留原生会话索引所使用的历史记录存储位置，同时移除该账户的本地凭据和状态。
  这可避免产生新的失效历史记录链接，但不会修复之前已失效的链接。
- 即使进程清理也失败，ACP 初始化仍会报告原始的初始化错误。
- 进程宿主使用专用的运行时入口，桌面软件包不再包含 Claude SDK 的两个未使用入口，但保留 Kavor 使用的 SDK 功能。

## 安装

通过 Kavor 更新，或前往 [download.agentkavor.com](https://download.agentkavor.com) 下载。macOS 软件包使用
Developer ID 签名，并经过 Apple 公证。Windows 直接下载的安装程序仍未签名，可能显示 SmartScreen 警告；
Microsoft Store 仍是独立的分发渠道，更新由 Store 控制。

## 已知限制

- Skip trust prompts 不会批准登录认证、工具权限或 Claude Code 中项目仓库自身的 MCP 提示。未识别的信任提示
  界面仍由你作答。OpenCode 不需要此偏好设置。
- Diagram 引擎和资源按需获取。首次使用可能需要联网，外部资源仍可能依赖网络连接。draw.io 仍仅供查看，
  D2 不提供 TALA。
