# Kavor 1.5.0

## 亮点

- 除直接下载 NSIS 安装程序外，Kavor 现已发布到 Windows Microsoft Store。Microsoft 会签名并分发 Store
  包，并负责通过 Store 安装的版本更新。
- 两种 macOS 架构均使用 Apple Developer ID 签名并由 Apple 公证。Gatekeeper 现在可以验证 Kavor
  发布者和公证票据，不再显示最初的“无法识别的开发者”流程。
- 为每个 CodingAgent 添加工作目录选择器。会话可从用户选择的任意现有目录启动，包括 Workspace
  之外的目录，同时保留独立的 Git 和 worktree 关联。
- 允许已连接的 CodingAgent 被动读取可达 peer 当前 provider 会话中已完成的轮次。历史记录使用游标
  分页；读取不会向 provider 发送输入、激活 peer 或创建 Kavor 消息。
- 改进 Kavor Skill 上下文传递：创建 Specification 的指导在连接 Specification 之前即可用，Trigger
  工作会直接收到相关运行上下文。

## 修复

- 在有界历史分页中保留完整的长 CodingAgent 会话消息，不再截断剩余文本。
- 在被动读取 peer 时检测 provider 会话变化，并拒绝过期的继续请求，而不是混合不同会话的片段。
- 恢复 Codex 会话前先进行验证；当前会话被外部归档时，可替换该会话而不丢失可恢复的 provider 历史。
- 跨 provider 分页读取完整的 Antigravity 历史，并统一 Claude Code、Codex、Antigravity、OpenCode 和 Grok
  的被动历史支持。
- 将过长的启动参数和所选工作目录路径限制在 CodingAgent 设置面板内。

## 安装

请从 <https://download.agentkavor.com> 下载 Kavor。页面会检测当前平台，也可显示所有可用包。现有直接
安装可在 Kavor 的 Software Update 设置中检查此版本。无需手动迁移 Workspace 数据；Kavor 会在应用
schema 升级前备份受支持的本地数据库。

- Windows x64 可从 Microsoft Store 获取，也可使用按用户辅助安装的 NSIS 安装程序。Microsoft 会签名
  和更新 Store 安装。直接安装程序仍未签名，因此 Microsoft SmartScreen 可能要求明确确认。
- macOS 13+ 分别提供 Apple Silicon 和 Intel DMG，使用 Kavor 的 Apple Developer ID 签名并由 Apple
  公证。本版本将以前的 ad-hoc 身份迁移到稳定的 Developer ID 身份。如果 macOS 拒绝从旧版本自动迁移，
  请从永久下载页手动安装对应 DMG；现有 Kavor 数据会保留。
- Linux x64 提供 AppImage 和 DEB 包。AppImage 支持由 Kavor 管理的更新并明确协调重启；DEB 更新需从
  下载页手动安装。

## 已知限制

- Schedule Trigger 要求 Kavor runtime 正在运行、设备未休眠、用户已登录且目标会话处于活动状态。Kavor
  未运行期间错过的执行会被记录并提供明确的手动运行选项，绝不会在下次启动时自动执行。
- 在 Windows ARM64 和 Linux ARM64 的原生 PTY、SQLite、进程隔离及打包 runtime 验证可在匹配的 CI
  环境运行之前，不提供这些架构的包。
- Windows 直接下载尚无 Authenticode 发布者证书；Microsoft Store 包由 Microsoft 签名。
- 首次从 ad-hoc macOS 版本迁移到 Developer ID 签名版本时，可能需要手动安装 DMG，或为
  `Kavor Safe Storage` 授权一次 Keychain。后续签名版本会保留相同的 Apple Team 身份。
- Microsoft Store 可能要在独立认证完成后才提供此确切版本；stable 直接安装包会立即在 Kavor 下载页
  提供。
