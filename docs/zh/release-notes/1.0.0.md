# Kavor 1.0.0

## 主要亮点

- 在持久、本地优先的 Canvas 上协调 CodingAgents、Terminals、Specifications、Files 和 Sticky Notes。
- 通过 Connections 显式授予能力，同时保留用户所有的 Guardrails 与人工审查边界。
- CodingAgents 可提出原子 Canvas 变更；用户可在 Header 定位、审查、应用或拒绝完整提案。
- 已连接 CodingAgents 可交换持久消息，并通过本地 MCP bridge 暴露审查后的 Kavor 操作目录。
- 重启后保留 Workspace、Canvas、Terminal 和 provider session 上下文，应用数据留在用户机器。
- 提示更新，并始终提供 <https://download.agentkavor.com> 手动 fallback。

## 修复

- 让丰富 Node 渲染随 viewport scale 调整，改善 Canvas pan/zoom。
- Terminal 状态和计数不受 Canvas 可见性优化影响。
- 强化支持平台的 PTY 启动、进程限制、清理与打包 runtime。
- Canvas 提案保持原子性，依赖的 Node/Connection 变更只需一次人工决策并在失败时共同回滚。
- 增加有界匿名 Analytics 和可选 Performance，且不收集 Workspace 内容、路径、prompt、命令、Terminal output 或 Authentication 身份。

## 安装

请从 <https://download.agentkavor.com> 下载。Windows x64：初始未签名 NSIS；macOS 13+：未公证 arm64/x64
DMG 并手动更新；Linux x64：AppImage 与手动 DEB。

## 已知限制

- Windows ARM64/Linux ARM64 尚待原生 gate；Windows 尚无 Authenticode；macOS 自动安装尚待 Developer ID/公证。
- 本版本不通过 Microsoft Store 分发。
