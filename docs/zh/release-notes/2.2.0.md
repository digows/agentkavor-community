# Kavor 2.2.0

## 主要变化

- 当 **Allow workspace editing** 和获授权的请求允许时，CodingAgents 可以启动、重启、停止和 Fork 可达会话。Fork 是否可用取决于 provider 和可用原生历史。
- Canvas 原子编辑支持删除可达 Nodes，同时停止执行并协调 Connections 与待处理消息，不会删除规范源文件或 Git worktrees。

## 修复

- 在启动 CodingAgent 前验证与已准备 worktree 的关联，保持 Workspace 根目录、agent 活动目录和各 checkout 的 Git 状态相互独立。
- 修复创建、选择或离开 worktree 时运行中会话的切换。在支持时使用现有原生身份恢复；明确停止的会话保持停止。
- 保护 Git 关联免受并发操作影响，阻止删除或完成仍被其他 CodingAgents 引用的 worktrees。失败不会把用户准备的 worktrees 当作尝试所拥有的临时资源删除。
- 保留启动失败的阶段和诊断，包括 provider 提前退出或界面持续空白。修复后可在同一 Node 中重新启动尝试。
- 在启动失败及重试期间保留待处理的第一条消息，避免重复已经消费的投递。
- 改善 Claude Code 的输入就绪检测，不会将视觉建议误认为用户键入的文字。人工草稿、问题和审批仍受保护。

## 安装

从 <https://download.agentkavor.com> 下载 Kavor，或在 Software Update 设置中检查更新。

- **Windows x64：** Microsoft Store 或需要用户操作的 NSIS 安装程序。Microsoft 负责 Store 安装的签名与更新。直接下载的安装程序仍未签名，可能显示 SmartScreen 警告。
- **macOS 13+：** 分别为 Apple Silicon 和 Intel 提供已签名且经过公证的 DMG。自动更新使用对应架构的 ZIP；DMG 仍可用于手动安装。
- **Linux x64：** AppImage 和 DEB。AppImage 支持 Kavor 管理的更新，并要求明确协调重启；DEB 更新需手动安装。

## 已知限制

- Fork 取决于 provider 的能力和已安装版本。Antigravity 集成不提供 Fork；另建没有历史的会话并不等价。
- Git worktree 不会安装依赖，也不会自动复制本地配置或凭据。环境准备仍取决于项目。
- provider 就绪和消息投递不证明任务完成。限额、认证和服务可用性仍由 providers 控制。
- 不包含 Windows ARM64 和 Linux ARM64 软件包。Microsoft Store 的可用时间可能晚于直接发布，因为它依赖独立认证。
