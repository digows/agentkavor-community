# Kavor 2.1.1

## 主要变化

- 减少重复的账户观测，同时保留 Automatic 账户选择和 Auto Rotate 的行为。

## 修复

- 常规 Codex 账户读取不再强制续期 OAuth 令牌。原生认证恢复仍由 Codex 控制。
- 共享同一账户的待完成观测，并在一次选择决策内复用该账户的当前观测，不复用上一次决策的执行数据。

## 安装

从 <https://download.agentkavor.com> 下载 Kavor，或在 Software Update 设置中检查更新。

- **Windows x64：** Microsoft Store 或需要用户操作的 NSIS 安装程序。Microsoft 负责 Store 安装的签名与更新。
  直接下载的安装程序仍未签名，可能显示 SmartScreen 警告。
- **macOS 13+：** 分别为 Apple Silicon 和 Intel 提供已签名且经过公证的 DMG。自动更新使用对应架构的 ZIP；
  DMG 仍可用于手动安装。
- **Linux x64：** AppImage 和 DEB。AppImage 支持 Kavor 管理的更新，并要求明确协调重启；DEB 更新需手动安装。

## 已知限制

- 使用情况报告和认证恢复仍取决于各 provider。此 hotfix 不改变刷新间隔、账户资格、轮换阈值或 provider 限额。
- 不包含 Windows ARM64 和 Linux ARM64 软件包。Microsoft Store 的可用时间可能晚于直接发布，
  因为它取决于 Microsoft 独立的认证流程。
