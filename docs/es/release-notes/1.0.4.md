# Kavor 1.0.4

## Aspectos destacados

- Añade updates administrados por Kavor a macOS arm64 y x64 mediante ZIP específicos, blockmaps diferenciales y un
  único canal stable consolidado.
- Mantiene el DMG de cada arquitectura para descarga humana, mientras el updater elige el ZIP correcto, lo descarga
  en segundo plano y lo instala mediante el cierre normal coordinado de Kavor.
- Conserva <https://download.agentkavor.com> como fallback permanente en toda plataforma y ante cualquier fallo.

## Correcciones

- Corrige el contrato macOS que activó el updater sin publicar los ZIP y `latest-mac.yml` requeridos por Electron Updater.
- Evita que un job macOS reemplace los metadatos de la otra arquitectura, validando cada ZIP y consolidando ambos.
- Añade SHA-256 inmutable para ambos ZIP y blockmaps, verificación exacta antes de promoción y gates nativos del metadata.
- Renombra la configuración obsoleta del paquete inicial al contrato de distribución directa actual.

## Instalación

Descarga Kavor en <https://download.agentkavor.com>. Windows x64 usa NSIS sin firma. macOS 13+ ofrece DMG arm64 y x64
ad-hoc sin notarización; después de instalar esta versión, releases aceptadas pueden instalarse al cerrar Kavor
normalmente. Linux x64 ofrece AppImage actualizable y DEB manual. La descarga manual siempre permanece disponible.

## Limitaciones conocidas

- Windows ARM64 y Linux ARM64 esperan gates nativos de PTY, SQLite, contención y runtime empaquetado.
- Windows aún no tiene certificado Authenticode.
- macOS aún no tiene Developer ID ni notarización; Gatekeeper puede pedir confirmación y acceso al Keychain.
- Microsoft Store no forma parte de esta versión.
