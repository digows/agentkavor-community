# Kavor 1.6.0

## Novedades

- Añade el Node WebBrowser al Canvas como un navegador Chromium completo operado por personas. Incluye pestañas
  persistentes, navegación, historial, ventanas emergentes, descargas, solicitudes de permisos, búsqueda, zoom,
  DevTools y un Perfil de Navegador Kavor dedicado y compartido por los Nodes WebBrowser del Usuario.
- Permite que un CodingAgent conectado controle la página activa exacta visible para el Usuario mediante operaciones
  Kavor acotadas para estado de página, navegación, snapshots de accesibilidad, acciones, evaluación de JavaScript,
  esperas, capturas, inspección de consola y red, cuerpos de respuesta y reglas de red con alcance de página.
- Permite que los CodingAgents creen Nodes WebBrowser mediante cambios atómicos del Canvas, con una URL inicial
  opcional, para luego descubrir y operar el Node con el mismo modelo de Connection y alcance usado en Kavor.
- Reduce el contexto automático del CodingAgent y conserva el acceso bajo demanda al grafo completo, layout,
  metadatos y resultados de la Specification y Skills necesarios para la tarea actual.

## Correcciones

- Inicia y bifurca sesiones de Codex sin esperar un archivo de rollout que Codex todavía no ha creado, y registra la
  sesión del proveedor cuando el primer prompt enviado establece su identidad nativa.
- Conserva la reanudación de Codex, el linaje de bifurcación y los nombres de sesión sincronizados cuando la sesión
  del proveedor se materializa después de abrir el terminal interactivo.
- Usa un vocabulario WebBrowser coherente en el dominio, Canvas, IPC, catálogo MCP, Skills, partición del perfil y
  esquema interno del navegador.
- Publica contratos de entrada completos para acciones y esperas de WebBrowser, de modo que los CodingAgents reciban
  todos los campos admitidos en lugar de un esquema de herramienta superior vacío.

## Instalación

Descarga Kavor desde <https://download.agentkavor.com>. La página detecta la plataforma actual y también muestra
todos los paquetes disponibles. Las instalaciones directas existentes pueden buscar esta versión en los ajustes de
Actualización de software de Kavor. No se requiere migración manual de datos del Workspace; el Node WebBrowser es
nuevo en esta versión y los datos existentes del Canvas siguen siendo compatibles.

- Windows x64 está disponible en Microsoft Store o como instalador NSIS asistido por Usuario. Microsoft firma y
  actualiza las instalaciones de Store. El instalador directo sigue sin firma, por lo que Microsoft SmartScreen
  puede exigir una confirmación explícita.
- macOS 13+ ofrece DMG separados para Apple Silicon e Intel, firmados con el Apple Developer ID de Kavor y
  notarizados por Apple. Las actualizaciones automáticas usan el ZIP de la arquitectura correspondiente y mantienen
  el DMG manual como alternativa.
- Linux x64 ofrece paquetes AppImage y DEB. AppImage admite actualizaciones administradas por Kavor con un reinicio
  coordinado explícito; las actualizaciones DEB se instalan manualmente desde la página de descarga.

## Limitaciones conocidas

- Los Nodes WebBrowser usan el Perfil de Navegador compartido y dedicado de Kavor; no reutilizan el perfil,
  extensiones, historial ni cookies del Chrome externo del Usuario. Eliminar un Node no borra datos compartidos de
  sitios; los ajustes globales de Kavor permiten borrar explícitamente caché, cookies y datos de sitios.
- El control del CodingAgent requiere que el Node WebBrowser esté activo en el Canvas. Los frames entre sitios
  aislados en otro proceso de Chromium se indican como omitidos y no pueden controlarse mediante el límite de
  seguridad del guest.
- Las solicitudes de permisos, diálogos de guardado, CAPTCHA, passkeys, certificados de cliente y autenticación del
  sistema operativo siguen siendo límites que debe resolver una persona.
- Los paquetes Windows ARM64 y Linux ARM64 no se incluyen hasta que sus gates de PTY nativo, SQLite, contención de
  procesos y runtime empaquetado puedan ejecutarse en entornos de CI equivalentes.
- Las descargas directas para Windows aún no tienen certificado de editor Authenticode; Microsoft firma los paquetes
  de Microsoft Store. La disponibilidad en Store puede llegar después de la release stable directa, tras la
  certificación independiente de Microsoft.
