# Kavor 1.7.0

## Aspectos destacados

- Añade copiar, cortar y pegar subgrafos seleccionados del Canvas mediante atajos de teclado estándar y menús
  contextuales. La transferencia puede permanecer en un Canvas o cruzar Workspaces y ventanas, conservando Nodes
  compatibles, Connections internas, posición y las operaciones de deshacer o rehacer.
- Mantiene activas las páginas WebBrowser cuando la persona cambia de Workspace, conserva el estado y permite que un
  CodingAgent conectado continúe trabajando en el navegador. Al regresar se presenta la misma página activa sin
  volver a cargarla.
- Pega archivos del portapapeles del sistema e imágenes PNG o JPEG en Terminal y CodingAgent como referencias de
  archivo seguras para el shell. Las imágenes copiadas se materializan de forma privada en el perfil local de Kavor.

## Correcciones

- Restaura en cada inicio de la aplicación los destinos Terminal y CodingAgent abiertos que pertenecen a Triggers en
  ejecución, de modo que el trabajo programado ya no dependa de iniciar Kavor explícitamente en segundo plano.
- Refina las instrucciones de Sticky Note para que un CodingAgent no reescriba de forma proactiva contenido del
  usuario o de otros agentes y actualice únicamente sus propias entradas claramente identificadas cuando esté
  autorizado.
- Actualiza Electron, Chromium, las herramientas de escritorio y las dependencias de ejecución a sus versiones
  estables compatibles más recientes, conservando solo los binarios nativos necesarios para cada plataforma.

## Instalación

Descarga Kavor desde <https://download.agentkavor.com>. La página detecta la plataforma actual y también muestra
todos los paquetes disponibles. Las instalaciones directas existentes pueden buscar esta versión en la configuración
de Software Update de Kavor. No se requiere migración manual de los datos del Workspace.

- Windows x64 está disponible en Microsoft Store o mediante el instalador NSIS asistido por usuario. Microsoft firma
  y actualiza las instalaciones de la Store. El instalador directo sigue sin firma, por lo que Microsoft SmartScreen
  puede requerir confirmación explícita.
- macOS 13+ ofrece DMG separados para Apple Silicon e Intel, firmados con el Apple Developer ID de Kavor y notarizados
  por Apple. Las actualizaciones automáticas utilizan el ZIP de la arquitectura correspondiente y mantienen el DMG
  como alternativa manual.
- Linux x64 ofrece paquetes AppImage y DEB. AppImage admite actualizaciones gestionadas por Kavor con un reinicio
  coordinado explícito; las actualizaciones DEB se instalan manualmente desde la página de descarga.

## Limitaciones conocidas

- El portapapeles de grafos del Canvas es local al proceso. Una copia o un corte puede cruzar Workspaces y ventanas
  de Kavor, pero no sobrevive al reinicio de la aplicación ni copia archivos físicos, sesiones de proveedores o
  historial de ejecución.
- El Browser Profile dedicado y compartido de Kavor acepta cualquier certificado de servidor para facilitar el
  desarrollo local. Una red hostil puede suplantar sitios abiertos en ese perfil, incluidos sitios donde el usuario
  inicia sesión. La sesión de la aplicación Kavor mantiene la validación normal de certificados de Chromium.
- Los Nodes WebBrowser no reutilizan el perfil, las extensiones, el historial ni las cookies del Chrome externo del
  usuario. Eliminar un Node no borra datos compartidos de los sitios; la configuración global de Kavor permite borrar
  explícitamente caché, cookies y datos de sitios.
- Los frames entre sitios aislados en otro proceso de Chromium se indican como omitidos y no pueden controlarse a
  través del límite de seguridad del guest.
- Los paquetes Windows ARM64 y Linux ARM64 no se incluyen hasta que sus gates nativos de PTY, SQLite, contención de
  procesos y runtime empaquetado puedan ejecutarse en entornos de CI equivalentes.
- Las descargas directas para Windows aún no tienen certificado de editor Authenticode; los paquetes de Microsoft
  Store están firmados por Microsoft. La disponibilidad en la Store puede ocurrir después de la versión estable
  directa debido a la certificación independiente de Microsoft.
