# Kavor 1.5.0

## Novedades

- Publica Kavor en Microsoft Store para Windows además de la descarga directa NSIS. Microsoft firma y distribuye el
  paquete de la Store y gestiona las actualizaciones de las instalaciones realizadas por ese canal.
- Firma las dos arquitecturas de macOS con Apple Developer ID y las notariza con Apple. Gatekeeper ahora puede
  verificar el editor de Kavor y el ticket de notarización sin mostrar el flujo inicial de desarrollador no
  identificado.
- Añade un selector de directorio de trabajo a cada CodingAgent. Una sesión puede iniciarse en cualquier directorio
  existente elegido por el usuario, incluso fuera del Workspace, conservando su asociación independiente de Git y
  worktree.
- Permite que CodingAgents conectados lean pasivamente los turnos completados de la sesión actual del provider de un
  peer accesible. El historial se pagina mediante cursor y leerlo no envía entradas al provider, no activa el peer
  ni crea un mensaje de Kavor.
- Mejora la entrega de contexto de Kavor Skills: las indicaciones para crear Specifications están disponibles antes
  de conectar una Specification y los Triggers reciben directamente su contexto operativo relevante.

## Correcciones

- Conserva completos los mensajes largos de sesiones de CodingAgent entre páginas de historial limitadas, sin
  truncar el texto restante.
- Detecta cambios de sesión del provider durante una lectura pasiva y rechaza la continuación obsoleta en lugar de
  combinar fragmentos de sesiones distintas.
- Valida las sesiones de Codex antes de reanudarlas y sustituye una sesión actual archivada externamente sin perder
  su historial restaurable del provider.
- Lee el historial completado de Antigravity entre páginas del provider y normaliza el historial pasivo en Claude
  Code, Codex, Antigravity, OpenCode y Grok.
- Mantiene los argumentos de inicio largos y las rutas de directorio seleccionadas dentro del panel de configuración
  de CodingAgent.

## Instalación

Descarga Kavor desde <https://download.agentkavor.com>. La página detecta la plataforma actual y también muestra
todos los paquetes disponibles. Las instalaciones directas existentes pueden buscar esta versión en Software
Update. No se requiere migración manual de los datos del Workspace; Kavor crea copias de seguridad de las bases de
datos locales compatibles antes de actualizar el esquema.

- Windows x64 está disponible en Microsoft Store o mediante el instalador NSIS asistido por usuario. Microsoft firma
  y actualiza las instalaciones de la Store. El instalador directo sigue sin firma, por lo que Microsoft SmartScreen
  puede requerir confirmación explícita.
- macOS 13+ ofrece DMG separados para Apple Silicon e Intel, firmados con Apple Developer ID de Kavor y notarizados
  por Apple. Esta versión migra la identidad ad-hoc anterior a la identidad estable de Developer ID. Si macOS rechaza
  la transición automática desde una versión anterior, instala manualmente el DMG correspondiente desde la página
  permanente de descargas; los datos existentes de Kavor se conservan.
- Linux x64 ofrece paquetes AppImage y DEB. AppImage admite actualizaciones gestionadas por Kavor con reinicio
  coordinado explícito; las actualizaciones DEB se instalan manualmente desde la página de descargas.

## Limitaciones conocidas

- Los Triggers de Schedule requieren que el runtime de Kavor esté activo, que el equipo esté despierto, que el
  usuario haya iniciado sesión y que la sesión de destino esté activa. Una ejecución perdida se registra y se ofrece
  como ejecución manual; nunca se ejecuta automáticamente al iniciar Kavor de nuevo.
- Los paquetes Windows ARM64 y Linux ARM64 no se incluyen hasta que sus validaciones nativas de PTY, SQLite,
  contención de procesos y runtime empaquetado puedan ejecutarse en entornos CI equivalentes.
- Las descargas directas para Windows aún no tienen certificado Authenticode; Microsoft firma los paquetes de la
  Microsoft Store.
- La primera migración desde una versión macOS ad-hoc a la versión firmada con Developer ID puede requerir instalar
  manualmente el DMG o autorizar una vez `Kavor Safe Storage` en Keychain. Las siguientes versiones firmadas conservan
  la misma identidad Apple Team.
- Microsoft Store puede publicar esta versión exacta después de completar su certificación independiente; los
  paquetes directos stable están disponibles inmediatamente en la página de descargas de Kavor.
