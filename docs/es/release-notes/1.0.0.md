# Kavor 1.0.0

## Aspectos destacados

- Coordina CodingAgents, Terminals, Specifications, Files y Sticky Notes en un Canvas persistente y local-first.
- Conecta Nodes para otorgar capacidades explícitas y visibles, preservando Guardrails y revisión humana.
- Deja que CodingAgents propongan cambios atómicos y permite localizar, revisar, aplicar o rechazar todo desde Header.
- Intercambia mensajes duraderos entre CodingAgents conectados y expone el catálogo revisado por la bridge MCP local.
- Conserva Workspace, Canvas, Terminal y sesiones de providers entre reinicios, con datos en la máquina del usuario.
- Informa updates y mantiene fallback manual permanente en <https://download.agentkavor.com>.

## Correcciones

- Mejora pan y zoom manteniendo el render rico proporcional a la escala de la viewport.
- Conserva estado y contadores de Terminal fuera de optimizaciones de visibilidad.
- Refuerza PTY, contención de procesos, limpieza y runtime empaquetado en plataformas compatibles.
- Hace atómicas las propuestas dependientes de Nodes y Connections, con una decisión humana y rollback conjunto.
- Añade Analytics anónimo limitado y Performance opcional sin contenido, rutas, prompts, comandos, output ni identidad.

## Instalación

Descarga Kavor en <https://download.agentkavor.com>. Windows x64 usa NSIS inicial sin firma; macOS 13+ ofrece DMG
arm64/x64 ad-hoc sin notarización y update manual; Linux x64 ofrece AppImage actualizable y DEB manual.

## Limitaciones conocidas

- Windows ARM64 y Linux ARM64 esperan gates nativos compatibles.
- Windows aún no tiene Authenticode.
- La instalación automática en macOS espera Developer ID y notarización.
- Microsoft Store no forma parte de esta versión.
