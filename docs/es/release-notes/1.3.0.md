# Kavor 1.3.0

## Aspectos destacados

- Añade Trigger Nodes de Schedule para trabajos únicos y recurrentes. Conecta un Trigger a un CodingAgent o Terminal,
  previsualiza las próximas ejecuciones en la zona horaria guardada, pausa o reanuda de inmediato, ejecuta bajo
  demanda y consulta un historial duradero con resultados perdidos, bloqueados, fallidos y completados.
- Añade ventanas independientes de Workspace sobre un único runtime compartido. Abre distintos Workspaces en
  paralelo, restaura la sesión anterior de ventanas, mantiene las sesiones de Terminal y CodingAgent aisladas por
  Workspace y, opcionalmente, deja Kavor disponible en la bandeja e iniciado en segundo plano al iniciar sesión.
- Sustituye la cola de propuestas del Canvas por edición atómica directa de CodingAgents autorizados. Un lote validado
  de cambios en Nodes, Connections, Files y Specifications se confirma como una sola operación o se revierte por
  completo.
- Convierte el grafo conectado en el límite de contexto compartido para CodingAgents. Los agentes alcanzables pueden
  intercambiar mensajes duraderos e inspeccionables, mientras los Guardrails de Connections directas siguen
  restringiendo cada par específico de recursos.
- Añade búsqueda acotada de archivos del Workspace mediante el binario ripgrep incluido, vistas previas más completas
  para enlaces de archivos y documentación oficial de Kavor expuesta en el catálogo MCP local.
- Unifica el estado de CodingAgents, Specifications y Triggers en el Header del Workspace y añade una superficie
  Acerca de con versión instalada, procedencia del build, actualización, soporte, seguridad e información legal.

## Correcciones

- Dirige la activación de una notificación nativa a la ventana existente que posee el Workspace correspondiente, sin
  abrir ventanas duplicadas ni cambiar una ventana ajena.
- Estabiliza el descubrimiento del entorno de providers, el inicio de CodingAgents, los diagnósticos del PTY Host, la
  recuperación de Terminals y la presentación PTY al abrir, cerrar, restaurar o alternar varias ventanas.
- Conserva las señales de finalización y atención de CodingAgents en segundo plano durante cambios de Workspace y
  envía notificaciones nativas solo cuando el trabajo relevante no está visible.
- Serializa mensajes en cola de CodingAgents y entregas de Triggers para que no sobrescriban la entrada humana ni
  adelanten trabajo ya aceptado por la sesión de destino.
- Aplaza el cambio de nombre de la sesión del provider cuando Claude Code no está disponible temporalmente, en vez de
  hacer fallar una sesión que sigue siendo utilizable.
- Contiene fallos del seguimiento de pantalla del Terminal y muestra fallos reales de inicio del host sin ocultarlos
  como un timeout genérico.

## Instalación

Descarga Kavor desde <https://download.agentkavor.com>. La página detecta la plataforma actual y también muestra todos
los paquetes disponibles. Las instalaciones directas existentes pueden buscar esta versión en Software Update de
Kavor. No se requiere una migración manual de datos del Workspace; Kavor crea una copia de seguridad de las bases
locales compatibles antes de actualizar el schema.

- Windows x64 usa el instalador NSIS asistido por usuario. Aún no está firmado, por lo que Microsoft SmartScreen puede
  pedir confirmación explícita.
- macOS 13+ ofrece DMG separados para arm64 y x64. Los builds tienen firma ad-hoc, pero no notarización; sigue las
  instrucciones de Gatekeeper de la página. Las actualizaciones administradas usan el ZIP de la arquitectura correcta
  y ofrecen un reinicio coordinado tras revalidar el artefacto. La descarga manual siempre permanece disponible.
- Linux x64 ofrece AppImage y DEB. AppImage admite actualizaciones administradas con reinicio explícito; DEB se
  actualiza manualmente desde la página de descarga.

## Limitaciones conocidas

- Los Triggers de Schedule requieren que el runtime de Kavor esté activo, la máquina despierta, el usuario con sesión
  iniciada y la sesión de destino activa. Una ocurrencia perdida mientras Kavor no estaba activo se registra y se
  ofrece como ejecución manual explícita; nunca se ejecuta automáticamente en el siguiente inicio.
- Windows ARM64 y Linux ARM64 esperan gates nativos de PTY, SQLite, contención de procesos y runtime empaquetado en
  entornos de CI equivalentes.
- Las descargas directas para Windows aún no tienen certificado Authenticode.
- macOS aún no tiene firma Developer ID ni notarización. Gatekeeper puede pedir confirmación y reemplazar un build
  ad-hoc puede volver a solicitar acceso a `Kavor Safe Storage` en Keychain.
- Microsoft Store no forma parte de esta versión.
