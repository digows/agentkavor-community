# Kavor 1.0.1

## Aspectos destacados

- Recupera herramientas nativas sin salir del Workspace: guía la instalación de Git y providers, muestra progreso y
  fallos accionables y actualiza la detección sin reiniciar Kavor.
- Ofrece perfiles globales `Auto`, `Full` y `Reduced`; `Auto` conserva feedback y reduce efectos con movimiento
  reducido del sistema o renderizado Chromium por software.
- Administra updates desde Settings con un estado único, check explícito y fallback manual. Badges persistentes
  mantienen visible el update durante descarga y hasta su instalación.
- Muestra opcionalmente en notificaciones un preview de texto limitado de la última respuesta cuando el provider lo
  ofrece; una opción de privacidad puede ocultarlo en lock screens.
- Inicia, detiene, reinicia y configura CodingAgents desde su Node; el rename sincroniza la sesión nativa si es posible.
- Reduce los paquetes eliminando locales, artefactos, source maps, tests y binarios ajenos sin quitar runtime ni avisos.

## Correcciones

- Rediseña output con backpressure limitado, batches ordenados, acknowledgements por attachment y checkpoints finales;
  las ráfagas ya no bloquean controles ni dejan que attachments viejos consuman output nuevo.
- Mejora presentación durante pan, zoom, remount y startup: los PTY quedan fuera del compositor escalado y la
  hidratación aparece después del checkpoint autoritativo.
- Evita que decoraciones transparentes y Locate oculten portals de Terminal/CodingAgent en cambios de foco.
- Corrige posición y preview de drag en todo zoom, incluso si cambia la viewport con el puntero quieto.
- Descarta resultados Git antiguos al cambiar Workspace, repositorio o target, limita controles a repositorios válidos
  y comparte discovery y scans concurrentes.
- Hace atómico el refresh entre Electron main y Process Host para detectar herramientas nuevas con un `PATH` fresco.
- Refuerza Windows para hooks PowerShell, ambiente, Git local, `winget` y Job Objects repetidos o concurrentes.
- Mejora recuperación de CodingAgents con feedback del installer, retry, opción manual, detección fresca y errores
  explícitos si el provider termina antes de mostrar su Terminal.
- Aísla y limita actividad asíncrona por sesión; Antigravity rechaza previews antiguos o ajenos.
- Conserva el Terminal Node si falla el teardown al eliminarlo y cierra el proceso antes del Node cuando tiene éxito.
- Separa revisiones de Sticky Notes de movimientos y resize concurrentes.
- Evita que checks concurrentes o estado inicial antiguo reemplacen disponibilidad, descargas o errores nuevos.
- Suaviza Authentication, onboarding, activación y startup para evitar flashes o escenas vacías.
- Aísla por completo los perfiles de desarrollo y producción: SQLite, credenciales, ventana, cookies, cache y storage.
- Cierra conexiones ociosas de Codex app-server al liberar la última sesión.
- Hace resistente Analytics anónimo de startup a reloads y red temporal, manteniendo Analytics detallado y Performance
  bajo control del usuario y excluyendo contenido, prompts, comandos, rutas, output e identidad.

## Instalación

Descarga Kavor en <https://download.agentkavor.com>. Windows x64 usa NSIS sin firma; macOS 13+ ofrece DMG arm64/x64
ad-hoc sin notarización y actualización manual; Linux x64 ofrece AppImage actualizable y DEB manual.

## Limitaciones conocidas

- Windows ARM64 y Linux ARM64 esperan gates nativos compatibles.
- Windows aún no tiene Authenticode.
- La instalación automática en macOS espera Developer ID y notarización.
- Microsoft Store no forma parte de esta versión.
