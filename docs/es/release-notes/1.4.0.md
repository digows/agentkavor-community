# Kavor 1.4.0

## Novedades

- Añade Grok como provider de CodingAgent, mediante un cliente ACP con configuración, entrada interactiva y
  compatibilidad de nombres y catálogo de sesiones a través de la convención de wire por método de extensión de ACP.
- Añade OpenCode como provider de CodingAgent, con un ciclo de vida de servidor local autenticado y compatibilidad
  para crear, reanudar, bifurcar, listar y nombrar sesiones, incluida la instalación de la versión de Windows sin
  necesidad de WSL.
- Añade una herramienta de selección de provider en la paleta del Canvas, de modo que colocar un Node de CodingAgent
  incluya una elección explícita de provider, con un ayudante de gesto compartido (pulsar frente a arrastrar)
  reutilizado en la paleta.
- Renderiza imágenes en línea Sixel e iTerm2 en las vistas de PTY del Terminal y del CodingAgent integrados,
  reflejando lo que el proceso subyacente ya pueda emitir.
- Admite múltiples raíces de specification por Workspace, con las actualizaciones correspondientes en la
  configuración de Specification, el panel de Backlog y el árbol de carpetas, de modo que las Specifications puedan
  organizarse en más de una raíz.

## Correcciones

- Corrige una condición de carrera en el traspaso de Onboarding en la que una ruta de Workspace cargada de forma
  diferida podía suspenderse y borrar el indicador de preparación de Onboarding, dejando el Canvas hidratado detrás
  de una etapa que Onboarding nunca liberaba.
- Revierte un session id de provider que un adapter inventó pero nunca confirmó cuando el PTY interactivo finaliza
  antes de estar listo para el inicio, de modo que un fallo en el primer lanzamiento ya no puede dejar un Node
  apuntando permanentemente a una sesión que el provider nunca creó.
- Restringe la protección del entorno de lanzamiento del provider a las dos variables que Kavor realmente posee, en
  lugar de todo el entorno ambiental heredado, y añade un resultado explícito de "actualización necesaria" en el
  inicio del provider, junto al ya existente de "comando ausente", mostrado en la superposición de instalación, la
  barra de herramientas y el chrome del node.
- Persiste el arrastre de varios nodes en el Canvas como un único movimiento agrupado en lugar de escrituras
  separadas por node.
- Estabiliza la presentación diferida de PTY, la resolución del entorno de login shell y el rastreador de pantalla
  de terminal xterm.
- Corrige los nodes de CodingAgent de OpenCode que se quedaban mostrando "Working" para siempre cuando el transporte
  de eventos del provider perdía la transición de estado inactivo; ahora Kavor reconcilia el estado real de la
  sesión directamente cuando esto ocurre.

## Instalación

Descarga Kavor desde <https://download.agentkavor.com>. La página detecta la plataforma actual y también muestra
todos los paquetes disponibles. Las instalaciones directas existentes pueden buscar esta versión en la
configuración de Software Update de Kavor. No se requiere ninguna migración manual de los datos del Workspace;
Kavor realiza una copia de seguridad de las bases de datos locales admitidas antes de aplicar actualizaciones de
esquema.

- Windows x64 usa el instalador NSIS asistido por usuario. El instalador todavía no está firmado, por lo que
  Microsoft SmartScreen puede requerir confirmación explícita.
- macOS 13+ ofrece DMG independientes para arm64 y x64. Los builds tienen firma ad-hoc, pero no están notarizados;
  sigue las instrucciones de Gatekeeper de la página de descarga. Las actualizaciones gestionadas por Kavor usan el
  ZIP correspondiente a la arquitectura y ofrecen un reinicio coordinado explícito tras revalidar el artefacto en
  caché. La descarga manual sigue estando disponible en todo momento.
- Linux x64 ofrece paquetes AppImage y DEB. AppImage admite actualizaciones gestionadas por Kavor con reinicio
  coordinado explícito; las actualizaciones DEB se instalan manualmente desde la página de descarga.

## Limitaciones conocidas

- Los Schedule Trigger requieren que el runtime de Kavor esté en ejecución, la máquina esté despierta, el usuario
  haya iniciado sesión y la sesión de destino esté activa. Una ocurrencia perdida mientras Kavor no estaba en
  ejecución se registra y se ofrece como una ejecución manual explícita; nunca se ejecuta automáticamente en el
  siguiente inicio.
- Los paquetes de Windows ARM64 y Linux ARM64 no están incluidos hasta que sus gates nativos de PTY, SQLite,
  contención de procesos y runtime empaquetado puedan ejecutarse en entornos de CI equivalentes.
- Las descargas directas para Windows todavía no tienen certificado de publisher Authenticode.
- Los paquetes de macOS todavía no tienen firma Developer ID ni notarización. Gatekeeper puede requerir confirmación
  manual, y sustituir un build ad-hoc puede hacer que macOS solicite de nuevo acceso a `Kavor Safe Storage` en el
  Keychain.
- La distribución a través de la Microsoft Store no forma parte de esta versión.
