# Kavor 1.7.1

## Novedades

- Actualiza Electron, Chromium, React, las herramientas de UI y las dependencias de runtime a versiones estables
  compatibles. Este hotfix conserva los flujos existentes de Canvas y CodingAgent sin exponer interfaces experimentales.

## Correcciones

- Restaura la entrada nativa de ratón y teclado en WebBrowser después de cambiar de Workspace, sin recargar la página
  que permanece activa ni bloquear los controles interactivos del navegador.
- Limpia el estado de popup de la página de origen cuando se cierra un popup de WebBrowser, elimina su marco y
  permite abrir nuevos popups sin limpiar un popup que lo haya sustituido.
- Corrige los colores de Markdown en el modo de lectura claro, incluidos títulos, enlaces, código, citas y tablas.
  Alternar entre los modos de lectura claro y oscuro ahora aplica un estilo consistente en las vistas compacta y normal.
- Conserva las horas con precisión de minutos en las programaciones únicas de Trigger tras actualizar las dependencias.
- Trata literalmente las rutas vigiladas del Workspace, sin expandir la sintaxis glob, y conserva la detección
  recursiva de directorios recién creados.
- Restaura la compatibilidad con el ejecutable nativo de pnpm al compilar paquetes del Workspace, recompilar
  dependencias nativas y generar los avisos de terceros incluidos en la aplicación empaquetada.
- Actualiza las dependencias gRPC y FTP afectadas y conserva el contrato revisado de los schemas de tools de CodingAgent.

## Instalación

Descarga Kavor desde <https://download.agentkavor.com>. Las instalaciones directas existentes pueden buscar esta
versión en los ajustes de Software Update. No es necesaria una migración manual de los datos del Workspace.

- Windows x64 está disponible en Microsoft Store o mediante el instalador NSIS asistido por usuario. Microsoft firma
  y actualiza las instalaciones de Store. El instalador directo sigue sin firma, por lo que Microsoft SmartScreen
  puede exigir una confirmación explícita.
- macOS 13+ ofrece DMG separados para Apple Silicon e Intel, firmados con el Apple Developer ID de Kavor y notarizados
  por Apple. Las actualizaciones automáticas usan el ZIP de la arquitectura correspondiente y mantienen el DMG como
  alternativa manual.
- Linux x64 ofrece paquetes AppImage y DEB. AppImage admite actualizaciones gestionadas por Kavor con un reinicio
  coordinado explícito; las actualizaciones DEB se instalan manualmente desde la página de descarga.

## Limitaciones conocidas

- Un aviso de seguridad en la dependencia upstream `braces` sigue sin un parche publicado. La vigilancia recursiva
  del Workspace ahora desactiva la expansión glob; es una mitigación, no una dependencia corregida.
- El Browser Profile dedicado y compartido de Kavor acepta cualquier certificado de servidor para facilitar el
  desarrollo local. Una red hostil puede suplantar sitios abiertos en ese perfil, incluidos aquellos donde el usuario
  inicia sesión. La sesión de la aplicación Kavor mantiene la verificación normal de certificados de Chromium.
- Los Nodes WebBrowser no reutilizan el perfil, las extensiones, el historial ni las cookies del Chrome externo del
  usuario. Eliminar un Node no borra los datos compartidos de los sitios; los ajustes globales de Kavor permiten
  limpiar explícitamente la caché, las cookies y los datos de los sitios.
- Los frames entre sitios aislados en otro proceso de Chromium se notifican como omitidos y no pueden controlarse
  a través del límite de seguridad del guest.
- Los paquetes Windows ARM64 y Linux ARM64 no se incluyen hasta que sus gates nativos de PTY, SQLite, contención de
  procesos y runtime empaquetado puedan ejecutarse en entornos CI correspondientes.
- Las descargas directas para Windows aún no tienen un certificado de editor Authenticode; Microsoft firma los
  paquetes de Microsoft Store. La disponibilidad en Store puede llegar después de la release stable directa, una
  vez completada la certificación independiente de Microsoft.
