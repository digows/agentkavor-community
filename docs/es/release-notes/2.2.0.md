# Kavor 2.2.0

## Novedades destacadas

- Los CodingAgents pueden iniciar, reiniciar, detener y hacer Fork de sesiones alcanzables cuando **Allow workspace editing** y la petición autorizada lo permiten. Fork depende del provider y del historial nativo disponible.
- La edición atómica del Canvas incluye eliminar Nodes alcanzables, cerrando la ejecución y conciliando Connections y mensajes pendientes, sin borrar fuentes canónicas ni Git worktrees.

## Correcciones

- Valida la asociación con un worktree preparado antes de iniciar el CodingAgent y mantiene separados la raíz del Workspace, el directorio activo del agente y el estado Git de cada checkout.
- Corrige las transiciones de sesiones en ejecución al crear, seleccionar o dejar un worktree. La reanudación usa la identidad nativa existente cuando se admite; las sesiones detenidas deliberadamente permanecen detenidas.
- Protege las asociaciones Git frente a operaciones concurrentes e impide eliminar o finalizar worktrees referenciados por otros CodingAgents. Los fallos no eliminan worktrees preparados por el usuario como si fueran temporales del intento.
- Conserva la etapa y el diagnóstico de fallos de inicio, incluida la salida anticipada del provider o una pantalla que permanece vacía. Un intento corregido puede iniciarse otra vez en el mismo Node.
- Conserva el primer mensaje pendiente entre un inicio fallido y su reintento, evitando repetir una entrega ya consumida.
- Mejora la detección de entrada disponible en Claude Code sin confundir sugerencias visuales con texto escrito por el usuario. Los borradores, preguntas y aprobaciones humanas siguen protegidos.

## Instalación

Descarga Kavor en <https://download.agentkavor.com> o busca actualizaciones en los ajustes de Software Update.

- **Windows x64:** Microsoft Store o instalador NSIS asistido por el usuario. Microsoft firma y actualiza las instalaciones de la Store. El instalador directo sigue sin firma y puede mostrar una advertencia de SmartScreen.
- **macOS 13+:** DMG separados, firmados y notarizados, para Apple Silicon e Intel. Las actualizaciones automáticas usan el ZIP de la arquitectura correspondiente; el DMG sigue disponible para instalación manual.
- **Linux x64:** AppImage y DEB. AppImage admite actualizaciones gestionadas por Kavor con reinicio coordinado explícito; las actualizaciones DEB se instalan manualmente.

## Limitaciones conocidas

- Fork depende de las capacidades y la versión instalada del provider. La integración de Antigravity no ofrece Fork; crear otra sesión sin historial no es un sustituto equivalente.
- Un Git worktree no instala dependencias ni copia automáticamente configuración local o credenciales. Preparar el entorno sigue dependiendo del proyecto.
- La disponibilidad del provider y la entrega de un mensaje no prueban la conclusión de la tarea. Los límites, autenticación y disponibilidad de los servicios siguen bajo control de los providers.
- No se incluyen paquetes Windows ARM64 ni Linux ARM64. La disponibilidad en Microsoft Store puede ser posterior a la publicación directa por su certificación independiente.
