# Kavor 1.1.0

## Aspectos destacados

- Sustituye en paquetes nuevos el inicio de sesión por protocolo privado del sistema por un callback breve en
  `127.0.0.1`, vinculado al intento. Google, GitHub y el enlace de correo sin contraseña vuelven directamente a Kavor
  desde el navegador, con PKCE para providers y un fallback explícito por portapapeles.
- Añade consentimiento legal de primer uso a Authentication y mantiene la sincronización del ciclo de la cuenta tras
  la API pública versionada de Kavor.
- Permite a CodingAgents proponer File y Specification Nodes mediante el mismo catálogo atómico del Canvas. Las
  Connection Skills ahora comienzan con las reglas aplicables y contexto Git-aware.
- Mejora presentación, cambio de Workspace, inicio y recuperación de Terminals y CodingAgents bajo actividad PTY.
- Simplifica navegación y acciones de Specifications sin perder acceso directo al trabajo basado en Files.

## Correcciones

- Corrige el intercambio de authorization code de Google Desktop y el intercambio confidencial server-side de GitHub,
  completando Authentication por loopback sin distribuir credenciales de GitHub en la aplicación.
- Elimina el protocolo privado de los paquetes desktop nuevos, evita fallos del handler de Linux y conserva rutas de
  compatibilidad hospedadas para versiones antiguas compatibles.
- Protege callbacks loopback contra intentos antiguos, repetidos, malformados o incompatibles y mantiene credenciales
  y respuestas fuera del almacenamiento persistente y de los logs.
- Corrige hidratación PTY y ownership de presentación al cambiar de Workspace, recuperando handshakes retrasados o
  interrumpidos sin inventar salidas de procesos.
- Reduce trabajo innecesario del Canvas y paneles alrededor de Terminal, CodingAgent, File y Specification Nodes y
  aclara las acciones de Specifications.
- Lleva el descubrimiento de releases a la API estable de descarga de Kavor, eliminando el acoplamiento directo al host.

## Instalación

Descarga Kavor desde <https://download.agentkavor.com>. La página detecta la plataforma y muestra todos los paquetes.

- Windows x64 usa NSIS por usuario, aún sin firma; SmartScreen puede pedir confirmación.
- macOS 13+ ofrece DMG arm64 y x64 con firma ad-hoc sin notarización. Las actualizaciones usan el ZIP correcto y un
  reinicio coordinado tras revalidar el artefacto. La descarga manual siempre está disponible.
- Linux x64 ofrece AppImage y DEB. AppImage admite actualizaciones con reinicio; DEB se instala manualmente.

## Limitaciones conocidas

- Versiones hasta 1.0.6 ya no pueden iniciar sesión nueva con GitHub porque el OAuth App legado se retiró tras el
  cambio al provider directo. Las sesiones existentes siguen válidas; instala Kavor 1.1.0 para entrar de nuevo.
- Windows ARM64 y Linux ARM64 esperan gates nativos de PTY, SQLite, contención y runtime empaquetado.
- Windows aún no tiene certificado Authenticode.
- macOS aún no tiene Developer ID ni notarización; Gatekeeper puede pedir confirmación y acceso al Keychain.
- Microsoft Store no forma parte de esta versión.
