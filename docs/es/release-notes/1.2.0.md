# Kavor 1.2.0

## Aspectos destacados

- Añade vistas previas enriquecidas en File Nodes para imágenes y PDF. Los PDF grandes renderizan solo las páginas
  visibles, mientras límites controlados de imagen, Canvas y archivo evitan un uso ilimitado de memoria.
- Completa el ciclo de vida de Files y Specifications: crea una Specification desde el menú del Canvas, renombra o
  elimina fuentes desde el Workspace, organiza carpetas y sincroniza Nodes existentes con el sistema de archivos.
- Permite soltar rutas del panel Files directamente en sesiones de Terminal y CodingAgent, con comillas adaptadas al
  shell activo.
- Amplía las propuestas atómicas del Canvas con creación de Specifications, progreso persistente de la aplicación y
  recuperación de efectos reversibles en Files y Specifications.
- Hace que cada Kavor Skill anuncie la llamada exacta `kavor.skill.get("<name>")` que un CodingAgent usa para cargarla.

## Correcciones

- Conserva campos personalizados, comentarios y orden del frontmatter YAML, además de nombres y rutas relativas al
  Workspace, al editar Specifications.
- Estabiliza la hidratación de Terminals y CodingAgents para que un estado PTY retrasado no pierda contenido restaurado
  ni duplique ownership al cambiar de Workspace.
- Mantiene los appends de Sticky Notes como bloques Markdown distintos, no crea revisiones vacías y aplica límites por
  punto de código Unicode.
- Refuerza las mutaciones de Files y Specifications con cambios serializados del Workspace, contención de rutas,
  invalidación de fuentes y fallos explícitos.
- Resuelve los avisos de seguridad presentes en el grafo anterior de dependencias de producción.

## Instalación

Descarga Kavor desde <https://download.agentkavor.com>. La página detecta tu plataforma y muestra todos los paquetes.

- Windows x64 usa el instalador NSIS asistido por usuario. Aún no está firmado; Microsoft SmartScreen puede pedir
  confirmación explícita.
- macOS 13+ ofrece DMG arm64 y x64. Los builds tienen firma ad-hoc, pero no notarización; sigue las instrucciones de
  Gatekeeper. Las actualizaciones administradas usan el ZIP de la arquitectura correcta y reinicio coordinado tras
  revalidar el artefacto. La descarga manual siempre permanece disponible.
- Linux x64 ofrece AppImage y DEB. AppImage admite actualizaciones administradas con reinicio explícito; DEB se
  actualiza manualmente desde la página de descarga.

## Limitaciones conocidas

- Windows ARM64 y Linux ARM64 esperan gates nativos de PTY, SQLite, contención de procesos y runtime empaquetado en CI.
- Las descargas directas para Windows aún no tienen certificado Authenticode.
- macOS aún no tiene firma Developer ID ni notarización. Gatekeeper puede pedir confirmación y reemplazar un build
  ad-hoc puede volver a solicitar acceso a `Kavor Safe Storage` en Keychain.
- Microsoft Store no forma parte de esta versión.
