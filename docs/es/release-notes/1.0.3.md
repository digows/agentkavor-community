# Kavor 1.0.3

## Aspectos destacados

- Restaura Terminal y CodingAgent empaquetados en macOS usando Electron Helper para la bridge de contexto y cargando
  Windows Job Object solo en Windows.
- Hace su presentación resistente a pan, zoom, remount y startup. El output hidratado aparece después del checkpoint
  autoritativo, sin perder la sesión cuando cambia su presentación.
- Añade canales stable y prerelease explícitos; stable es el predeterminado y prerelease requiere opt-in fuera del Workspace.
- Incluye identidad de build verificable y refuerza validación nativa antes de alcanzar stable.

## Correcciones

- Evita que Process Host falle antes del handshake en macOS/Linux al no empaquetar Job Object y `koffi` de Windows.
- Corrige el runtime de la bridge macOS para que el ejecutable no rechace el entry point Node en background.
- Añade un gate de startup que espera el handshake y verifica el runtime por plataforma sin ocultar crashes como timeout.
- Rediseña hidratación PTY y ownership para conservar output, readiness, acknowledgements, foco y controles entre capas.
- Elimina estado de presentación persistido y migra bases para derivarlo de recursos vivos.
- Mejora startup, restart, worktree, disponibilidad y recuperación de CodingAgents.
- Limita respuestas Antigravity a la petición terminada y acepta variantes soportadas sin filtrar respuestas antiguas.
- Impide que checks viejos reemplacen estado nuevo, conserva detalles tras reload y añade el icono a notificaciones.
- Mejora posicionamiento, Connections, transiciones, startup, Settings, Git, Specifications y presentación de Nodes.
- Tolera writes transitorios de Chromium en el canary empaquetado, evitando fallos por `ENOTEMPTY` temporal.
- Simplifica CI: diagnóstico manual para una plataforma, tag para la matriz completa y stable al 100% con pausa reversible.

## Instalación

Descarga Kavor en <https://download.agentkavor.com>. Windows x64 usa NSIS sin firma; macOS 13+ ofrece DMG arm64/x64
ad-hoc sin notarización y actualización manual; Linux x64 ofrece AppImage actualizable y DEB manual.

## Limitaciones conocidas

- Windows ARM64 y Linux ARM64 esperan gates nativos compatibles.
- Windows aún no tiene Authenticode.
- La instalación automática en macOS espera Developer ID y notarización.
- Microsoft Store no forma parte de esta versión.
