# Kavor 2.3.0

## Novedades destacadas

- **Diagramas en el Canvas:** archivos de 13 familias de formatos, entre ellos Mermaid, PlantUML con C4, Graphviz,
  D2, Excalidraw y draw.io. Alterna entre Diagram, Source y Split, consulta los errores de renderizado y exporta SVG
  o PNG. Excalidraw permite edición visual; draw.io es de solo visualización en Kavor.
- **Documentación organizada en el filesystem:** Specifications y Diagrams comparten Documentation roots. Configura
  una Diagrams folder relativa a la primera raíz, recorre el árbol real de carpetas y crea desde la toolbar o el
  formulario inline. El destino predeterminado sigue siendo `docs/diagrams/`; cambiarlo no mueve archivos existentes.
- **Más formas de añadir contexto:** arrastra archivos del sistema al Canvas o pega archivos, datos de imagen, una
  URL o texto. Los archivos permanecen en su ubicación original; las imágenes pegadas se guardan como PNG en el
  Workspace. Las fuentes externas reflejan cambios en disco, y los archivos sin preview enriquecido muestran una
  tarjeta con detalles y acciones.

## Correcciones

- Auto respeta las cuentas excluidas de la participación en el Workspace y conserva las elecciones Manual. Cuando
  las alternativas participantes no son utilizables, las sesiones existentes se mantienen y se reconsideran cuando
  se recupera una cuenta elegible, sin convertir una exclusión en permiso para una nueva ejecución.
- Las consultas de uso de Codex dejan de reintentarse automáticamente tras la revocación definitiva de credenciales;
  la recuperación explícita sigue disponible mediante Refresh iniciado por una persona.
- Se corrige el ajuste de dimensiones de Terminals y CodingAgents al presentar sesiones preiniciadas y cambiar el
  zoom, conservando la sesión nativa en lugar de recrearla para ajustar su presentación.

## Instalación

Actualiza desde Kavor o utiliza la [página de descargas](https://agentkavor.com/downloads). Si el actualizador no está
disponible, los paquetes siguen accesibles en [download.agentkavor.com](https://download.agentkavor.com).

## Limitaciones conocidas

- Los engines y recursos de Diagramas se obtienen bajo demanda. El primer uso puede requerir internet; la caché
  permite reutilizar recursos ya descargados, pero el contenido con URLs externas todavía puede depender de la red.
- draw.io no tiene editor en Kavor y D2 no ofrece TALA. La disponibilidad de modelos, la lectura del uso y la
  reanudación de sesiones siguen dependiendo de las capacidades y la autenticación del harness elegido.
