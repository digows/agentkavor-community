# Kavor 1.6.2

## Novedades

- Amplía los controles humanos del Node WebBrowser con un botón explícito de DevTools, la apertura de la página HTTP
  o HTTPS activa en el navegador del sistema y acciones nativas para cortar, copiar, pegar y seleccionar todo en el
  campo de dirección.
- Gestiona los desafíos de autenticación HTTP y proxy dentro del Node WebBrowser y muestra contadores por página de
  errores de consola y reglas de red de CodingAgents, con acciones directas para inspeccionar errores o borrar reglas
  activas.
- Abre servidores de desarrollo local con certificados autofirmados, caducados o emitidos por autoridades privadas
  dentro del Browser Profile dedicado de Kavor, sin debilitar la validación de certificados de la sesión de la
  aplicación Kavor.

## Correcciones

- Hace que la presentación de nueva pestaña del WebBrowser ocupe todo el viewport y mantiene el progreso de carga en
  el borde de la barra de estado sin mover el contenido de la página.
- Refina el menú de creación del Canvas para que los providers de CodingAgent y los tipos de Node tengan agrupación
  coherente y colores de icono que identifiquen cada elemento.
- Hace que la publicación en Microsoft Store valide las credenciales protegidas y el acceso a Partner Center antes
  de consumir minutos de build nativo, y serializa los envíos sin cancelar una operación activa de Store.

## Instalación

Descarga Kavor desde <https://download.agentkavor.com>. La página detecta la plataforma actual y también muestra todos
los paquetes disponibles. Las instalaciones directas existentes pueden buscar esta versión en la configuración de
Software Update de Kavor. No se requiere ninguna migración manual de los datos del Workspace.

- Windows x64 está disponible en Microsoft Store o mediante el instalador NSIS asistido por usuario. Microsoft firma
  y actualiza las instalaciones de Store. El instalador directo permanece sin firmar, por lo que Microsoft SmartScreen
  puede exigir una confirmación explícita.
- macOS 13+ ofrece DMG separados para Apple Silicon e Intel, firmados con el Apple Developer ID de Kavor y notarizados
  por Apple. Las actualizaciones automáticas utilizan el ZIP de la arquitectura correspondiente y mantienen el DMG
  como alternativa manual.
- Linux x64 ofrece paquetes AppImage y DEB. AppImage admite actualizaciones administradas por Kavor con un reinicio
  coordinado explícito; las actualizaciones de DEB se instalan manualmente desde la página de descarga.

## Limitaciones conocidas

- El Browser Profile dedicado y compartido de Kavor acepta cualquier certificado de servidor para facilitar el
  desarrollo local. Por ello, una red hostil puede suplantar sitios abiertos en ese perfil, incluidos aquellos donde
  el usuario inicia sesión. La sesión de la aplicación Kavor conserva la validación normal de certificados de
  Chromium.
- Los Nodes WebBrowser no reutilizan el perfil, las extensiones, el historial ni las cookies del Chrome externo del
  usuario. Eliminar un Node no borra los datos compartidos de los sitios; la configuración global de Kavor permite
  borrar explícitamente caché, cookies y datos de sitios.
- El control por CodingAgent requiere que el Node WebBrowser esté activo en el Canvas. Los frames entre sitios
  aislados en otro proceso de Chromium se indican como omitidos y no pueden controlarse a través del límite de
  seguridad del guest.
- Los paquetes Windows ARM64 y Linux ARM64 no se incluyen hasta que sus gates nativos de PTY, SQLite, contención de
  procesos y runtime empaquetado puedan ejecutarse en entornos de CI equivalentes.
- Las descargas directas de Windows aún no tienen un certificado de publisher Authenticode; los paquetes de Microsoft
  Store están firmados por Microsoft. La disponibilidad en Store puede llegar después de la release stable directa
  debido a la certificación independiente de Microsoft.
