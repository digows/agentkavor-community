# Kavor 1.0.6

## Aspectos destacados

- Hace mucho más resistentes las sesiones de Terminal y CodingAgent con output sostenido, actividad concurrente y
  varios Workspaces. Los PTY usan un host dedicado, aislado de Git, instaladores, probes y otras operaciones limitadas.
- Separa procesos vivos de su presentación en el Canvas. Cambiar Workspace, mover, ampliar, remontar u ocultar un Node
  puede desacoplar y restaurar su viewport sin reiniciar el proceso ni perder output ordenado.
- Rediseña Software Update alrededor de `Restart & update`, una acción explícita y verificada. Progreso, estado, errores
  y recuperación viven en Settings; Header y notificaciones solo llaman la atención.
- Añade un diálogo post-update offline que, tras el primer inicio sano, muestra una sola vez Highlights, Fixes y Known
  limitations de todas las versiones saltadas.
- Aplica al instante las preferencias de Workspace; solo el nombre conserva una acción Save explícita.

## Correcciones

- Elimina el dominio de fallo compartido del process host que podía terminar sesiones no relacionadas bajo bloqueos.
- Añade procesamiento PTY justo y limitado y un canal tipado directo, evitando que una sesión ruidosa monopolice input,
  resize, interrupción, checkpoint u output de otra.
- Corrige hidratación PTY en cambios de visibilidad y Workspace: pinta primero el checkpoint autoritativo sin duplicar
  output, conservar viewports antiguos ni reiniciar procesos ocultamente.
- Recupera automáticamente una interrupción del host PTY, respeta Stop y evita launches duplicados o salidas inventadas.
- Separa el host de operaciones del PTY y centraliza el entorno de login para que la detección no compita con el PTY.
- Corrige la identidad del context hook de CodingAgent en launches Node y separa la inyección Kavor de procesos comunes.
- Impide instalar un update al cerrar normalmente: revalida el cache con SHA-512 antes del shutdown y mantiene Kavor
  abierto con recuperación manual si falla.
- Corrige estado antiguo del updater, agrupa reinicios repetidos y añade diagnósticos locales limitados con rotación.
- Elimina toasts globales, aplica al instante el canal prerelease y muestra readiness pulsante en Header y restart.
- Revierte preferencias inmediatas de animación, telemetry, performance, path y canal si su persistencia falla.
- Añade sincronización Firebase firmada e idempotente con el registro de comunicaciones, retries limitados y
  reconciliación diaria.
- Alinea el startup empaquetado con hosts lazy: un inicio ocioso no arranca PTY ni operaciones antes de necesitarlos.

## Instalación

Descarga Kavor desde <https://download.agentkavor.com>. Windows x64 usa NSIS sin firma; macOS 13+ ofrece DMG arm64 y
x64 ad-hoc sin notarización y updates por ZIP revalidado; Linux x64 ofrece AppImage actualizable y DEB manual.

## Limitaciones conocidas

- Windows ARM64 y Linux ARM64 esperan gates nativos de PTY, SQLite, contención y runtime empaquetado.
- Windows aún no tiene certificado Authenticode.
- macOS aún no tiene Developer ID ni notarización; Gatekeeper puede pedir confirmación y acceso al Keychain.
- Microsoft Store no forma parte de esta versión.
