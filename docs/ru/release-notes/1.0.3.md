# Kavor 1.0.3

## Основные изменения

- Terminal/CodingAgent восстановлены в macOS package: context bridge использует Electron Helper, Job Object загружается только в Windows.
- Presentation устойчива к pan, zoom, remount и Workspace startup; hydrated output появляется после checkpoint без потери session.
- Добавлены stable/prerelease channels: stable по умолчанию, prerelease — opt-in отдельно от Workspace data.
- Packages содержат проверяемый build identity; native validation перед stable усилена.

## Исправления

- Process Host не падает до handshake на macOS/Linux без Windows Job Object и `koffi`.
- Исправлен macOS bridge runtime, чтобы main executable не отклонял background Node entry point.
- Startup gate ждёт handshake и проверяет platform runtime, не маскируя early crash как timeout.
- PTY hydration/ownership сохраняют output, readiness, acknowledgements, focus и controls при переходе между layers.
- Persisted presentation status удалён, базы мигрированы на вычисление availability из live resources.
- Улучшены CodingAgent startup, restart, worktree, availability и recovery provider/Terminal.
- Antigravity extraction ограничена completed request и не выдаёт stale responses.
- Старые update checks не заменяют новые; details переживают reload; в OS notifications добавлен Kavor icon.
- Улучшены placement, Connections, panels, Workspace startup, Settings, Git, Specifications и Node presentation.
- Telemetry canary терпит временные Chromium writes и не блокирует release из-за временного `ENOTEMPTY`.
- Native CI упрощён: manual diagnostic для одной platform, tag для full matrix, stable по умолчанию 100% с reversible pause.

## Установка

Скачайте Kavor с <https://download.agentkavor.com>. Windows x64: неподписанный NSIS; macOS 13+: DMG без notarization
и ручные updates; Linux x64: AppImage и ручной DEB.

## Известные ограничения

- Windows ARM64/Linux ARM64 ожидают native gates; Windows — Authenticode; macOS auto install — Developer ID/notarization.
- Microsoft Store в этот выпуск не входит.
