# Kavor 2.1.0

## Основные изменения

- **Ваши аккаунты в одном месте.** CodingAgent Accounts объединяет окна использования, оставшийся ресурс
  и сроки обновления лимитов providers в верхней панели Workspace и панели аккаунтов. Добавляйте отдельные
  аккаунты Codex, Claude Code и Grok и управляйте ими, выбирайте аккаунт для CodingAgent или используйте
  Automatic. Нативный вход остаётся аккаунтом Main; добавленные в Kavor аккаунты не заменяют вход в приложениях
  provider.
- **Распределяйте ресурс между своими Workspaces.** Automatic учитывает участвующие аккаунты каждого Workspace,
  совместимость модели и ваш порог использования. По возможности предпочитает отдельные аккаунты для разных
  Workspaces и выполняет смену на безопасной границе между ходами. Выбор Manual имеет приоритет. Низкий или
  исчерпанный ресурс по полученным данным сам по себе не приостанавливает CodingAgent и не блокирует ввод в терминал.
- **Управляйте аккаунтами через Agent Kavor.** Используйте `/accounts`, `/account` и `/autorotate` в выбранном
  Workspace, в том числе через включённый Channel. `/status` также показывает аккаунт и использование CodingAgent.
  Эти структурированные команды используют те же средства управления, что и desktop, без хода модели для
  маршрутизации. Добавление аккаунтов и вход остаются действиями desktop.

## Исправления

- Периодически обновляет использование видимых аккаунтов, повторяет неудачные наблюдения и сохраняет последние
  достоверные проценты, явно указывая недоступность или подсказку по входу. Добавление аккаунта и повторный вход
  остаются доступны при ошибке запроса использования.
- Улучшает доставку сообщений между агентами и доступность ввода в Grok, OpenCode и Antigravity, включая
  прерванные отправки, поле Grok без фокуса, широкие компоновки OpenCode и длинные нативные истории. Защита
  человеческих черновиков и нативных вопросов сохраняется; отправки с неопределённым результатом не дублируются
  автоматически.
- Улучшает восстановление терминалов CodingAgents, обработку изменения размера и индикацию активности при
  повторном открытии или переподключении Node. Пассивные уведомления provider больше не принимаются за активную работу.
- Делает уведомления об ошибках CodingAgents полезнее, различая лимиты provider, перегрузку, аутентификацию
  и другие ошибки, без раскрытия необработанной диагностики в ответах через Channels.
- Прерывает изменение размера Browser Node, когда указатель входит во встроенную страницу, сохраняя
  взаимодействие с ней.
- Переносит средства управления Git самого Workspace в нижнюю панель и отличает репозиторий Workspace от
  репозитория или worktree выбранного Node.
- Обновляет Electron и поставляемые зависимости с исправлениями безопасности.

## Установка

Скачайте Kavor с <https://download.agentkavor.com>. Существующие прямые установки могут проверить эту версию
в настройках Software Update. Нативные входы providers остаются доступны без добавления аккаунта в Kavor.
Обновления базы используют процесс миграции Kavor с резервной копией.

- **Windows x64:** Microsoft Store или NSIS-установщик с участием пользователя. Microsoft подписывает и обновляет
  установки Store. У прямого установщика пока нет подписи издателя; SmartScreen может запросить явное подтверждение.
- **macOS 13+:** отдельные подписанные и нотарифицированные DMG для Apple Silicon и Intel. Автообновления
  используют ZIP соответствующей архитектуры; DMG остаётся доступным для ручной установки.
- **Linux x64:** AppImage и DEB. AppImage поддерживает управляемые Kavor обновления с явным согласованным
  перезапуском; обновления DEB устанавливаются вручную со страницы загрузки.

## Известные ограничения

- Использование и данные о личности аккаунтов зависят от того, что сообщает каждый provider. Antigravity
  поддерживает мониторинг использования, а не пул аккаунтов; использование OpenCode зависит от настроенного
  provider и не входит в этот мониторинг. Grok не сообщает нативные данные о личности. Нечитаемые показания
  отображаются как недоступные, а не как нулевое использование.
- Grok не отличает подтверждённую ошибку квоты от общего rate limit. Поэтому завершившиеся ошибкой ходы Grok
  не отправляются автоматически повторно на другом аккаунте. Ротация по порогу использования остаётся доступной.
- Балансы накопленных сбросов могут отображаться, если provider их сообщает; расход накопленного сброса
  не проверен. Настройки кредитов и сбросов управляют выбором аккаунтов Kavor, а не списаниями внутри
  выполняющегося хода у provider.
- WhatsApp требует привязанного аккаунта, сети и запущенного аутентифицированного Kavor desktop на компьютере,
  который не спит. Интеграция использует привязанные устройства, а не размещённый у Meta WhatsApp Business API.
  Подтверждения на desktop по-прежнему зависят от вас.
- Общий Browser Profile принимает любой сертификат сервера для локальной разработки. Враждебная сеть может
  выдать себя за сайты, открытые в этом профиле. Сессия приложения сохраняет обычную проверку сертификатов.
  Browser Nodes не используют профили или расширения внешнего Chrome; фреймы в других процессах остаются
  вне границы управления встроенной страницей.
- Пакеты Windows ARM64 и Linux ARM64 не включены. Доступность в Microsoft Store может наступить после прямой
  публикации из-за независимой сертификации Microsoft.
