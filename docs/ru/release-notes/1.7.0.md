# Kavor 1.7.0

## Основные изменения

- Добавлено копирование, вырезание и вставка выбранных подграфов Canvas с помощью стандартных сочетаний клавиш и
  контекстных меню. Перенос возможен внутри одного Canvas, а также между Workspaces и окнами с сохранением
  поддерживаемых Nodes, внутренних Connections, расположения и операций отмены или повтора.
- Активные страницы WebBrowser продолжают работать при переключении Workspace, сохраняя состояние и позволяя
  подключённому CodingAgent продолжать работу в браузере. При возврате отображается та же активная страница без
  перезагрузки.
- Файлы из системного буфера обмена и изображения PNG или JPEG вставляются в Terminal и CodingAgent как безопасные
  для shell ссылки на файлы. Скопированные изображения конфиденциально сохраняются в локальном профиле Kavor.

## Исправления

- При каждом запуске приложения восстанавливаются открытые цели Terminal и CodingAgent, принадлежащие активным
  Triggers, поэтому запланированная работа больше не зависит от явного запуска Kavor в фоновом режиме.
- Уточнены инструкции Sticky Note: CodingAgent не должен самостоятельно переписывать содержимое пользователя или
  другого агента и при наличии разрешения обновляет только собственные явно помеченные записи.
- Electron, Chromium, инструменты настольного приложения и зависимости runtime обновлены до последних совместимых
  стабильных версий; в пакетах остаются только нативные бинарные файлы, необходимые соответствующей платформе.

## Установка

Загрузите Kavor с <https://download.agentkavor.com>. Страница определяет текущую платформу и также показывает все
доступные пакеты. Существующие прямые установки могут проверить наличие этой версии в настройках Software Update
Kavor. Ручная миграция данных Workspace не требуется.

- Windows x64 доступен в Microsoft Store или через пользовательский установщик NSIS. Microsoft подписывает и
  обновляет установки Store. Прямой установщик остаётся неподписанным, поэтому Microsoft SmartScreen может запросить
  явное подтверждение.
- Для macOS 13+ доступны отдельные DMG для Apple Silicon и Intel, подписанные Apple Developer ID Kavor и заверенные
  Apple. Автоматическое обновление использует ZIP соответствующей архитектуры, а DMG остаётся ручным вариантом.
- Для Linux x64 доступны AppImage и DEB. AppImage поддерживает управляемые Kavor обновления с явным согласованным
  перезапуском; обновления DEB устанавливаются вручную со страницы загрузки.

## Известные ограничения

- Буфер обмена графом Canvas действует только в текущем процессе. Копия или вырезанный фрагмент может переходить
  между Workspaces и окнами Kavor, но не сохраняется после перезапуска приложения и не копирует физические файлы,
  сессии провайдеров или историю runtime.
- Для локальной разработки выделенный общий Browser Profile Kavor принимает любые серверные сертификаты. Поэтому
  враждебная сеть может имитировать сайты, открытые в этом профиле, включая сайты, где пользователь авторизуется.
  Сессия приложения Kavor сохраняет обычную проверку сертификатов Chromium.
- Nodes WebBrowser не используют внешний профиль Chrome пользователя, его расширения, историю или cookies. Удаление
  Node не стирает общие данные сайтов; глобальные настройки Kavor позволяют явно очистить кэш, cookies и данные сайтов.
- Межсайтовые frames, изолированные в другом процессе Chromium, помечаются как пропущенные и недоступны для управления
  через границу безопасности guest.
- Пакеты Windows ARM64 и Linux ARM64 не выпускаются, пока их нативные gates PTY, SQLite, изоляции процессов и
  упакованного runtime не смогут выполняться в соответствующих средах CI.
- Прямые загрузки Windows пока не имеют сертификата издателя Authenticode; пакеты Microsoft Store подписывает
  Microsoft. Из-за независимой сертификации Microsoft публикация в Store может произойти после прямого stable release.
