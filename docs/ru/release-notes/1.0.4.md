# Kavor 1.0.4

## Основные изменения

- Для macOS arm64/x64 добавлены Kavor-managed updates через architecture-specific ZIP, differential blockmaps и единый stable channel.
- DMG остаётся загрузкой для человека; updater выбирает ZIP, загружает в фоне и устанавливает через coordinated normal quit Kavor.
- <https://download.agentkavor.com> остаётся постоянным fallback для каждой платформы и любой updater failure.

## Исправления

- Исправлен macOS release contract, включивший updater без обязательных ZIP и `latest-mac.yml` Electron Updater.
- Каждый native ZIP проверяется, а metadata объединяется, чтобы один architecture job не заменял другой.
- Добавлены immutable SHA-256 для ZIP/blockmaps, точная проверка assets до promotion и native package gates metadata.
- Устаревшая initial-release configuration переименована согласно текущему direct-distribution contract.

## Установка

Скачайте Kavor с <https://download.agentkavor.com>. Windows x64: неподписанный NSIS. macOS 13+: arm64/x64 DMG без
notarization; после этой версии принятые releases могут устанавливаться при обычном выходе. Linux x64: AppImage и ручной DEB.

## Известные ограничения

- Windows ARM64/Linux ARM64 ожидают native gates; Windows — Authenticode; macOS — Developer ID/notarization.
- Возможны запросы Gatekeeper/Keychain. Microsoft Store в этот выпуск не входит.
