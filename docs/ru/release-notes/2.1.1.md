# Kavor 2.1.1

## Основные изменения

- Сокращает избыточные наблюдения за аккаунтами, сохраняя поведение выбора Automatic и Auto Rotate.

## Исправления

- Обычное чтение данных аккаунтов Codex больше не вызывает принудительное обновление токена OAuth.
  Восстановление нативной аутентификации по-прежнему контролирует Codex.
- Ожидающие завершения наблюдения за одним аккаунтом используются совместно. Текущее наблюдение за аккаунтом
  повторно используется в рамках одного решения о выборе, но данные выполнения из предыдущего решения
  не переиспользуются.

## Установка

Скачайте Kavor с <https://download.agentkavor.com> или проверьте обновления в настройках Software Update.

- **Windows x64:** Microsoft Store или NSIS-установщик с участием пользователя. Microsoft подписывает и обновляет
  установки Store. Прямой установщик остаётся неподписанным и может вызвать предупреждение SmartScreen.
- **macOS 13+:** отдельные подписанные и нотарифицированные DMG для Apple Silicon и Intel. Автообновления
  используют ZIP соответствующей архитектуры; DMG остаётся доступным для ручной установки.
- **Linux x64:** AppImage и DEB. AppImage поддерживает управляемые Kavor обновления с явным согласованным
  перезапуском; обновления DEB устанавливаются вручную.

## Известные ограничения

- Данные об использовании и восстановление аутентификации по-прежнему зависят от provider. Этот hotfix не меняет
  интервалы обновления, допустимость аккаунтов, пороги ротации или лимиты providers.
- Пакеты Windows ARM64 и Linux ARM64 не включены. Доступность в Microsoft Store может наступить после прямой
  публикации из-за независимой сертификации Microsoft.
