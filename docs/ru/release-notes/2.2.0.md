# Kavor 2.2.0

## Основные изменения

- CodingAgents могут запускать, перезапускать, останавливать и делать Fork достижимых сессий, если это допускают **Allow workspace editing** и разрешённый запрос. Fork зависит от provider и доступной нативной истории.
- Атомарное редактирование Canvas включает удаление достижимых Nodes с остановкой выполнения и согласованием Connections и ожидающих сообщений, без удаления canonical sources или Git worktrees.

## Исправления

- Проверяет связь с подготовленным worktree до запуска CodingAgent и разделяет корень Workspace, активный каталог агента и Git-состояние каждого checkout.
- Исправляет переходы работающих сессий при создании, выборе или выходе из worktree. Возобновление использует прежнюю нативную идентичность, когда поддерживается; намеренно остановленные сессии остаются остановленными.
- Защищает Git-привязки от конкурентных операций и запрещает удаление или завершение worktrees, на которые ссылаются другие CodingAgents. Ошибки не удаляют подготовленные пользователем worktrees как временные ресурсы попытки.
- Сохраняет этап и диагностику ошибок запуска, включая ранний выход provider и постоянно пустой экран. После исправления можно повторно запустить тот же Node.
- Сохраняет ожидающее первое сообщение при ошибке запуска и повторной попытке, избегая повторения уже использованной доставки.
- Улучшает определение готовности ввода Claude Code, не путая визуальные подсказки с введённым пользователем текстом. Человеческие черновики, вопросы и подтверждения остаются защищёнными.

## Установка

Скачайте Kavor с <https://download.agentkavor.com> или проверьте обновления в настройках Software Update.

- **Windows x64:** Microsoft Store или NSIS-установщик с участием пользователя. Microsoft подписывает и обновляет установки Store. Прямой установщик остаётся неподписанным и может вызвать предупреждение SmartScreen.
- **macOS 13+:** отдельные подписанные и нотарифицированные DMG для Apple Silicon и Intel. Автообновления используют ZIP нужной архитектуры; DMG остаётся доступным для ручной установки.
- **Linux x64:** AppImage и DEB. AppImage поддерживает обновления под управлением Kavor с явным согласованным перезапуском; обновления DEB устанавливаются вручную.

## Известные ограничения

- Fork зависит от возможностей provider и установленной версии. Интеграция Antigravity не предоставляет Fork; другая сессия без истории не является равноценной заменой.
- Git worktree не устанавливает зависимости и не копирует автоматически локальную конфигурацию или учётные данные. Подготовка окружения зависит от проекта.
- Готовность provider и доставка сообщения не доказывают завершение задачи. Лимиты, аутентификация и доступность сервисов остаются под контролем providers.
- Пакеты Windows ARM64 и Linux ARM64 не включены. Публикация Microsoft Store может последовать за прямой из-за независимой сертификации.
