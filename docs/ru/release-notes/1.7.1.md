# Kavor 1.7.1

## Основные изменения

- Обновляет Electron, Chromium, React, инструменты UI и зависимости runtime до совместимых стабильных версий.
  Этот hotfix сохраняет существующие рабочие процессы Canvas и CodingAgent, не открывая экспериментальные интерфейсы.

## Исправления

- Восстанавливает нативный ввод мышью и клавиатурой в WebBrowser после переключения Workspace без перезагрузки
  сохранённой активной страницы и без блокировки интерактивных элементов браузера.
- Очищает состояние popup у страницы-владельца при закрытии popup WebBrowser, удаляет его рамку и позволяет
  открывать следующие popup, не очищая новый popup, который заменил предыдущий.
- Исправляет цвета Markdown в светлом режиме чтения, включая заголовки, ссылки, код, цитаты и таблицы.
  При переключении между светлым и тёмным режимами чтения теперь применяется единый стиль в компактном и обычном виде.
- Сохраняет точность времени до минуты в разовых расписаниях Trigger после обновления зависимостей.
- Обрабатывает отслеживаемые пути Workspace буквально, без раскрытия синтаксиса glob, сохраняя рекурсивное
  обнаружение новых каталогов.
- Восстанавливает совместимость с нативным исполняемым файлом pnpm при сборке пакетов Workspace, пересборке
  нативных зависимостей и создании уведомлений о сторонних компонентах для упакованного приложения.
- Обновляет затронутые зависимости gRPC и FTP и сохраняет проверенный контракт schemas для tools CodingAgent.

## Установка

Скачайте Kavor с <https://download.agentkavor.com>. Существующие прямые установки могут проверить наличие этого
релиза в настройках Software Update. Ручная миграция данных Workspace не требуется.

- Windows x64 доступен в Microsoft Store или через пошаговый установщик NSIS для отдельного пользователя.
  Microsoft подписывает и обновляет установки Store. Прямой установщик по-прежнему не подписан, поэтому
  Microsoft SmartScreen может потребовать явного подтверждения.
- Для macOS 13+ доступны отдельные DMG для Apple Silicon и Intel, подписанные Apple Developer ID Kavor и
  нотариально проверенные Apple. Автоматические обновления используют ZIP для соответствующей архитектуры,
  сохраняя DMG как ручной запасной вариант.
- Linux x64 предлагает AppImage и DEB. AppImage поддерживает обновления под управлением Kavor с явным
  согласованным перезапуском; обновления DEB устанавливаются вручную со страницы загрузки.

## Известные ограничения

- Для upstream-зависимости `braces` по-прежнему нет опубликованного патча к известному предупреждению безопасности.
  Рекурсивное отслеживание Workspace теперь отключает раскрытие glob; это мера снижения риска, а не исправление зависимости.
- Выделенный общий Browser Profile Kavor принимает любые сертификаты сервера для локальной разработки.
  Враждебная сеть поэтому может выдавать себя за сайты, открытые в этом профиле, включая сайты, где пользователь
  входит в учётную запись. Сессия приложения Kavor сохраняет обычную проверку сертификатов Chromium.
- Nodes WebBrowser не используют профиль, расширения, историю или cookies внешнего Chrome пользователя.
  Удаление Node не удаляет общие данные сайтов; глобальные настройки Kavor позволяют явно очистить кеш, cookies
  и данные сайтов.
- Межсайтовые frames, изолированные в другом процессе Chromium, отмечаются как пропущенные и не могут
  управляться через границу безопасности guest.
- Пакеты Windows ARM64 и Linux ARM64 не включены, пока проверки нативных PTY, SQLite, ограничения процессов
  и упакованного runtime не смогут выполняться в соответствующих CI-окружениях.
- Прямые загрузки для Windows пока не имеют сертификата издателя Authenticode; пакеты Microsoft Store подписывает
  Microsoft. Появление в Store может произойти после прямого stable-релиза, когда завершится независимая
  сертификация Microsoft.
