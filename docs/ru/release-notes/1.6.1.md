# Kavor 1.6.1

## Основные изменения

- Проверка prerelease-обновлений начинает использовать публичный prerelease-канал Kavor сразу после включения
  настройки, а ручная проверка сравнивает манифесты stable и prerelease и выбирает самую новую доступную версию.
- Улучшен chrome Node WebBrowser: header стал выше и стабильнее, адресное поле лучше читается, а индикатор загрузки
  остаётся внутри header и не сдвигает viewport страницы.

## Исправления

- Содержимое WebBrowser больше не сдвигается и не меняет размер при начале или завершении навигации.
- Восстановлен предусмотренный высокий контраст значка Terminal на панели инструментов Canvas.
- В сворачиваемых разделах настроек Workspace теперь используются согласованные значки.
- Повышена надёжность прямой доставки обновлений и последовательности отправки в Microsoft Store: завершённый
  rollout финализируется до отправки следующего пакета.

## Установка

Скачайте Kavor с <https://download.agentkavor.com>. Страница определяет текущую платформу и показывает все доступные
пакеты. Существующие прямые установки могут проверить наличие этой версии в настройках Software Update Kavor.
Ручная миграция данных Workspace не требуется.

- Windows x64 доступен в Microsoft Store или через пользовательский установщик NSIS. Microsoft подписывает и
  обновляет установки из Store. Прямой установщик остаётся неподписанным, поэтому Microsoft SmartScreen может
  потребовать явного подтверждения.
- Для macOS 13+ доступны отдельные DMG для Apple Silicon и Intel, подписанные Apple Developer ID Kavor и
  нотаризованные Apple. Автоматическое обновление использует ZIP соответствующей архитектуры, а DMG остаётся
  вариантом ручной установки.
- Для Linux x64 доступны AppImage и DEB. AppImage поддерживает управляемые Kavor обновления с явным согласованным
  перезапуском; DEB обновляется вручную со страницы загрузки.

## Известные ограничения

- Nodes WebBrowser используют отдельный общий Browser Profile Kavor и не используют profile, расширения, историю
  или cookie внешнего Chrome пользователя. Удаление Node не стирает общие данные сайтов; глобальные настройки Kavor
  позволяют явно очистить кэш, cookie и данные сайтов.
- Для управления через CodingAgent Node WebBrowser должен быть активен на Canvas. Межсайтовые frame, изолированные
  в другом процессе Chromium, отмечаются как пропущенные и недоступны через границу безопасности guest.
- Пакеты Windows ARM64 и Linux ARM64 не включены, пока их нативные gate для PTY, SQLite, изоляции процессов и
  упакованного runtime не смогут выполняться в соответствующих средах CI.
- Прямые загрузки Windows пока не имеют сертификата publisher Authenticode; пакеты Microsoft Store подписывает
  Microsoft. Версия в Store может стать доступна после прямой stable release из-за независимой сертификации Microsoft.
