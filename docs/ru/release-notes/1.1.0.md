# Kavor 1.1.0

## Основные изменения

- В новых пакетах private-protocol sign-in заменён коротким callback `127.0.0.1`, привязанным к попытке. Google,
  GitHub и passwordless email возвращаются в Kavor через системный браузер; provider flows используют PKCE и clipboard fallback.
- В Authentication добавлено первое юридическое согласие, а синхронизация аккаунта помещена за versioned public API.
- CodingAgents могут предлагать File и Specification Nodes через атомарный каталог Canvas. Connection Skills начинают
  с применимых правил и Git-aware контекста.
- Улучшены отображение, смена Workspace, startup и recovery Terminal/CodingAgent при параллельной PTY-активности.
- Упрощены навигация и действия Specifications при сохранении прямого доступа к File-backed работе.

## Исправления

- Исправлены Google Desktop и confidential server-side exchange GitHub для loopback без доставки GitHub credentials в приложение.
- Private protocol удалён из новых desktop packages; устранены Linux handler failures, старые hosted compatibility paths сохранены.
- Callback защищён от старых, повторных, malformed и mismatched попыток; credentials и ответы не сохраняются и не логируются.
- Исправлены PTY hydration и ownership при смене Workspace, включая recovery задержанного/прерванного handshake без ложных exits.
- Снижена лишняя работа Canvas/panels вокруг Terminal, CodingAgent, File и Specification Nodes; действия уточнены.
- Release discovery переведён на стабильный download API Kavor вместо прямой зависимости от release host.

## Установка

Скачайте Kavor с <https://download.agentkavor.com>. Windows x64: неподписанный NSIS; macOS 13+: arm64/x64 DMG без
notarization и ZIP update с проверкой; Linux x64: AppImage и ручной DEB.

## Известные ограничения

- Версии до 1.0.6 больше не начинают новый GitHub sign-in после отключения legacy OAuth App. Существующие sessions
  действуют; установите 1.1.0 для нового входа.
- Windows ARM64/Linux ARM64 ожидают native gates; Windows — Authenticode; macOS — Developer ID/notarization.
- Microsoft Store в этот выпуск не входит.
