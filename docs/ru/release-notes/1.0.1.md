# Kavor 1.0.1

## Основные изменения

- Восстанавливает недостающие native tools внутри Workspace: проводит установку Git/providers, показывает progress и
  actionable failures и обновляет detection без restart.
- Добавляет global `Auto`, `Full`, `Reduced`; `Auto` сохраняет operational feedback и уменьшает effects при reduced motion
  ОС или software rendering Chromium.
- Управляет updates из Settings с единым status, explicit check и manual fallback; badges видны от download до install-ready.
- Опционально показывает bounded plain-text preview последнего CodingAgent response в OS notification; privacy setting
  может скрыть content на lock screen.
- Позволяет start, stop, restart и configure CodingAgent из Node; rename синхронизирует native session, если поддерживается.
- Уменьшает packages, удаляя неиспользуемые locales, dev artifacts, source maps, tests и binaries других ОС при сохранении runtime/notices.

## Исправления

- Output delivery перестроен с bounded backpressure, ordered batches, attachment acknowledgements и final exit checkpoints.
- Presentation при pan, zoom, remount и startup держит PTY вне zoom compositor и показывает hydration после checkpoint.
- Transparent decorations и Locate больше не скрывают Terminal/CodingAgent portals.
- Исправлены Node placement и drag preview на любом zoom, включая смену viewport при неподвижном pointer.
- Stale Git results удаляются при смене Workspace/repository/target; controls ограничены valid repos; discovery/scans разделяются.
- Native-tool refresh атомарен между Electron main и Process Host и использует свежий `PATH`.
- Усилен Windows: PowerShell hooks, environment propagation, user-local Git, `winget`, concurrent Job Objects.
- Улучшен CodingAgent recovery: installer feedback, retry, manual install, fresh detection и explicit early-exit errors.
- Async provider activity изолирована и ограничена по session; Antigravity отклоняет stale/unrelated previews.
- Terminal Node сохраняется при failure teardown и удаляется только после успешного закрытия process.
- Sticky Note revisions не зависят от concurrent Canvas move/resize.
- Competing update checks и stale initial state не заменяют новые availability/download/error.
- Сглажены Authentication, onboarding, Workspace activation и Canvas startup без flashes и blank scene.
- Development/packaged profiles изолируют SQLite, credentials, window, cookies, cache и Browser storage.
- Idle Codex app-server connections закрываются после последней session.
- Anonymous startup Analytics устойчив к reload/network failures; detailed Analytics/Performance управляются пользователем,
  а content, prompts, commands, paths, output и identity исключены.

## Установка

Скачайте Kavor с <https://download.agentkavor.com>. Windows x64: неподписанный NSIS; macOS 13+: DMG без notarization
и ручные updates; Linux x64: AppImage и ручной DEB.

## Известные ограничения

- Windows ARM64/Linux ARM64 ожидают native gates; Windows — Authenticode; macOS auto install — Developer ID/notarization.
- Microsoft Store в этот выпуск не входит.
