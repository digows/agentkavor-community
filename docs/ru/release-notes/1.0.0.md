# Kavor 1.0.0

## Основные изменения

- Координируйте CodingAgents, Terminals, Specifications, Files и Sticky Notes на постоянном local-first Canvas.
- Connections явно предоставляют capabilities, сохраняя human-owned Guardrails и review boundaries.
- CodingAgents предлагают atomic Canvas changes; Header позволяет найти, проверить, применить или отклонить всё предложение.
- Connected CodingAgents обмениваются durable messages, а reviewed operation catalog доступен через local MCP bridge.
- Workspace, Canvas, Terminal и provider session context переживают restart, а данные остаются на машине пользователя.
- Доступность update сопровождается постоянным manual fallback на <https://download.agentkavor.com>.

## Исправления

- Улучшены pan/zoom благодаря пропорциональному viewport scale rich Node rendering.
- Terminal state/counters отделены от Canvas visibility optimization.
- Усилены PTY startup, process containment, cleanup и packaged runtime на поддерживаемых платформах.
- Зависимые Node/Connection proposals атомарны, требуют одного human decision и вместе откатываются.
- Добавлены bounded anonymous Analytics и optional Performance без Workspace content, paths, prompts, commands, output и Authentication identity.

## Установка

Скачайте Kavor с <https://download.agentkavor.com>. Windows x64: начальный неподписанный NSIS; macOS 13+: arm64/x64
DMG без notarization и ручные updates; Linux x64: AppImage и ручной DEB.

## Известные ограничения

- Windows ARM64/Linux ARM64 ожидают native gates; Windows — Authenticode; macOS auto install — Developer ID/notarization.
- Microsoft Store в этот выпуск не входит.
