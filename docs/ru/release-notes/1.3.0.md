# Kavor 1.3.0

## Основные изменения

- Добавлены Schedule Trigger Nodes для однократной и повторяющейся работы. Trigger можно соединить с одним CodingAgent
  или Terminal, просмотреть будущие срабатывания в сохранённом часовом поясе, немедленно приостановить или возобновить,
  запустить вручную и изучить долговечную историю с результатами missed, blocked, failed и completed.
- Добавлены независимые окна Workspace поверх единого общего runtime. Можно открыть разные Workspaces рядом,
  восстановить прошлую сессию окон, изолировать Terminal и CodingAgent по Workspace, а также оставить Kavor в системном
  трее и при желании запускать его в фоне при входе в систему.
- Очередь предложений Canvas заменена прямым атомарным редактированием авторизованными CodingAgents. Проверенный набор
  изменений Nodes, Connections, Files и Specifications теперь фиксируется одной операцией или полностью откатывается.
- Связный граф стал границей общего контекста CodingAgents. Достижимые Agents могут обмениваться долговечными и
  проверяемыми сообщениями, а Guardrails прямых Connections продолжают ограничивать конкретные пары ресурсов.
- Добавлены ограниченный поиск файлов Workspace через включённый бинарный ripgrep, расширенные превью ссылок на файлы
  и официальная документация Kavor через локальный каталог MCP.
- Статусы CodingAgents, Specifications и Triggers объединены в Header Workspace. Добавлено окно About с установленной
  версией, происхождением build, обновлением, поддержкой, безопасностью и юридической информацией.

## Исправления

- Активация нативного уведомления теперь направляется в существующее окно, которому принадлежит нужный Workspace,
  без создания дубликатов и переключения постороннего окна.
- Стабилизированы обнаружение окружения providers, запуск CodingAgents, диагностика PTY Host, восстановление Terminals
  и представление PTY при открытии, закрытии, восстановлении и переключении нескольких окон Workspace.
- Сигналы завершения и внимания фоновых CodingAgents сохраняются при смене Workspace, а нативные уведомления
  отправляются только когда соответствующая работа ещё не видна.
- Сообщения CodingAgent в очереди и доставки Triggers сериализуются, чтобы не перезаписывать ввод пользователя и не
  обходить работу, уже принятую целевой сессией.
- Переименование provider session откладывается, когда Claude Code временно недоступен, вместо отказа всё ещё
  пригодной сессии.
- Ошибки отслеживания экрана Terminal локализуются, а реальные сбои запуска host отображаются без маскировки под
  общий timeout.

## Установка

Скачайте Kavor с <https://download.agentkavor.com>. Страница определяет текущую платформу и показывает все доступные
пакеты. Существующие прямые установки могут проверить версию в настройках Software Update. Ручная миграция данных
Workspace не требуется: Kavor создаёт резервную копию поддерживаемой локальной базы перед обновлением schema.

- Windows x64 использует пользовательский установщик NSIS. Он пока не подписан, поэтому Microsoft SmartScreen может
  запросить явное подтверждение.
- macOS 13+ предоставляет отдельные DMG для arm64 и x64. Builds подписаны ad-hoc, но не notarized; следуйте инструкции
  Gatekeeper. Обновление использует ZIP нужной архитектуры и предлагает явный согласованный перезапуск после повторной
  проверки. Ручная загрузка доступна всегда.
- Linux x64 предоставляет AppImage и DEB. AppImage поддерживает управляемое обновление с явным перезапуском, DEB
  заменяется вручную со страницы загрузки.

## Известные ограничения

- Schedule Triggers требуют запущенного runtime Kavor, бодрствующей машины, вошедшего пользователя и активной целевой
  сессии. Срабатывание, пропущенное когда Kavor не работал, записывается и предлагается для явного ручного запуска;
  оно никогда не выполняется автоматически при следующем старте.
- Windows ARM64/Linux ARM64 ожидают нативных CI gates для PTY, SQLite, containment процессов и packaged runtime.
- Прямые загрузки Windows пока не имеют сертификата Authenticode.
- macOS пока не имеет подписи Developer ID и notarization. Gatekeeper может запросить подтверждение, а замена ad-hoc
  build — повторный доступ к `Kavor Safe Storage` в Keychain.
- Microsoft Store не входит в эту версию.
