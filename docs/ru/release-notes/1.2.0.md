# Kavor 1.2.0

## Основные изменения

- Добавлены расширенные превью изображений и PDF в File Nodes. Большие PDF отображают только видимые страницы, а
  ограниченные размеры изображений, Canvas и файлов защищают Workspace от неограниченного расхода памяти.
- Завершён жизненный цикл Files и Specifications: создание Specification из меню Canvas, переименование и удаление
  источников, папки и синхронизация существующих Nodes с файловой системой.
- Пути из панели Files можно перетаскивать в Terminal и CodingAgent с quoting для активной shell.
- Атомарные предложения дополнены созданием Specifications, сохранением прогресса и восстановлением обратимых
  побочных эффектов Files/Specifications.
- Каждый Kavor Skill теперь указывает точный вызов `kavor.skill.get("<name>")` для загрузки CodingAgent.

## Исправления

- При редактировании Specifications сохраняются поля, комментарии и порядок YAML frontmatter, имена и относительные пути.
- Стабилизирована hydration Terminal/CodingAgent: задержанное PTY-состояние не теряет содержимое и не дублирует ownership.
- Append Sticky Note остаются отдельными Markdown-блоками; пустой append не создаёт revision; лимиты считаются по Unicode code point.
- Изменения Files/Specifications усилены сериализацией, ограничением путей, invalidation источников и явными ошибками.
- Устранены security advisories из предыдущего графа production-зависимостей.

## Установка

Скачайте Kavor с <https://download.agentkavor.com>. Windows x64 использует неподписанный NSIS. macOS 13+ предоставляет
arm64/x64 DMG с ad-hoc подписью без notarization и обновления через повторно проверенный ZIP. Linux x64 предоставляет
обновляемый AppImage и ручной DEB. Ручная загрузка доступна всегда.

## Известные ограничения

- Windows ARM64/Linux ARM64 ожидают нативных CI gates для PTY, SQLite, containment и packaged runtime.
- Windows пока без Authenticode; macOS без Developer ID и notarization, возможны запросы Gatekeeper/Keychain.
- Microsoft Store в этот выпуск не входит.
