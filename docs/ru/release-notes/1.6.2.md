# Kavor 1.6.2

## Основные изменения

- Расширены пользовательские элементы управления Node WebBrowser: добавлены явный переключатель DevTools,
  открытие активной HTTP- или HTTPS-страницы в системном браузере и нативные действия вырезания, копирования,
  вставки и выбора всего текста в адресной строке.
- Node WebBrowser теперь обрабатывает запросы HTTP- и proxy-аутентификации и показывает для каждой страницы
  количество ошибок консоли и сетевых правил CodingAgent с прямыми действиями для просмотра ошибок или очистки
  активных правил.
- В выделенном Browser Profile Kavor открываются локальные серверы разработки с самоподписанными, просроченными или
  выданными частными центрами сертификатами, не ослабляя проверку сертификатов для сессии приложения Kavor.

## Исправления

- Представление новой вкладки WebBrowser теперь заполняет весь viewport, а прогресс загрузки отображается на границе
  строки состояния, не сдвигая содержимое страницы.
- В меню создания Canvas provider CodingAgent и типы Node теперь последовательно сгруппированы и имеют различимые
  цвета значков.
- Публикация в Microsoft Store проверяет защищённые учётные данные и доступ к Partner Center до расходования минут
  нативного build, а отправки выполняются последовательно без отмены активной операции Store.

## Установка

Скачайте Kavor с <https://download.agentkavor.com>. Страница определяет текущую платформу и позволяет показать все
доступные пакеты. Пользователи существующих прямых установок могут проверить наличие этой версии в настройках
Software Update Kavor. Ручная миграция данных Workspace не требуется.

- Windows x64 доступен в Microsoft Store или в виде интерактивного NSIS-установщика для текущего пользователя.
  Microsoft подписывает и обновляет установки Store. Прямой установщик пока не подписан, поэтому Microsoft
  SmartScreen может потребовать явного подтверждения.
- Для macOS 13+ предоставляются отдельные DMG для Apple Silicon и Intel, подписанные Apple Developer ID Kavor и
  нотариально заверенные Apple. Автоматическое обновление использует ZIP для соответствующей архитектуры, а DMG
  остаётся ручным запасным вариантом.
- Для Linux x64 предоставляются AppImage и DEB. AppImage поддерживает обновления под управлением Kavor с явным
  согласованным перезапуском; DEB обновляется вручную со страницы загрузки.

## Известные ограничения

- Для локальной разработки выделенный общий Browser Profile Kavor принимает любой сертификат сервера. Поэтому
  враждебная сеть может подменить сайты, открытые в этом Profile, включая сайты, где пользователь выполняет вход.
  Сессия приложения Kavor сохраняет обычную проверку сертификатов Chromium.
- Node WebBrowser не используют Profile, расширения, историю или cookie внешнего Chrome. Удаление Node не стирает
  общие данные сайтов; глобальные настройки Kavor позволяют явно очистить кэш, cookie и данные сайтов.
- Для управления CodingAgent Node WebBrowser должен быть активен на Canvas. Межсайтовые frame, изолированные Chromium
  в другом процессе, отмечаются как пропущенные и не могут управляться через границу безопасности guest.
- Пакеты Windows ARM64 и Linux ARM64 не выпускаются, пока их нативные проверки PTY, SQLite, изоляции процессов и
  упакованного runtime не смогут выполняться в соответствующих средах CI.
- Прямые загрузки Windows пока не имеют сертификата publisher Authenticode; пакеты Microsoft Store подписывает
  Microsoft. Публикация в Store может состояться позже прямой stable release из-за независимой сертификации Microsoft.
