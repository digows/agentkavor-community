# Kavor 1.6.0

## Основные изменения

- В Canvas добавлен Node WebBrowser — полноценный браузер Chromium, управляемый человеком. Он поддерживает
  постоянные вкладки, навигацию, историю, всплывающие окна, загрузки, запросы разрешений, поиск, масштабирование,
  DevTools и отдельный Профиль Браузера Kavor, общий для Nodes WebBrowser Пользователя.
- Подключённый CodingAgent может управлять именно той активной страницей, которую видит Пользователь, через
  ограниченные операции Kavor для состояния страницы, навигации, снимков доступности, действий, выполнения
  JavaScript, ожиданий, снимков экрана, проверки консоли и сети, тел ответов и сетевых правил уровня страницы.
- CodingAgents могут создавать Nodes WebBrowser атомарными изменениями Canvas, при необходимости открывая начальный
  URL, а затем находить и использовать Node по той же модели Connection и достижимости, что и в других частях Kavor.
- Автоматический контекст CodingAgent уменьшен с сохранением доступа по запросу к полному графу, layout, метаданным
  и результатам Specification, а также Skills, необходимым для текущей задачи.

## Исправления

- Сессии Codex запускаются и разветвляются без ожидания rollout-файла, который Codex ещё не создал; сессия провайдера
  записывается после того, как первый отправленный prompt установит её собственную идентичность.
- Возобновление Codex, происхождение ветвей и синхронизированные имена сессий сохраняются, когда сессия провайдера
  материализуется уже после открытия интерактивного терминала.
- Единая терминология WebBrowser используется в домене, Canvas, IPC, каталоге MCP, Skills, разделе профиля и
  внутренней схеме браузера.
- Для действий и ожиданий WebBrowser публикуются полные входные контракты, поэтому CodingAgents получают все
  поддерживаемые поля вместо пустой схемы инструмента верхнего уровня.

## Установка

Скачайте Kavor с <https://download.agentkavor.com>. Страница определяет текущую платформу и также показывает все
доступные пакеты. Существующие прямые установки могут проверить эту версию в настройках обновления ПО Kavor. Ручная
миграция данных Workspace не требуется: Node WebBrowser появился в этой версии, а существующие данные Canvas остаются
совместимыми.

- Windows x64 доступна в Microsoft Store или в виде вспомогательного NSIS-установщика для Пользователя. Microsoft
  подписывает и обновляет установки Store. Прямой установщик остаётся неподписанным, поэтому Microsoft SmartScreen
  может потребовать явного подтверждения.
- Для macOS 13+ доступны отдельные DMG для Apple Silicon и Intel, подписанные Apple Developer ID Kavor и нотариально
  заверенные Apple. Автоматические обновления используют ZIP для соответствующей архитектуры, а ручной DMG остаётся
  резервным вариантом.
- Для Linux x64 доступны AppImage и DEB. AppImage поддерживает управляемые Kavor обновления с явным согласованным
  перезапуском; обновления DEB устанавливаются вручную со страницы загрузки.

## Известные ограничения

- Nodes WebBrowser используют отдельный общий Профиль Браузера Kavor и не используют профиль, расширения, историю или
  cookies внешнего Chrome Пользователя. Удаление Node не стирает общие данные сайтов; глобальные настройки Kavor
  позволяют явно очистить кэш, cookies и данные сайтов.
- Для управления CodingAgent Node WebBrowser должен быть активен на Canvas. Межсайтовые frames, изолированные в другом
  процессе Chromium, помечаются как пропущенные и не управляются через границу безопасности уровня guest.
- Запросы разрешений, диалоги сохранения, CAPTCHA, passkeys, клиентские сертификаты и аутентификация операционной
  системы остаются границами, которые разрешает человек.
- Пакеты Windows ARM64 и Linux ARM64 не включены, пока gates для нативного PTY, SQLite, изоляции процессов и
  упакованного runtime не смогут выполняться в соответствующих средах CI.
- Прямые загрузки Windows ещё не имеют сертификата издателя Authenticode; пакеты Microsoft Store подписывает
  Microsoft. Версия в Store может появиться после прямой stable release и независимой сертификации Microsoft.
