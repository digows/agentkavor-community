# Kavor 2.2.1

## Исправления

- Действующий режим **Manual**, заданный в CodingAgent или унаследованный от Workspace, не запрашивает ресурс
  для ротации при завершении хода. Видимые показания и **Refresh** остаются доступны.
- **Automatic** повторно использует свежие показания того же аккаунта между Workspaces в пределах исходных
  30 секунд, не откладывая повторную оценку при истечении срока, обновлении окна или подтверждённой ошибке аутентификации либо квоты.
- Отображение имён аккаунтов и разрешение известных имён или идентичностей в командах Agent Kavor больше не вызывают
  лишних запросов использования. Для неизвестных идентичностей запрос по-прежнему может потребоваться.
- Исправлено ручное обновление аккаунта без показания в памяти: первоначальный запрос больше не дублируется.

Ротация остаётся превентивной, с порогом по умолчанию **95 % использования**. Правила участия, модели и разрешений
на расходы сохраняются; смена аккаунта по-прежнему соблюдает безопасную границу между ходами и непрерывность сессии.

О Manual, Automatic и времени показаний читайте в [CodingAgent Accounts](../coding-agent-accounts.md).

## Обновление

Скачайте Kavor с <https://download.agentkavor.com> или проверьте обновления в настройках Software Update.
Лимиты, аутентификация и доступность сервисов остаются под контролем providers.
