# Kavor 1.0.6

## Основные изменения

- Terminal/CodingAgent стали устойчивее при длительном output, параллельной работе и нескольких Workspaces. PTY
  работают в отдельном host, изолированном от Git, installers, probes и других bounded operations.
- Live processes отделены от Canvas presentation. Смена Workspace, pan, zoom, remount или offscreen detach/restore
  viewport без перезапуска процесса и потери упорядоченного output.
- Software Update перестроен вокруг явного проверенного `Restart & update`. Progress, readiness, errors и recovery
  находятся в Settings; Header и уведомления лишь привлекают внимание.
- Добавлен offline post-update dialog, один раз показывающий Highlights, Fixes и Known limitations всех пропущенных releases.
- Workspace preferences применяются сразу; явный Save остался только для имени.

## Исправления

- Удалён общий process-host failure domain, способный завершить несвязанные sessions.
- Добавлены fair bounded PTY output и прямой typed channel, чтобы шумная session не блокировала остальные.
- Исправлена hydration при visibility/Workspace changes: сначала authoritative checkpoint, без дублей и скрытых restart.
- Добавлен recovery после PTY host interruption с сохранением Stop и без duplicate launch/fabricated exit.
- Operation host отделён от PTY, login environment refresh централизован, detection больше не конкурирует с PTY.
- Исправлена process identity CodingAgent context hook для Node launches.
- Обычный quit не устанавливает update неявно: cache перепроверяется по SHA-512, а при ошибке Kavor остаётся открыт.
- Исправлены stale updater readiness и repeated restart; добавлены bounded rotating diagnostics.
- Убраны global update toasts, prerelease применяется сразу, Header/restart показывают pulsing ready state.
- Немедленные preferences откатываются при ошибке сохранения.
- Добавлена signed idempotent Firebase account sync с bounded retries и daily reconciliation.
- Packaged startup согласован с lazy hosts и не запускает PTY/operations до необходимости.

## Установка

Скачайте Kavor с <https://download.agentkavor.com>. Windows x64: неподписанный NSIS; macOS 13+: DMG без notarization
и перепроверяемый ZIP update; Linux x64: AppImage и ручной DEB.

## Известные ограничения

- Windows ARM64/Linux ARM64 ожидают native gates; Windows — Authenticode; macOS — Developer ID/notarization.
- Возможны запросы Gatekeeper/Keychain. Microsoft Store в этот выпуск не входит.
