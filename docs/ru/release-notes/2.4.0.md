# Kavor 2.4.0

## Главное

- **Skip trust prompts:** настройка запуска для каждого Node типа CodingAgent, включённая по умолчанию.
  Совместимые harness запускаются без вопроса о доверии к выбранной папке или её хукам. Отключите настройку в
  Startup — изменение вступит в силу при следующем запуске. Явно заданные нативные аргументы по-прежнему имеют
  приоритет; разрешения на использование инструментов и аутентификация по-прежнему обрабатываются отдельно.
  Доверие к папке также позволяет harness загружать хуки и другие нативные настройки проекта.
- **Организация на панели Diagrams:** создавайте папки и файлы прямо на панели и упорядочивайте их в существующем
  дереве документации. Если действие не удаётся завершить, отображаются более понятные сообщения.
- **Содержимое Canvas загружается по мере необходимости:** текстовые редакторы, поддержка языков и Connection
  Inspector загружаются по запросу; редактирование и работа с инспектором остаются прежними.

## Исправления

- Перетаскивание на Canvas работает и при перемещении через превью Diagram. Если текстовый документ открывается
  на запрошенной строке, она видна уже при первоначальной загрузке.
- Обнаружение провайдеров и запуск процессов в Windows сохраняют аргументы, переданные через npm-лаунчеры
  `.cmd` и `.bat`, включая пути с пробелами и значения в кавычках.
- При удалении управляемого аккаунта Codex сохраняются места хранения истории, используемые нативным индексом
  сессий, а локальные учётные данные и состояние аккаунта удаляются. Это предотвращает появление новых
  неработающих ссылок на историю; уже неработающие ссылки не исправляются.
- Инициализация ACP сообщает исходную ошибку запуска, даже если очистка процесса тоже завершается ошибкой.
- Хосты процессов используют выделенные точки входа среды выполнения. Пакеты настольного приложения больше не
  включают две неиспользуемые точки входа SDK Claude; при этом возможности SDK, используемые Kavor, сохраняются.

## Установка

Обновитесь через Kavor или используйте [download.agentkavor.com](https://download.agentkavor.com). Пакеты для macOS
подписаны сертификатом Developer ID и прошли нотарификацию Apple. Прямые установщики для Windows по-прежнему не
подписаны и могут вызывать предупреждения SmartScreen; Microsoft Store остаётся отдельным каналом распространения,
обновлениями в котором управляет Store.

## Известные ограничения

- Skip trust prompts не заменяет аутентификацию, выдачу разрешений на использование инструментов или
  подтверждение запроса MCP самого репозитория в Claude Code. Если экран доверия не распознан, он остаётся
  доступным для вашего ответа. Для OpenCode эта настройка не требуется.
- Движки и ресурсы Diagram загружаются по запросу. При первом использовании может потребоваться интернет, а
  внешние ресурсы могут по-прежнему зависеть от подключения. draw.io остаётся доступным только для просмотра,
  D2 не поддерживает TALA.
