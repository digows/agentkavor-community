# Kavor 2.3.0

## Главное

- **Диаграммы на Canvas:** файлы 13 семейств форматов, включая Mermaid, PlantUML с C4, Graphviz, D2, Excalidraw и
  draw.io. Переключайтесь между Diagram, Source и Split, проверяйте ошибки отрисовки и экспортируйте SVG или PNG.
  Excalidraw поддерживает визуальное редактирование; draw.io в Kavor доступен только для просмотра.
- **Документация в файловой системе:** Specifications и Diagrams используют общие Documentation roots. Настройте
  Diagrams folder относительно первого корня, просматривайте реальное дерево папок и создавайте файлы через toolbar
  или встроенную форму. Путь по умолчанию остаётся `docs/diagrams/`; его изменение не перемещает существующие файлы.
- **Больше способов добавить контекст:** перетаскивайте файлы из системы на Canvas или вставляйте файлы, данные
  изображения, URL либо текст. Файлы остаются на своих местах; вставленные изображения сохраняются как PNG в
  Workspace. Внешние источники отражают изменения на диске, а для файлов без расширенного просмотра отображается
  карточка с информацией и действиями.

## Исправления

- Auto учитывает исключение аккаунтов из участия в Workspace и сохраняет выбор Manual. Пока участвующие
  альтернативы непригодны, существующие сессии сохраняются; когда подходящий аккаунт восстанавливается, выбор
  пересматривается. Исключение не становится разрешением на новый запуск.
- Запросы статистики использования Codex больше не повторяются автоматически после окончательного отзыва учётных
  данных. Явное восстановление по-прежнему доступно через Refresh, запущенный человеком.
- Исправлена подстройка размеров Terminals и CodingAgents при показе заранее запущенных сессий и изменении масштаба.
  Нативная сессия сохраняется, а не создаётся заново ради корректировки отображения.

## Установка

Обновитесь через Kavor или используйте [страницу загрузки](https://agentkavor.com/downloads). Если встроенное
обновление недоступно, пакеты остаются доступны на [download.agentkavor.com](https://download.agentkavor.com).

## Известные ограничения

- Движки и ресурсы диаграмм загружаются по запросу. При первом использовании может потребоваться интернет; кеш
  позволяет повторно использовать уже загруженные ресурсы, но содержимое со ссылками на внешние URL всё ещё может
  зависеть от сети.
- У draw.io нет редактора в Kavor, а D2 не поддерживает TALA. Доступность моделей, чтение статистики использования и
  возобновление сессий по-прежнему зависят от возможностей и аутентификации выбранного harness.
