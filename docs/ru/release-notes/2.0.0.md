# Kavor 2.0.0

> Редакционная правка от 16 октября 2026 года: уточнено описание Agent Kavor и Browser без изменения бинарных
> файлов 2.0.0. [Исходные примечания](https://github.com/digows/agentkavor-community/blob/285143eb2012de9e702c2cd80bb5d5f1a75ea8fc/docs/ru/release-notes/2.0.0.md)
> остаются доступны; эта правка не меняет копию, встроенную в приложение.

## Основные изменения

- **Agent Kavor через WhatsApp — первый публичный Channel.** Общайтесь с локальными agents в личном чате или
  отдельной группе для каждого Workspace. Выбирайте контекст и CodingAgent, следите за прогрессом, отвечайте на
  вопросы и обменивайтесь вложениями. Привяжите аккаунт в настройках Channels в верхней панели; после привязки
  появится Workspace Channels, а настройки сохраняются автоматически. Улучшены сопряжение, переподключение и
  обратная связь о командах, состоянии, отмене и ошибках; исходное содержимое и корреляция Motion Photo
  сохраняются при нативном повторном выполнении.
- **Совместная работа CodingAgents.** Нативная отправка через provider, доставка после завершения хода и явное
  прерывание, если оно разрешено, соблюдают Guardrails для Connections и сохраняют черновики человека. Связанные
  agents также могут читать завершённые ходы других агентов через ограниченную историю с постраничной загрузкой.
- **Browser работает и за пределами видимого Canvas.** Связанные agents могут управлять вкладками WebBrowser в
  фоновом режиме. Start, Shutdown и отключение звука остаются под явным контролем, сохраняя выбор выключения,
  сохранённые вкладки и общие данные сайтов при изменениях жизненного цикла UI.
- **Ресурсы по требованию.** Вспомогательные процессы запускаются по мере необходимости, а неактивные ресурсы
  освобождаются без потери записанного состояния Workspace, Terminal, CodingAgent и Browser. Также улучшена
  очистка PTY и вспомогательных процессов.
- **Обновлённые шрифты и визуальное оформление.** Inter и Geist Mono на desktop, доработанное оформление приложения
  и восстановленная прозрачность значков в macOS.

## Исправления

- Сохраняет нативные параметры запуска CodingAgent, включая явно заданные модель, разрешения, сессию и рабочий
  каталог, не подменяя выбор пользователя без уведомления.
- Исправляет завершение ходов Grok и проверенные сценарии пассивного чтения сессий, улучшает сопоставление нативной
  доставки сообщений и подтверждение уведомлений между окнами Workspace.
- Показывает нативные вопросы CodingAgent и включает исходный Workspace в заголовки системных уведомлений,
  чтобы было проще различать параллельную работу в нескольких Workspaces.

## Установка

Скачайте Kavor с <https://download.agentkavor.com>. Существующие прямые установки могут проверить наличие этого
релиза в настройках Software Update. Обновление базы данных Workspace проходит через миграцию Kavor с резервным
копированием.

- Windows x64 доступен в Microsoft Store или через пошаговый установщик NSIS для отдельного пользователя.
  Microsoft подписывает и обновляет установки Store. Прямой установщик по-прежнему не подписан, поэтому
  Microsoft SmartScreen может потребовать явного подтверждения.
- Для macOS 13+ доступны отдельные DMG для Apple Silicon и Intel, подписанные Apple Developer ID Kavor и
  нотариально проверенные Apple. Автоматические обновления используют ZIP для соответствующей архитектуры,
  сохраняя DMG как ручной запасной вариант.
- Linux x64 предлагает AppImage и DEB. AppImage поддерживает обновления под управлением Kavor с явным
  согласованным перезапуском; обновления DEB устанавливаются вручную со страницы загрузки.

## Известные ограничения

- Если гиперссылка OSC 8 в Terminal выводится на строке, над которой уже находится указатель, перед открытием может
  потребоваться перевести указатель на другую строку и обратно. Это ограничение кеша наведения upstream xterm остаётся
  в данном релизе.
- Аудит производственных зависимостей сообщает о неустранённых upstream-предупреждениях об отказе в обслуживании для
  [braces](https://github.com/advisories/GHSA-vfj7-8cjw-p6xm) и
  [sprintf-js](https://github.com/advisories/GHSA-hp3w-g68c-fv3c). Эти версии уже присутствовали в Kavor 1.7.1.
  Рекурсивное отслеживание Workspace отключает раскрытие glob в пути, использующем braces; это мера снижения риска,
  а не исправление зависимости.
- WhatsApp требует привязанного аккаунта, доступа к сети и работающего Kavor на desktop с аутентифицированной сессией. Интеграция через привязанное
  устройство — не размещённый у Meta WhatsApp Business API; ограничения аккаунта WhatsApp остаются под контролем Meta.
- Выделенный общий Browser Profile Kavor принимает любые сертификаты сервера для локальной разработки.
  Враждебная сеть поэтому может выдавать себя за сайты, открытые в этом профиле, включая сайты, где пользователь
  входит в учётную запись. Сессия приложения Kavor сохраняет обычную проверку сертификатов Chromium.
- Nodes WebBrowser не используют профиль, расширения, историю или cookies внешнего Chrome пользователя.
  Удаление Node не удаляет общие данные сайтов; глобальные настройки Kavor позволяют явно очистить кеш, cookies
  и данные сайтов.
- Межсайтовые frames, изолированные в другом процессе Chromium, отмечаются как пропущенные и не могут
  управляться через границу безопасности guest.
- Пакеты Windows ARM64 и Linux ARM64 не включены. Прямые загрузки Windows пока не имеют сертификата издателя
  Authenticode; пакеты Microsoft Store подписывает Microsoft. Появление в Store может произойти после прямого
  stable-релиза, когда завершится независимая сертификация Microsoft.
